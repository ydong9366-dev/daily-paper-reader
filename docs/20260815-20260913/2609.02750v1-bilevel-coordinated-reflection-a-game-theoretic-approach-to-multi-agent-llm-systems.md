## 摘要
多智能体 LLM 系统通常使用一个编排器将任务分解给一组工作者，然后通过文本反思进行改进。尽管经验结果强劲，这些系统仍缺乏对协调、记忆改进以及外部验证作用的统一解释。我们将编排器与工作者之间的交互建模为一个双层协调博弈：在有界耦合下，工作者的局部更新博弈是一个近似势博弈，其均衡松弛由分解质量控制。随后，我们将反思分析为语义记忆状态上的随机移动。对于自由形式反思，我们推导出一个有限时间上界，证明其最坏情况紧性，并在可证伪的持续危害条件下给出一个正下界。我们进一步证明一个信息论不可能性结果：任何仅观察所生成文本记录的门控都无法在文本不可区分的环境上一致地改进，而环境锚定的门控则可以。受这一分离的启发，我们提出随机反思记忆上升（Stochastic Reflective Memory Ascent, SRMA），它仅在基于环境依据的评估风险严格下降后才接受候选记忆。在校准和非退化修正质量条件下，SRMA 可以精确、几何或多项式地收敛；匹配构造表明这两种速率情形都是阶紧的。我们还为随机评估提供置信门控，并为分段平稳环境提供重锚定保证。实验使用环境锚定指标实例化这些对象，并检验所预测的协调规律与漂移规律。在 500 个 SWE-bench 实例上，完整的基于 Kimi 的系统解决了 72.2%，而公开的 mini-SWE-agent 参考为 70.8%。代码：https://github.com/YihangChen9/Bilevel-Coordinated-Reflection

## Abstract
Multi-agent LLM systems commonly use an orchestrator to decompose a task for a team of workers and then improve through textual reflection. Despite strong empirical results, these systems lack a unified account of coordination, memory improvement, and the role of external verification. We model orchestrator-worker interaction as a bilevel coordination game: under bounded coupling, the workers' local-update game is an approximate potential game whose equilibrium slack is controlled by decomposition quality. We then analyse reflection as stochastic movement over semantic memory states. For free-form reflection, we derive a finite-time upper bound, prove worst-case tightness, and give a positive lower bound under a falsifiable persistent-harm condition. We further prove an information-theoretic impossibility result: no gate that observes only the generated transcript can improve uniformly over text-indistinguishable environments, whereas an environment-grounded gate can. Motivated by this separation, we introduce Stochastic Reflective Memory Ascent (SRMA), which accepts a candidate memory only after a grounded evaluation risk strictly decreases. Under calibration and non-degenerate corrective mass, SRMA converges exactly, geometrically or polynomially; matching constructions show that both rate regimes are order-tight. We also provide confidence gating for stochastic evaluation and re-anchoring guarantees for piecewise-stationary environments. Experiments instantiate these objects with environment-grounded metrics and test the predicted coordination and drift laws. On 500 SWE-bench instances, the complete Kimi-based system resolves 72.2% versus a 70.8% public mini-SWE-agent reference. Code: https://github.com/YihangChen9/Bilevel-Coordinated-Reflection

## 1. 核心问题与整体含义

- **研究背景**：多智能体 LLM 系统普遍采用“编排器（orchestrator）分解任务 + 工作者（worker）执行 + 文本反思写入共享记忆”的范式，在 AutoGen、MetaGPT、Reflexion 等框架中取得强经验结果，但模型权重在测试时冻结，记忆编辑成为主要适应通道。
- **核心问题**：现有框架多为过程性描述（谁与谁通信、更新哪个缓冲区），缺少统一理论解释：
  - 编排器的分解质量如何控制工作者的协调？
  - 无条件反思何时会平台化而非收敛？
  - 为什么外部验证器能成功，而更强的纯文本批评者仍可能失败？
- **整体含义**：本文将编排器–工作者交互建模为**双层协调博弈**，将反思建模为**语义记忆状态上的随机移动**，并用信息论证明**接地的必要性**，从而为多智能体 LLM 的协调、记忆改进与外部验证提供统一的理论基础。

## 2. 方法论

### 2.1 双层协调博弈（问题形式化）

- **Leader（编排器）**：生成策略剖面 τ = (τ₁,…,τ_N)，为 worker i 分配子任务 τᵢ；在较慢时间尺度更新策略记忆 mₒ。
- **Follower（工作者）**：生成局部子解 xᵢ；在较快时间尺度通过 η_c-better response 更新执行记忆 mₑ。
- **弱耦合可分解性假设（Assumption 1）**：
  - 全局效用 U(x) = Σᵢ uᵢ(xᵢ|τᵢ) + Σ_{(i,j)∈E} ψᵢⱼ(xᵢ,xⱼ|τᵢ,τⱼ)
  - κ := sup|ψᵢⱼ| < ∞，d_max 为最大邻居数；κ 与 d_max 共同刻画分解质量。
- **Lemma 1（近似势博弈）**：固定 τ 时，工作者子博弈是 η_c-近似势博弈，势函数为 E[U(x)]，松弛上界 **η_c ≤ 2 d_max κ**。
- **Theorem 1（Follower 收敛）**：迭代 η_c-better-response 有限步收敛到 η_c-近似纯策略纳什均衡。
- **Corollary 1（Leader 分解权衡）**：E[U(x*(τ))] ≥ J_loc(τ) − (5/2) N C(τ)，其中 C(τ)=d_max(τ)κ(τ)。好的分解同时提升局部效用并缩小耦合项。

### 2.2 双记忆漂移动力学与幻觉下限

- 记忆分为**执行记忆 mₑ**（worker 共享）与**策略记忆 mₒ**（orchestrator 使用）；将次优性 V_t ∈ [0,1]。
- **自由形式反思（Regime A）**：
  - **Assumption 2（单边漂移）**：E[V_{t+1}|F_t] ≤ (1−γ_t)V_t + ν_t。
  - **Theorem 2（有限时间上界）**：e_T ≤ (1−γ)^T e₀ + (ν/γ)(1−(1−γ)^T)，极限上界为 ν/γ。
  - **Proposition 1（最坏情况紧性）**：该上界在单边漂移类中不可一致改进。
  - **Assumption 3（持续有害承诺）**：E[V_{t+1}|F_t] ≥ (1−γ)V_t + ν。
  - **Theorem 3（普遍下界）**：lim inf e_T ≥ ν/γ > 0。
  - **Corollary 2（双侧误差管）**：上下界匹配时误差精确收敛到 ν/γ。
- **Leader 外层循环**：在更慢时间尺度上类似地得到有限回合界，不主张渐近 leader-regret。

### 2.3 接地的必要性（信息论不可能性）

- **定义 1（自包含门控）**：仅基于生成文本过程及内部随机性的接受规则；接地门控可额外观察环境相关信号（奖励、模拟器状态、测试执行、形式化检查结果）。
- **模糊对构造**：两个环境 ε⁺ / ε⁻ 在文本层面完全不可区分（相同提议核），但同一反思的语义效果相反。
- **Theorem 4（自门控不可能性）**：对任意自包含门控与任意时域 T，max{e⁺_T, e⁻_T} ≥ e₀；若 e₀<1/2 且接受过模糊提议则严格大于。
  - 自由形式规则在两个环境中 e_T → 1/2；
  - 接地门控只接受修正类，e_T = e₀(1−κμ)^T → 0。
- **Remark 1**：该定理是对文本不可区分环境的 minimax 结论；当真理依赖外部状态时，评判能力无法替代接地。

### 2.4 SRMA：验证器门控反思

- **定义 2（验证器与评估风险）**：Rᵢ(mₑ) := ρ(V(gᵢ(τᵢ,mₑ), τᵢ))，其中 gᵢ 为固定确定性评估协议（如精确规划器）。
- **定义 3（SRMA 更新）**：仅在 **Rᵢ(fme_{t+1}) < Rᵢ(mₑᵗ)** 时接受候选记忆，否则保留原记忆。
- **Assumption 4（校准）**：Vᵢ(mₑ) ≤ L·Rᵢ(mₑ)。
- **Assumption 5（非退化修正质量）**：p_t ≥ c₁ R_t^β。
- **Assumption 6（比例接受递减）**：E[R_t − R_{t+1}|accept] ≥ c₂ R_t。
- **Proposition 2（单调乘法漂移）**：E[R_{t+1}|F_t] ≤ R_t − c R_t^{1+β}，c = c₁c₂。
- **Theorem 5（精确收敛与速率）**：
  - β=0：几何速率 r_T ≤ (1−c)^T r₀；
  - β∈(0,1]：多项式速率 r_T ≤ (r₀^{−β} + cβT)^{−1/β}；
  - 校准成立时任务次优性以相同速率收敛。
- **Proposition 3（速率紧性）**：几何速率精确，多项式指数 T^{−1/β} 在时间尺度上阶紧。
- **Proposition 4（置信门控随机评估）**：用 K_t 个独立探针 + Hoeffding 界，仅当候选风险上界 + a_t < 当前风险下界 − a_t 时接受。
- **Proposition 5（分段平稳重锚定）**：风险变化有限次，最终段满足假设时定理 5 仍适用。
- **Algorithm 1 流程**：评估当前风险 → 采样反思 → 形成候选记忆 → 评估候选风险 → 若严格下降则提交，否则保留；随机评估时用置信测试替代。

## 6. 主要结论与发现

- **协调**：分解质量通过 η_c ≤ 2 d_max κ 控制 follower 均衡松弛；好的分解同时提升局部效用并降低耦合代价。
- **自由反思**：有有限时间上界 ν/γ，且最坏情况紧；持续有害承诺下存在正误差下限，即无条件反思会平台化。
- **接地的必要性**：任何仅观察文本的门控在文本不可区分环境上无法一致改进；接地门控可恢复几何收敛。
- **SRMA**：在校准与非退化修正质量下精确收敛，速率或几何或多项式且阶紧；置信门控处理随机评估，重锚定处理分段平稳。

  - RC：SRMA 达 oracle 的 98.
