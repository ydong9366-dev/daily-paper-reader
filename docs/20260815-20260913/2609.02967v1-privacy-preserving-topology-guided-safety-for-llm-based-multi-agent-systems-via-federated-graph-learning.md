## 摘要
面向基于LLM的多智能体系统（MAS）的拓扑引导防护会基于智能体间通信图训练GNN，以定位风险智能体并对拓扑进行干预——但它们假设单一运营商能够汇集所有带标签的轨迹。跨组织时这一假设不成立：各交互回合包含私有提示、工具输出和专有工作流，且任何单一数据孤岛都无法看到完整攻击分布。我们将隐私保护MAS防护建模为图联邦学习，并实现FGLGuard：每个运营商在自己的由评判器标注的回合图上拟合边特征图注意力检测器，并且仅共享模型更新。该方法结合了面向非IID客户端的近端局部目标、域平衡聚合、受过度拒答约束的阈值校准、经佐证的上游评分，以及针对被拦截答案的受保护重写。联邦并非可选：现成迁移在分布偏移下崩溃（仅在域内重训练后AUROC才从0.51到0.70），因此可部署的防护必须在每个站点的私有轨迹上自适应。在Agent-SafetyBench、R-Judge和AgentDojo上，联邦FGLGuard在全部三个基准上超过域内集中式上限，且无需汇集任何数据——而无监督异常防护和仅本地训练则失败。一个防护器在四个不同域运营商间联邦后，与多域集中式相比AUROC差距在0.03以内，而任何单域防护器在其他域上都会崩溃。实时FGLGuard在效用接近无防护、零API成本且能力损失可忽略的情况下，将AgentDojo的真实攻击成功率降低43%。

## Abstract
Topology-guided safeguards for LLM-based multi-agent systems (MAS) train a GNN over the inter-agent communication graph to localize risky agents and intervene on the topology---but they assume one operator can pool all labeled traces. Across organizations that assumption breaks: episodes contain private prompts, tool outputs, and proprietary workflows, and no silo alone sees the full attack distribution. We cast privacy-preserving MAS safeguarding as graph federated learning and instantiate FGLGuard: each operator fits an edge-featured graph attention detector on its own judge-labeled episode graphs and shares only model updates. The method couples a proximal local objective for non-IID clients, domain-balanced aggregation, over-refusal-constrained threshold calibration, corroborated upstream scoring, and a guarded rewrite for blocked answers. Federation is not optional: off-the-shelf transfer collapses under distribution shift (AUROC 0.51 to 0.70 only after in-domain retraining), so a deployable guard must adapt on each site's private traces. On Agent-SafetyBench, R-Judge, and AgentDojo, federated FGLGuard exceeds the in-domain centralized ceiling on all three benchmarks without pooling any data---where unsupervised anomaly guards and local-only training fail. One guard federated across four different-domain operators comes within 0.03 AUROC of multi-domain centralization, while any single-domain guard collapses on the others. Live FGLGuard cuts AgentDojo's ground-truth attack-success rate by 43% at near-unguarded utility, zero API cost, and negligible capability loss.

- **背景**：基于 LLM 的多智能体系统（MAS，如 AutoGen、MetaGPT、LangGraph）通过通信图组织多个智能体协作，但通信通道本身成为主要攻击面——注入提示会在智能体间"蠕虫式"传播，对抗消息沿网络扩散，递归交互耗尽资源。
- **现有范式**：拓扑引导防护（如 G-Safeguard）把 MAS 当作图，用 GNN 定位风险智能体并干预拓扑，效果显著。
- **致命假设**：该范式默认"单一运营方可以汇集所有带标签轨迹"进行集中式训练。
- **跨组织现实**：运行回合包含私有提示、工具输出和专有工作流，数据被天然隔离（siloed）；每个运营方只能看到全部攻击分布的一个切片，最需要他人攻击样本的机构反而拿不到。
- **迁移失败的实证**：现成 G-Safeguard 检测器在真实 Agent-SafetyBench 回合上仅达随机水平（AUROC 0.51）；同一架构在域内重训练后回升到 0.70，说明瓶颈是分布偏移而非架构。
- **核心问题**：运营方能否在不交换任何原始轨迹的前提下，协作训练一个拓扑安全防护器？作者将隐私保护 MAS 防护形式化为**图联邦学习**问题，并提出 FGLGuard。

## 2. 方法论

### 核心思想
将 MAS 安全防护建模为图联邦学习：各运营方在本地对自身带标签回合图训练边特征图注意力检测器，仅交换模型参数；针对非 IID、标签稀缺、跨域的现实，联合设计评分器、聚合、校准与运行时算子。

### 关键技术细节

- **图表示**：
  - 回合被表示为属性图 $G=(X,A,E)$，节点为智能体，$A$ 为有向通信拓扑。
  - 边特征 $e_{ij}$ 为接收方智能体各轮话语嵌入序列（冻结句编码器 MiniLM，$d=384$）。
  - **作者改进**：节点特征锚定到智能体自身话语历史 $x_i=\frac{1}{T}\sum_t \phi(u_i^t)$，而非从入边聚合——避免稀疏拓扑下孤立节点无特征。
- **边条件注意力评分器**：两层边特征 GAT（256 隐藏维、4 头），公式 (2)–(4) 给出边条件注意力、softmax 归一化与节点更新；线性头输出每智能体风险分 $s_j\in[0,1]$。
- **联邦近端训练（Eq. 5）**：客户端求解 BCE 损失 + 近端项 $\frac{\mu}{2}\|\theta-\theta^{(r)}\|^2$（$\mu=0.01$），防止少数（或无）不安全样本的客户端漂移向良性多数。
- **域平衡聚合（Eq. 6）**：域内按节点数比例加权，跨域每个域获得总权重 $1/D$，避免大域主导；单域时退化为 FedAvg。
- **预算约束阈值校准（Eq. 7）**：在 $FPR\le\rho$ 约束下最大化召回率，平票时偏向低 FPR；在仅良性流量上退化为 $(1-\rho)$ 分位数。校准统计量即为部署时所用的佐证分数，故无需重新调参。
- **佐证干预算子（Eq. 8–9）**：$\hat{s}_j=\max(s_j,\max_{i:A_{ij}=1}s_i)$，用上游邻居风险佐证当前智能体；决策 $\Pi(u_j)$ 为：通过则放行，被拦截则授予一次受保护重写并重新评分，仍不合格则拒答。
- **算法流程（Alg. 1）**：服务器广播全局模型 → 客户端本地近端训练 → 上传参数与节点数 → 域平衡聚合 → 服务器用客户端上传的标量分数对 $(s,y)$ 校准 $\tau^*$，全程无原始图离开客户端。

## 6. 主要结论与发现

- **(Q1)** 联邦 FGLGuard **无需汇集数据即超过域内集中式上限**（ASB 0.726 / R-Judge 0.895 / AgentDojo 0.680）；仅本地训练与现成迁移均失败（本地平均 0.666/0.762/0.584，且在标签偏斜下崩溃至 0.509）。
- **(Q2)** 免费评判器标签优于无监督与免训练防护：无监督方法在原生植入攻击语料上看似强，但在有机风险上跌至随机甚至反相关（"异常智能体"假设在协作漂移场景下无信号）；免训练方法在 ASB 上仅 0.533–0.574。
- **(Q3)** **跨域联邦与多域集中式几乎持平**（每域差距 ≤0.03 AUROC，ASB 上甚至略高）；任何单域专家在域外崩溃至 0.537–0.573，即攻击覆盖只能通过"带着自己轨迹加入联邦"获得，无法通过相似性迁移。
- **(Q4)** 实时部署中，FGLGuard 将 AgentDojo 定向 ASR 从 0.401 降至 0.230（**−43%**），同时干净效用从 0.575 升至 0.650；能力损失 ≤4.2 分（表 1 三项 ≤2.1），而 LLM 评判器过度拦截 17–54% 良性流量、最高抹去 24.4 分。
- **总体**：联邦是必要条件而非可选项；分布偏移所需的域内自适应可以在不汇集隐私轨迹的前提下获得。

## 7. 优点

- **问题建模新颖**：首次将隐私保护 MAS 安全防护形式化为图联邦学习，准确指出原范式的集中式假设是跨组织部署的阻塞点。
- **设计元素与部署现实一一对应**：偏斜分布→近端目标；数据量不均→域平衡聚合；用户容忍度→过度拒答预算；风险来自上游→佐证评分；硬拦截损失工作→受保护重写。每个机制都有对应的理论命题（Prop. 1–3）支撑。
- **理论保证清晰**：域平衡聚合的凸组合性/域等权/退化性/分裂不变性；预算校准的可行性构造；佐证算子的阻塞单调性与"佐证+校准必须联合使用"的结论。
- **工程代价极低**：0.5M 参数、纯 CPU 训练、50 ms 推理、零 API 成本，实用性突出。
- **实验严谨**：梯度预算匹配、种子固定、划分卫生、独立 gpt-5 审计、拓扑迁移矩阵、骨干迁移验证，消融系统且覆盖多种部署变量。
- **诚实的负面结果**：明确指出无监督/免训练路线在有机风险上失效，并给出结构性解释。

## 8. 不足与局限

- **模拟联邦**：作者自述使用模拟联邦环境，未在真实跨组织部署中验证通信、同步、恶意客户端等实际因素。
- **需部署特定校准**：阈值 $\tau^*$ 依赖各站点验证分数，跨站点直接迁移校准点未被验证（Prop. 2(iv) 仅是校准集上的经验保证，非分布无关）。
- **显式拒答基准改进有限**：作者承认在显式 refusal 类基准上提升有限。
- **标签依赖**：方法假设运行时评判器为每个回合免费打标；若评判器本身有偏或不可用，方法前提不成立。
- **节点标签信用分配简化**：将回合标签广播到所有节点（虽经 0.708 vs 0.705 的敏感性检验，但仍是近似）。
- **图结构敏感性**：团队规模 $n=3$ 时性能明显下降
