## 摘要
基于大语言模型（LLM）的多智能体系统（MAS）的性能在很大程度上取决于有效的通信拓扑。然而，现有的拓扑生成方法通常仅通过任务级奖励驱动的黑盒优化来学习通信拓扑。虽然有效，但这种优化几乎无法解释为何选择特定的通信边，使得难以识别对成功协作至关重要的关键通信子图。为解决这一局限性，我们提出了E2-Explainer，一个模型无关的框架，用于为任意拓扑生成器产生的通信拓扑提供可解释的解释。具体而言，我们将拓扑解释表述为一个因果归因问题，该问题识别由任务保持的边级证据支持的精简通信子图。我们通过一种格兰杰风格的目标获得该证据，该目标衡量屏蔽每个通信通道如何改变任务结果和最终响应的稳定性。然后将得到的预算子图蒸馏到一个摊销解释器中，从而在部署时无需重复进行边级评估即可实现高效的事后解释。在多个推理和编码基准上的大量实验表明，E2-Explainer能够识别保持成功协作的关键通信子图。这些子图还可以直接执行以修剪冗余通信边，在显著降低通信成本的同时保持有竞争力的任务性能。

## Abstract
The performance of large language model (LLM)-based multi-agent systems (MAS) largely depends on effective communication topologies. Existing topology generation methods, however, typically learn communication topologies through black-box optimization driven solely by task-level rewards. While effective, such optimization provides little insight into why particular communication edges are selected, making it difficult to identify the critical communication subgraphs responsible for successful collaboration. To address this limitation, we propose E2-Explainer, a model-agnostic framework for providing interpretable explanations of communication topologies produced by arbitrary topology generators. Specifically, we formulate topology explanation as a causal attribution problem that identifies compact communication subgraphs supported by edge-level evidence of task preservation. We obtain this evidence with a Granger-style objective that measures how masking each communication channel changes the task outcome and the stability of the final response. The resulting budgeted subgraphs are then distilled into an amortized explainer, enabling efficient post-hoc explanation without repeated edge-level evaluations at deployment. Extensive experiments on multiple reasoning and coding benchmarks demonstrate that E2-Explainer identifies critical communication subgraphs that preserve successful collaboration. These subgraphs can also be executed directly to prune redundant communication edges, substantially reducing communication costs while maintaining competitive task performance.

## 2. 论文提出的方法论

### 2.1 核心思想

- 将**拓扑解释**形式化为一个**因果归因问题**：识别出在移除后会对任务结果产生显著负面影响的通信边/子图。
- 借鉴 **Granger causality** 的思想：若某条通信边传递的信息能改进 MAS 的协作性能，则该边对协作结果具有因果重要性。
- 将 Granger 式因果准则从单条边扩展到局部通信子结构，从而识别出紧凑的、因果相关的子图。

### 2.2 技术框架与关键步骤

E2-Explainer 包含四个主要阶段（见图 2）：

**Step 1：候选拓扑构造**
- 使用任意现有拓扑生成器（如 G-Designer、AgentPrune、OFA-MAS、ARG-Designer）生成候选通信图 \(G = (V, E)\)。

**Step 2：边级 Granger 式因果归因**
- 对每条活跃边 \(e = (u, v)\)，构造干预图 \(G_{-e} = G \setminus \{e\}\)，保持其他所有因素不变，屏蔽该边传递的消息。
- **任务级因果贡献**：
  \[
  \Delta^{task}_e = Q(x, G) - Q(x, G_{-e})
  \]
  其中 \(Q(x, G)\) 为任务得分（如准确率、执行正确率等）。仅保留非负的保持贡献：
  \[
  u^{task}_e = \max(0, \Delta^{task}_e)
  \]
- **辅助语义信号（语义熵）**：任务得分可能过于粗糙，无法区分同一分数下的不同掩码效果。因此引入结果级语义熵（semantic entropy）作为辅助信号：
  \[
  \bar{H}(Y) = -\sum_{c \in C(Y)} p(c) \log p(c)
  \]
  其中 \(C(Y)\) 为 \(M\) 次随机执行所得响应的语义等价类。语义辅助效应定义为：
  \[
  u^{sem}_e = \max(0, \bar{H}(Y_{G_{-e}}) - \bar{H}(Y_G))
  \]
  正值表示掩码该边增加了最终响应的不确定性，说明该边有助于保持原始行为。
- **统一边效用**：
  \[
  u_e = \text{clip}_{[0,1]}\left(\alpha \cdot \tilde{u}^{task}_e + \beta \cdot \tilde{u}^{sem}_e\right)
  \]
  其中 \(\tilde{\cdot}\) 表示归一化，\(\alpha, \beta\) 为权重（实验中取 \(\alpha=0.8, \beta=0.2\)）。
- 所有边的效用值构成一个保留排序（preservation ordering）\(\pi_G\)。

**Step 3：因果子图提取**
- 给定预算 \(b = (\rho_E, \rho_V)\)（边/节点剪枝比例），通过 TopK 选择保留效用最高的边：
  \[
  E^*_b = \text{TopK}(\pi_G, k_E(b))
  \]
- 执行**可执行性约束投影** \(H^*_b = R_{valid}(G, E^*_b, k_V(b))\)，确保子图：
  - 不引入原始图中不存在的边；
  - 保留必要的输入节点和最终聚合节点；
  - 移除与被剔除节点关联的边；
  - 若原始图为有向无环图（DAG），投影后仍保持无环性。
- 多个预算 \(b \in B\) 生成一个**预算敏感解释族** \(F^*(x, G) = \{H^*_b : b \in B\}\)。

**Step 4：摊销解释器（Amortized Explainer）**
- 由于边级因果归因需要反复执行底层 LLM-MAS，部署时成本过高，因此将 Step 2–3 发现的因果子图作为**监督信号**，训练一个摊销解释器 \(F_\theta\)：
  \[
  \hat{H}_b = F_\theta(x, G, b), \quad \hat{H}_b \subseteq G
  \]
- 解释器输入：任务查询 \(x\)、候选图 \(G\)、预算 \(b\)；输出：边/节点保留概率，再通过 TopK 和有效性投影得到最终子图。
- 训练目标：边级与节点级二元交叉熵损失：
  \[
  L = L_{edge} + \lambda_{node} L_{node} + \lambda_{wd} \|\theta\|_2^2
  \]
- 部署时只需一次前向传播，无需任务标签、无需边干预评估，可直接为新拓扑生成预算化子图。

## 6. 主要结论与发现

1. **冗余通信边普遍存在**：在 G-Designer 和 OFA-MAS 生成的拓扑中，大部分随机掩码会导致性能下降，但仍有少量随机剪枝能保持甚至提升性能，说明存在任务保持型紧凑子图，但难以通过随机剪枝发现。
2. **E2-Explainer 能有效识别关键子图**：在 4 种拓扑优化器上，E2-Explainer 将加权 token 使用量降低 20.1%–25.6%，同时保持或提升了平均准确率（提升 0.44–1.09 个百分点）。
3. **跨优化器迁移有效**：仅在 G-Designer 图上训练的解释器，可直接应用于未见过的 ARG-Designer、OFA-MAS、AgentPrune，说明学到的是可迁移的通信路径选择线索，而非记忆特定生成器的邻接模式。
4. **跨规模泛化可行**：5-agent 训练的解释器迁移到 6-agent 图，在 MMLU 和 HumanEval 上均实现准确率提升和 token 减少。
5. **因果信号是主要驱动力**：消融实验显示，去掉任务级因果信号会导致显著性能下降（MMLU 从 79.74 降至 75.82），而语义熵作为补充信号能进一步改善效果。
6. **结构稀疏 ≠ 实际成本降低**：仅剪边（E75+N0）最多只减少 5.27% token；引入节点剪枝（如 E25+N20）才能实现显著的 token 节省（25.10%），说明通信成本由节点保留、边保留、消息长度等共同决定。
7. **手工拓扑上同样有效**：在五种人工指定的拓扑上，E2-Explainer 在 30 个组合中的 26 个中提升或持平准确率，并在所有组合中降低 token 使用量。
8. **剪枝存在风险**：特别是代码生成任务（HumanEval）中，过度节点剪枝（如 N40）会导致准确率下降 6.52 个百分点，说明不同角色可能提供互补性信号。

## 7. 优点

- **问题定义清晰且新颖**：将 LLM-MAS 拓扑解释定义为因果归因下的紧凑子图识别问题，填补了拓扑生成可解释性的空白。
- **模型无关性强**：不依赖任何特定拓扑生成器的内部参数或优化状态，仅基于候选图、任务和角色信息进行操作，适用范围广。
- **因果与语义信号互补**：任务级因果贡献提供主要证据，语义熵在任务奖励稀疏或粗糙时提供更密集的反馈，二者结合提高了归因鲁棒性。
- **摊销化设计务实高效**：将昂贵的离线边干预评估蒸馏为一次前向传播的在线预测，避免了部署时的重复 LLM 执行，工程可行性高。
- **实验设计较全面**：覆盖多种优化器、数据集、预算、规模、校准来源和人工拓扑，且 Token 统计口径严谨，报告实际在线成本而非仅名义稀疏度。
- **定性分析深入**：提供了四个完整执行轨迹案例，细致展示了子图剪枝如何影响信息传播和最终聚合结果，增强了结果的可信度和可解释性。
- **可执行性保障**：通过有效性投影（validity projection）确保子图可直接执行，且不引入原始图中不存在的边。

## 8. 不足与局限

- **校准样本量较小**：每个数据集仅使用 40 条校准查询，可能不足以捕捉任务分布的多样性，在更复杂或更多样化的任务上泛化性存疑。
- **边级归因的局限性**：论文只估计了单边移除在完整拓扑背景下的“一阶条件贡献”，没有枚举多边联合干预（多边组合的因果效应），可能遗漏边之间的交互效应。作者也承认多边组合的枚举成本是指数增长的。
- **单骨干模型限制**：所有实验只在 Qwen3-8B 上验证，未测试不同规模或不同家族的 LLM，无法确认方法对骨干模型变化的鲁棒性。
- **默认预算的选择合理性**：E25+N20 是在 G-Designer 上选定的，并固定迁移到其他优化器。虽然保证了公平性，但不同优化器的最优预算可能不同，实际应用中可能需要针对性地调整。
- **部分场景准确率下降**：在 GSM8K、MultiArith、SVAMP 的若干组合中，E2-Explainer 导致准确率下降（尤其 OFA-MAS 在 SVAMP 上下降 1.32 点），说明冗余边并非总是无用的，过度剪枝仍有风险。
- **计算开销未完全透明**：虽然在线推理成本显著降低，但离线边干预评估（每条边 5 次执行 × 多预算 × 40 条校准样本）的总计算成本并不低，论文未单独报告这部分资源消耗。
- **随机性带来的因果推断不确定性**：干预图和原始图使用独立的随机采样（温度 0.2），而非配对种子，因此边级贡献估计存在一定噪声；定性案例也提示不能将正确性变化单纯归因于某条边的移除。
- **可解释性的“解释”本质**：该方法识别的是“保留任务行为的关键子图”，而不是提供人类可读的语义解释（如自然语言规则），对于需要深层逻辑说明的应用场景可能仍然不够直观。
