## 摘要
无人驾驶飞行器（UAV）越来越多地部署在复杂室外环境中的自主导航，其中动态条件和任务要求需要智能自适应决策。现有的基于优化、机器学习（ML）和强化学习（RL）的方法通常依赖于预定义模型或特定任务训练，限制了它们在不确定场景中的泛化和适应性。最近的大语言模型（LLM）辅助方法提供了有前景的推理能力，但仍然受到有限的智能体功能的限制，包括不足的记忆、规划和工具交互机制。本文提出了一种基于LLM智能体的路径查找器（LAPF）框架，用于城镇规模室外环境中的自主UAV导航。LAPF通过将感知、记忆、规划和动作模块集成到闭环认知架构中，扩展了LLM辅助导航。所提出的智能体利用先前的导航经验，执行思维链（CoT）推理，将每个检测到的危险与有界的纠正动作配对，并根据环境反馈动态优化航路点决策。每种方法的三个独立试验表明，LAPF的平均路径长度分别为512.83米和506.37米，而直线最优路径为497.33米，相对于CoT提示，路径长度分别减少了17.2%和15.6%，在开阔场地和障碍物注入场景中，绝对路径效率分别为97.1%和98.1%。此外，LAPF是唯一一种将每个检测到的危险与有界的、度量中性的纠正动作配对，同时保持接近目标的稳定性，且在两种场景中零钳位事件的评估方法，而CoT提示从9.7增加到14.0个事件。

## Abstract
Uncrewed aerial vehicles (UAVs) are increasingly deployed for autonomous navigation in complex outdoor environments, where dynamic conditions and mission requirements require intelligent adaptive decision-making. Existing optimization-based, Machine Learning (ML), and Reinforcement Learning (RL) approaches often rely on predefined models or task-specific training, limiting their generalization and adaptability in uncertain scenarios. Recent Large Language Model (LLM)-assisted approaches offer promising reasoning capabilities but remain constrained by limited agentic functionality, including insufficient memory, planning, and tool interaction mechanisms.This paper proposes an LLM-Agent-Based Path Finder (LAPF) framework for autonomous UAV navigation in town-scale outdoor environments. LAPF extends LLM-assisted navigation by integrating perception, memory, planning, and action modules into a closed-loop cognitive architecture. The proposed agent leverages prior navigation experiences, performs Chain-of-Thought (CoT) reasoning, couples each detected hazard to a bounded corrective action, and dynamically refines waypoint decisions based on environmental feedback.The three independent trials per method demonstrate that LAPF achieves mean path lengths of 512.83 m and 506.37 m, compared to the straight-line optimum of 497.33 m, corresponding to path length reductions of 17.2% and 15.6% relative to CoT prompting and absolute path efficiencies of 97.1% and 98.1% in open-field and obstacle-injected scenarios, respectively. Furthermore, LAPF is the only evaluated approach that couples every detected hazard to a bounded, metric-neutral corrective action while maintaining near-goal stability, with zero clamp events in both scenarios, whereas CoT prompting increases from 9.7 to 14.0 events.

## 2. 方法论

### 2.1 核心思想
- 将无人机导航构建为**闭环感知–推理–行动循环**，而非单次提示到输出的映射。
- 扩展常规 LLM 提示法，集成四个核心模块：**感知（Perception）、记忆（Memory）、规划（Planning）、行动（Action）**，并通过反馈信号不断修正决策。
- 在行动层引入**两层屏蔽策略（two-tier shielded policy）**：第一层保证危险检测的强制调用，第二层为自主决策的工具调用，确保安全关键场景的执行可靠性。

### 2.2 系统架构与关键技术细节

**（1）感知模块**
- 观测模型为 `Ot = {It, σt, Lt}`，其中：
  - `It`：RGB 图像（1024×768），直接以原生图像输入传给 VLM 骨干；
  - `σt`：LiDAR 点云的压缩统计量（包含点云数量、距离边界、横向边界和最小视线方向坐标 `ct`）；
  - `Lt`：6-DoF 位姿（位置 + 欧拉角）。
- 点云和位姿以符号状态形式进入文本提示，与视觉图像在同一轮推理中融合。

**（2）记忆模块**
- 维护最近 `k=3` 个导航回合（episode），每个回合含观测、执行航点、执行结果和 LLM 生成的反思（reflection）。
- 检索基于**最近性（recency）**而非相似性，为决策提供时间上下文。

**（3）规划模块**
- 采用思维链（CoT）推理，综合当前观测、记忆和经验反馈信号生成候选航点。
- 策略形式化为：`π: (Psys, G, Ot, Mt, φt) → (cwp_t, Tools_t)`。
- 输出为结构化 JSON（包含 situation_analysis、thought、waypoint、tool_calls），保证可解析性。

**（4）行动模块（两层屏蔽策略）**
- **第一层（保证）**：危险指示器 `ht = 𝟙[ct ≤ dsafe]` 在每一步强制执行，与模型是否调用工具无关。若 `ht=1`，模型航点被确定性修正算子 `R(wp_{t-1}) = wp_{t-1} + κ(p_goal - wp_{t-1})` 覆盖，其中 `κ∈(0,1)`。
- **第二层（自主）**：航点调整器（WaypointAdjust）、保持算子 `H(w)` 等工具由模型自主调用。
- 最终执行航点遵循有序组合：
  `wp_t = H(𝟙[WaypointAdjust∈Tools_t] [ht·R(wp_{t-1}) + (1-ht)·C(cwp_t)])`
- 稳定性算子 `C(w)` 在接近目标区域（距目标 < ε）控制步长不超过 `δ_max`。

**（5）反馈闭环**
- 每步执行后计算路径长度误差、趋势和效率，更新反馈信号 `φt`，并将新 episode 写入记忆库，实现闭环更新。

### 2.3 关键公式与目标函数
- 投影任务长度：`êL_t = L_t + ‖p_goal - wp_t‖`（已走长度 + 到目标剩余距离）；
- 路径效率：`η_t = L* / êL_t`（L* 为直线最优距离）；
- 偏差比：`ρ_t = η_t^{-1}`；
- 钳位事件数 `Nc` 与危险事件数 `Nh`；
- 优化目标：`min_π E[êL_{Tmax}]`，满足目标到达条件和强制执行条件（危险时的位移为有界确定性值）。

### 2.4 核心性质
- **度量中性（Metric Neutrality）**：修正算子 R 对路径效率指标贡献为零（因修正总是落在起点–目标连线上），保障安全执行与路径质量指标互不混淆。

## 3. 实验设计

- **数据集**：UAVScenes 数据集，AMtown03 城镇序列（41 帧，110 步决策步长，超出则循环观测序列）。
- **场景设置**：
  - **开放场场景（Open-Field）**：无注入障碍，直线最优路径长 497.33 m；
  - **障碍注入场景（Obstacle-Injected）**：注入 5 个障碍（其中 4 个低于 5 m 安全阈值，触发危险信号），由覆盖感知间隙 `ct` 实现，且所有方法接受相同的观测序列。
- **对比方法**：
  - **Pure LLM**：直接生成决策，无反馈、记忆或迭代修正；
  - **CoT LLM**：具备思维链推理，但仍非智能体化；
  - **LAPF（本文方法）**。
- **公平性控制**：
  - 所有方法共用同一 Qwen2-VL-7B 骨干、相同解码设置、逐字节相同的符号状态和相同的输出 schema；
  - RGB 图像输入格式、C 算子、H 算子对所有方法一致；
  - 障碍注入作用于观测流而非指令状态，保证三种方法面对相同的危险集合。

## 6. 主要结论

- **路径长度**：开放场与障碍注入场景中，LAPF 平均路径长度分别为 512.83 m 和 506.37 m（直线最优 497.33 m），较 CoT LLM 分别**减少 17.2% 和 15.6%**；
- **路径效率**：分别达 **97.05% 和 98.09%**，远高于 Pure LLM（89.4%/85.7%）和 CoT LLM（80.4%/83.0%）；
- **稳定性**：LAPF 在两个场景均保持**零钳位事件**，而 CoT LLM 从 9.7 增至 14.0 次，Pure LLM 从 0.0 增至 2.3 次；
- **安全性**：LAPF 是唯一能将所有检测到的危险（4 次注入事件）转换为有界、确定性修正动作的方法；
- **归因分析**：性能提升主要来源于记忆、反馈与工具强制执行的协同作用，而非单纯的推理深度。
