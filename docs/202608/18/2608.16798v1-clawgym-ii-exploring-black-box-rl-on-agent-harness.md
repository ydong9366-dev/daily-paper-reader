## 摘要
智能体框架通过协调智能体与环境的交互，显著提升了长时程任务的性能。然而，通过复杂框架进行强化学习仍 largely 未被探索，因为将此类训练扩展到长时程智能体任务会带来根本性挑战。在这项工作中，我们提出了一种统一的黑盒强化学习框架，用于通过复杂框架对通用智能体进行稳定且可扩展的优化。具体而言，我们首先构建了一个基于沙箱的执行基础设施，将任务环境和框架隔离在临时沙箱中，以支持大规模并发回放。然后，我们将策略优化与不透明的框架执行解耦，并在模型边界放置一个服务代理以捕获模型调用。为了重构多轮轨迹并提高训练效率，我们将捕获的调用组织成前缀树，并进一步调整基于评论者的 PPO 和无评论者的 GRPO 以优化恢复出的树结构。同时，我们在整个优化过程中保持训练-推理一致性。最后，我们引入了混合框架训练，允许单个模型通过异构框架进行联合优化。借助 Qwen3-30A3B，黑盒强化学习通过 OpenClaw 和 Claude Code 分别在 ClawGym-Bench 上将 Pass@1 提升了 9.98 和 14.81 个点，同时在 200-400 个优化步骤内保持稳定。此外，该框架在更具挑战性的任务（如 JobBench 和 OfficeQA）上也取得了持续的改进。总体而言，我们的框架通过黑盒框架实现了对通用智能体的有效、稳定且可扩展的优化，并支持跨异构执行系统的统一训练。

## Abstract
Agent harnesses have substantially improved performance on long-horizon tasks by coordinating agent interactions with the environment. However, reinforcement learning through complex harnesses remains largely unexplored, as scaling such training to long-horizon agent tasks introduces fundamental challenges. In this work, we present a unified black-box RL framework for stable and scalable optimization of general agents through complex harnesses. Concretely, we first build a sandbox-based execution infrastructure that isolates task environments and harnesses within temporary sandboxes for large-scale concurrent rollouts. We then decouple policy optimization from opaque harness execution and place a serving proxy at the model boundary to capture model calls. To reconstruct multi-turn trajectories and improve training efficiency, we organize the captured calls into prefix trees and further adapt both critic-based PPO and critic-free GRPO to optimize over the recovered tree structure. Meanwhile, we maintain training-inference consistency throughout the optimization process. Finally, we introduce mix-harness training, allowing a single model to be jointly optimized by heterogeneous harnesses. With Qwen3-30A3B, black-box RL improves Pass@1 on ClawGym-Bench by 9.98 and 14.81 points through OpenClaw and Claude Code, respectively, while remaining stable over 200-400 optimization steps. Moreover, the framework yields consistent gains on more challenging tasks such as JobBench and OfficeQA. Overall, our framework enables effective, stable, and scalable optimization of general agents through black-box harnesses, supporting unified training across heterogeneous execution systems.

### 研究动机与背景

- **Agent Harness 的重要性**：现代智能体系统日益依赖成熟的 agent harness（如 Claude Code、Codex、OpenClaw）作为底层运行层，它们集成了系统提示词、工具接口、上下文管理、工作流编排、重试与恢复机制等能力，能显著提升长时程任务的完成质量。
- **核心矛盾**：即便模型本身很强，若未经过与特定 harness 适配的训练，也可能无法充分发挥 harness 的能力。因此需要通过强化学习让模型更好地利用这些复杂 harness。
- **关键挑战**：现代 harness 设计复杂、执行逻辑不透明，不能像简单文本环境那样直接观察完整交互轨迹来训练。这引出了论文的核心研究问题：

> **如何通过 harness 进行黑盒强化学习，以稳定地优化通用智能体？**

### 具体面临的三项根本性挑战

1. **可扩展且稳定的黑盒 RL 基础设施**：通用智能体任务需要专用、有状态的环境，大规模并发回放对执行基础设施提出高要求；长时程任务中运行时延迟和故障会累积并使整个轨迹失效。
2. **从碎片化黑盒轨迹中进行高效策略优化**：黑盒 harness 暴露的是碎片化、分叉、冗余的模型调用而非完整轨迹，难以直接用于 RL；不透明内部操作还会放大训练-推理不一致性，导致训练不稳定。
3. **跨异构 harness 的可扩展性**：不同 harness 的交互协议、工具接口、上下文管理差异很大，需要一种能统一支持多种 harness、且无需大量系统特定改动的框架。

## 2. 方法论

### 核心思想

论文提出一个**统一的黑盒强化学习框架**：将 harness 视为不透明"黑盒"回放引擎，在模型服务边界捕获模型调用，通过前缀树重建训练轨迹，并适配 PPO 和 GRPO 两种主流 RL 算法进行优化。框架的核心设计理念是**解耦策略优化与 harness 执行**。

### 关键技术细节

#### (1) 基于沙箱的并发执行基础设施

- 每个任务环境与对应 harness 封装在**临时沙箱**中，按需创建、完成后销毁，提供隔离的工作空间，支持大规模并发回放。
- 沙箱内通过 **MCP（Model Context Protocol）服务器**暴露通用能力（如网页搜索）和任务特定工具，无需修改 harness 原生工作流。

#### (2) 服务代理（Serving Proxy）捕获模型调用

- 在模型服务边界放置代理作为 harness 使用的模型端点。每个模型请求经过代理时，记录精确的输入 token、生成 token、回放 log 概率和任务元数据。
- 只捕获模型侧信息，不侵入 harness 内部逻辑。

#### (3) 前缀树（Prefix Tree）构建

- 将一次回放中捕获的模型调用 $C = \{(x_i, y_i)\}_{i=1}^m$ 组织成**逐回放前缀树**，重建共享交互结构。
- 每个调用附加到历史累积信息为 $x_i$ 最长前缀的现有节点上；通过子调用输入与父历史、父响应的对比，恢复 harness 引入的非模型内容（工具输出等）。
- 每个从根到叶的路径定义一条候选多轮轨迹。共享前缀仅存储一次，不同延续作为独立分支保存。

#### (4) 轨迹提取与过滤

- **移除死叶（Dead Leaves）**：推理服务器重试或 harness 重新生成无效响应会产生被取代的尝试，这些尝试构成死叶，予以丢弃。
- **丢弃过度分叉任务**：叶子数量超过预设阈值时丢弃整个回放，防止噪声信号进入梯度更新。
- **排除辅助轨迹**：子代理（subagent）和上下文压缩（compaction）轨迹被排除，因其角色与主任务求解不同，广播相同终局奖励会造成模糊的信用分配。

#### (5) 树结构上的策略优化

**GRPO 的适配**：同一任务的 $n$ 次回放构成一个组，按组统计归一化奖励得到优势：

$$\hat{A}_i = \frac{R_i - \mu_q}{\sigma_q + \varepsilon}, \quad \mu_q = \frac{1}{n}\sum_{j=1}^n R_j, \quad \sigma_q = \sqrt{\frac{1}{n}\sum_{j=1}^n (R_j - \mu_q)^2}$$

每个回放的优势一次性计算，分配给该回放保留轨迹覆盖的所有可训练 token 节点，共享前缀中的 token 只贡献一次 loss。

**PPO 的适配**：采用简化变体，设 $\gamma=1$、$\lambda=1$，同一回放内各轨迹独立处理，不回传跨分支信号。此时 GAE 退化为：

$$\hat{A}_t = R_i - V_\phi(s_t)$$

优点只与最终奖励和当前状态的价值估计有关。

#### (6) 训练-推理一致性保障

- **黑盒 token-in-token-out 纪律**：推理引擎生成的 token 直接移植到前缀树作为唯一训练数据来源；harness 收到的结构化文本仅从这些 token 解码出来供 harness 执行，绝不重新编码回训练轨迹。
- **Token 级重要性采样校正**：由于推理引擎与训练引擎的数值精度、内核、并行化不同，同一 token 在回放和训练时计算的概率存在差异。用以下权重缩放每个训练 token 的 loss：

$$w_t = \min\left(\exp\left(\log \pi_{\text{old}}(a_t|s_t) - \log \pi_{\text{rollout}}(a_t|s_t)\right), \bar{c}\right)$$

其中 $\bar{c}$ 为截断阈值，控制极端比率的方差。

#### (7) 混合 harness 训练（Mix-Harness Training）

- 每个"任务- harness 对"构成一个基本训练实例。
- 同一任务与不同兼容 harness 配对，产生多个训练实例，在训练批次内随机混合。
- 优势归一化按**任务- harness 对**分组而非仅按任务分组，防止不同 harness 的交互模式与奖励分布扭曲相对优势估计。

#### (8) 工程保障措施

- **稳健沙箱执行与故障处理**：超时强制终止、显式沙箱故障丢弃（不参与优势估计与优化）。
- **缓冲伪流式解析**：生成时缓冲输出 token，持续发出合成 SSE 保持流连接，回合完成后用非流式解析器一次性解析，消除增量解析错误。
- **完整轨迹捕获（Settling）**：等待记录数在多轮检查中不再变化且无待处理记录后再组装轨迹，防止不完整轨迹。

## 6. 主要结论与发现

1. **黑盒 RL 带来实质性性能提升**：在 Qwen3-30A3B 骨干上，ClawII-OC 和 ClawII-CC 在 ClawGym-Bench 分别比初始策略提升 **9.98** 和 **14.81** 个点；在 PinchBench 提升 **11.71** 和 **17.28** 个点。ClawII-OC-30A3B 还超过 ClawGym-30A3B SFT 基线 5.80 个点。

2. **跨异构 harness 效果一致**：黑盒 RL 在 OpenClaw 和 Claude Code 两种结构迥异的 harness 下均有效，30A3B 模型在两个设置下分别超越 Qwen3-235A23B 达 8.14 和 6.28 个点。

3. **训练稳定性良好**：PPO 和 GRPO 均在约 200-400 步内保持稳定优化，训练奖励与评估性能均呈上升趋势。

4. **混合 harness 训练可行**：单模型可通过异构 harness 联合优化，混合模型评估表现与单 harness 训练相当或略优，无系统性性能退化。

5. **框架可扩展到更难任务**：Claude Code 下黑盒 RL 将 JobBench-Easy 从 20.46 提升至 27.20，OfficeQA-Full 从 8.53 提升至 21.54。

6. **冷启动具有正面价值**：轻量冷启动提供更好的行为先验，训练轨迹更平滑、熵更稳定、下游表现更强；但非必需，直接 RL 也有效。

7. **黑盒 RL vs 白盒 RL**：白盒 AgentLoop RL 在同框架下评估更强（59.90 vs 51.37），可迁移到黑盒 harness（50.33 vs 45.11），但不及直接在黑盒 harness 下训练的效果（62.62），表明训练-部署 harness 的一致性很重要。

## 7. 优点

- **问题选择精准**：切入现代 agent 系统面临的真问题——生产级 harness 的黑盒化与复杂化使传统 RL 训练方法失效，论文给出了系统性的解决方案。

- **框架设计优雅且模块化**：沙箱隔离 → 服务代理捕获 → 前缀树重建 → 树结构优化 → 混合 harness 训练，每一层封装清晰、解耦彻底。将 harness 内部逻辑完全视为黑盒，是工程上的务实选择。

- **工程细节扎实**：token-in-token-out 纪律、token 级重要性采样校正、缓冲伪流式解析、settling 机制等，从多个角度保障训练-推理一致性，处理了真实黑盒场景中"看不见摸不着"的陷阱。

- **算法适配有理论自觉**：将 GRPO 和 PPO 适配到树结构时，明确讨论了共享前缀去重、优势估计的简化假设及其代价，并给出未来改进方向。

- **实验验证全面**：覆盖两个主流 harness、两个模型规模、两种 RL 算法、混合训练、跨任务迁移、冷启动消融、白盒对比，层次丰富。

- **混合 harness 训练开创性强**：证明异质 harness 可以联合优化单一模型，这是向"训练系统与部署系统解耦"迈出的重要一步。

## 8. 不足与局限

- **算力细节缺失**：未报告 GPU 型号、数量、训练时长、成本等关键资源信息，第三方难以评估该框架的实际工程门槛。

- **统计严谨性不足**：未提供多次运行的方差/置信区间，部分性能提升可能不具统计显著性；论文也仅报告 Pass@1 单一指标。

- **初始化不一致问题**：ClawII-OC 与 ClawII-CC 的初始化策略不同（一个有冷启动、一个无），影响两者性能对比的归因清晰度。

- **数据污染风险未完全排除**：训练数据来自 ClawGym-SynData，评估集为 ClawGym-Bench，两者同源；论文未详细阐述去重或防止数据泄漏的机制。

- **PPO 适配方案较为粗糙**：采用 $\gamma=1, \lambda=1$ 的简化 GAE，将同一回放内的轨迹视为独立处理，作者也承认这增加优势方差。树结构上更 principled 的信用分配仍待开发。

- **辅助轨迹被排除**：子代理和上下文压缩轨迹被过滤掉，但作者明确说明未来工作将探索纳入这些信号，当前版本可能损失了部分有价值的训练信息。

- **应用限制**：框架依赖 MCP 标准化接口，对不支持 MCP 或高度定制化的 harness 可能需要额外适配工作；沙箱基础设施本身也有运维成本。
