## 摘要
基于大型语言模型的多智能体系统通常以文本形式（即离散标记）进行通信。然而，文本引入了离散瓶颈。将发送方的连续隐状态转换为离散标记会丢失标记身份无法捕获的信息。最近的工作提出了潜在通信作为替代方案，即智能体直接传输隐表示而不将其转换为文本。然而，现有的潜在方法要么在Transformer中逐层注入工作记忆，要么需要训练投影器从而限制可移植性。我们提出了StateBridge，一种无训练的潜在通信方法，通过闭式正交变换将发送方的最终层隐状态对齐到接收方的输入空间。轻量级范数校准和词汇表锚定确保与预训练输入分布的兼容性。对齐后的状态作为连续前缀添加到接收方智能体的输入中。我们在数学推理、代码生成和问答任务上，使用来自两个家族的四种模型评估了StateBridge。StateBridge在26个模型-任务对中的22个上取得最佳或并列最佳分数，始终优于最强基线。

## Abstract
Large language model based multi-agent systems usually communicate in text, i.e., using discrete tokens. However, text introduces a discrete bottleneck. Converting the sender's continuous hidden states into discrete tokens discards information that token identities alone cannot capture. Recent work proposes latent communication as an alternative, where agents transmit hidden representations directly without converting them to text. However, existing latent methods either inject working memory layer by layer across the transformers, or require trained projectors that limit portability. We propose StateBridge, a training-free latent communication approach that aligns the sender's final-layer hidden states to the receiver's input space via a closed-form orthogonal transformation. Lightweight norm calibration and vocabulary anchoring ensure compatibility with the pretrained input distribution. The aligned states are prepended to the input of the receiver agent as a continuous prefix. We evaluate StateBridge on math reasoning, code generation, and question answering with four models from two families. StateBridge achieves the best or tied-best score on 22 out of 26 model-task pairs, consistently outperforming the strongest baseline.

## 1. 核心问题与研究动机

### 背景与问题
- **文本通信的离散瓶颈**：传统LLM多智能体系统通过自然语言（离散token）通信，发送方需将连续隐状态压缩为token序列，这一过程**不可逆地丢失了连续表示中的细粒度信息**（置信度、备选推理路径等）。
- **现有潜在通信方法的缺陷**：
  - KV-cache传输方法（如LatentMAS、Cache-to-Cache）在**所有Transformer层注入内部处理状态**，而非消息的紧凑表征，且对模型架构敏感（实验中在OLMo3上性能崩溃）。
  - 基于嵌入的方法（如Interlat、ThoughtComm）依赖**训练投影器**，将方法绑定到特定模型和任务，缺乏可移植性。

### 核心研究问题
> 能否**仅通过对齐**（无需训练、无需架构修改）解决最终层隐状态与输入嵌入空间之间的表示失配，使现成的LLM智能体能够通过连续表示进行有效通信？

## 2. 方法论：StateBridge

### 核心思想
- 潜在通信要有效，传输的状态必须同时满足两个条件：
  1. **信息丰富**：保留发送方隐状态中的连续信息；
  2. **输入兼容**：与接收方预训练时读取的输入嵌入空间的几何分布一致。
- 关键洞察：闭式对齐变换本身即可弥合最终层隐状态与输入嵌入之间的差距，无需任何可学习参数。

### 技术流程（三步对齐接口）

**消息提取（Message Extraction）**
- 保留生成消息的最后K个token的最终层隐状态：S ∈ R^{K×d}（K=64）
- 提取对应token在嵌入矩阵W_emb中的嵌入作为参考目标：R = W_emb[y]
- 丢弃模型推理过程（如Qwen3的`<think>`段）的隐状态

**步骤1：Procrustes对齐（保几何结构）**
- 中心化：去除两组点云的全局偏移
- 白化：Σ_S = S_c^T S_c/K + λI，将各主方向方差归一化，防止高方差方向主导对齐
- 求解正交Procrustes问题：Q* = argmin ||S_w Q - R_w||²_F，约束Q^T Q = I
- 闭式解：对S_w^T R_w做SVD = UDV^T，则Q* = UV^T
- 重构：S̃ = S_w Q\* Σ_R^{1/2} + 1_K μ_R^T
- **核心性质**：Q*为正交矩阵，严格保持白化空间中点对之间的欧氏距离和内积（Gram矩阵不变），即语义相似性关系在变换中不丢失

**步骤2：范数校准（Norm Calibration）**
- 问题：最终层隐状态范数远超输入嵌入（Qwen3-4B中约为140倍），会主导注意力分数
- 操作：将每个对齐向量缩放到词汇嵌入的平均L2范数：ŝ_i = s̃_i · n̄/||s̃_i||₂

**步骤3：词汇锚定（Vocabulary Anchoring）**
- 操作：将每个校准向量轻微移向其余弦相似度最高的词汇嵌入：s̄_i = (1-α)ŝ_i + αW_emb[v*_i]，α=0.3
- 作用：不将连续向量离散化为token，而是使其靠近预训练中见过的嵌入区域，确保可读性

**前缀注入（Prefix Injection）**
- 对齐后的前缀直接拼接到接收者的prompt嵌入之前：X = [S̄; P]
- 位置索引顺序分配，接收方无需任何架构或注意力掩码修改

### 计算复杂度
- 时间复杂度：白化O(d³) + 词汇锚定搜索O(KVd)，均**低于单次自回归生成的一步代价** O(TLd²)
- 空间复杂度：仅存储最终层K个隐状态O(Kd)，远低于KV-cache方法O(TLd)

## 6. 主要结论与发现

1. **StateBridge在26个模型-任务对中的22个上取得最佳或并列最佳**，平均分比最强基线提升2.4~2.9个百分点，且跨两个模型家族一致有效。

2. **跨架构鲁棒性**：OLMo3-7B-Think上，LatentMAS平均仅55.1%（低于TextMAS的73.9%），而StateBridge达到76.7%。证明仅操作输入嵌入层的对齐方法比逐层KV注入具有更强的架构适用性。

3. **挑战性任务收益更大**：在MedQA、GPQA、AIME24/25和代码生成等需要深度推理的任务上提升最明显（最高达+7.0点），说明任务越难，文本通信丢失的信息越关键。

4. **几何保持是关键**：用岭回归替换Procrustes使平均分从82.4%跌至74.9%（代码任务降幅最大），验证了正交变换对语义几何结构的保留是有效核心。附录A.2的数学证明进一步揭示：岭回归将前缀约束在token嵌入张成的低维子空间内，本质上仍受离散瓶颈限制。

5. **兼容性步骤不可省略**：去掉范数校准（↓2.9）或词汇锚定（↓2.2）均造成性能下降，说明对齐加上兼容性校准共同构成有效通信。

6. **案例研究证实信息增益**：在MedQA案例中，批评者仅从对齐前缀中恢复了"koilonychia"（精确医学术语），该词未出现在可见的后缀token中，证明前缀携带了超越离散token的连续语义信息。

## 8. 不足与局限

### 方法层面
- **同构模型假设**：目前仅支持共享同一权重和词表的同质智能体系统，不支持异构模型之间的潜在通信
- **固定前缀长度**：K=64对所有任务一刀切。案例研究显示K=128时对齐质量下降（全局旋转需在更异构的点集上妥协），但论文未提出自适应长度策略
- **无训练但需要标定数据**：Procrustes对齐需要同一消息的token嵌入作为参考目标，本质上是利用接收方的嵌入表进行在线校准，对嵌入层质量有一定的依赖

### 实验层面
- **评估偏差风险**：超参在单一配置（MedQA/Qwen3-4B）上选取后固定，可能对其他设置非最优（如表3显示α=0.4在HumanEval+上更好）
- **统计显著性未报告**：无方差、置信区间或多次运行的标准差，AIME等小样本数据集上的差异（如3.3点）可能不显著
- **未测试异构通信场景**：发送方与接收方权重不同时方法尚未验证（论文未来工作有提及但未实验）
- **GSM8K上对Qwen3模型的退化**（↓2.5~2.6点）未深入解释，作者归因于格式化干扰但缺乏消融验证

### 应用层面
- **安全性未讨论**：连续向量的可解释性远差于文本，缺乏审计性和可验证性
- **实际部署的工程挑战**：需要反向钩子提取隐状态、自定义嵌入级推理管线，对推理框架有特殊要求
- **潜在信息泄漏**：如果连续前缀保留了过多的发送方内部推理信息，可能带来隐私或安全风险
