## 摘要
准确且负责任的医学问答（QA）在医疗保健中至关重要，因为复杂病例需要事实知识和细致推理。现有的医学问答系统通常基于单智能体架构和静态检索，往往缺乏适应性、持久记忆和结构化决策。本研究引入了一种自适应记忆与反思（AMR）智能体系统，这是一个多智能体框架，其中专门智能体使用专用记忆和基于反思的反馈来检索相关既往病例并改进后续推理。复杂度评估将问题路由至独立、协作或升级工作流，而共识与伦理监督模块支持推理整合和输出审查。在MedQA和MedMCQA上的评估显示，与若干基线相比，该系统表现强劲。消融研究表明，结合智能体特定记忆、反思和外部检索可获得最佳性能。这些发现凸显了结构化记忆和反馈在开发更可信的医学智能体方面的潜力。源代码公开于https://github.com/mm-air/AMR-Agent。

## Abstract
Accurate and responsible medical question answering (QA) is important in healthcare, where complex cases require factual knowledge and nuanced reasoning. Existing medical QA systems, typically based on single-agent architectures and static retrieval, often lack adaptability, persistent memory, and structured decision-making. This work introduces an adaptive memory and reflection (AMR) agentic system, a multi-agent framework in which specialized agents use dedicated memory and reflection-based feedback to retrieve relevant prior cases and improve subsequent reasoning. Complexity assessment routes questions through solo, collaborative, or escalated workflows, while consensus and ethical overseer modules support reasoning consolidation and output review. Evaluation on MedQA and MedMCQA demonstrates strong performance compared with several baselines. Ablation studies show that combining agent-specific memory, reflection, and external retrieval yields the strongest performance. These findings highlight the potential of structured memory and feedback for developing more trustworthy medical agents. The source code is publicly available at https://github.com/mm-air/AMR-Agent.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：医学问答（Medical QA）需要同时具备事实知识和细致推理，尤其是复杂病例。然而，现有医疗QA系统大多基于**单智能体架构**和**静态检索**，存在以下关键缺陷：
  - 缺乏**适应性**：无法根据问题复杂度动态调整推理深度。
  - 缺乏**持久记忆**：无法从过去的错误中学习，难以积累经验。
  - 缺乏**结构化决策**：不透明、不可控，缺少显式的伦理审查机制。
- **研究意义**：该论文旨在解决上述问题，通过构建多智能体协作框架，将医疗QA视为一个**结构化推理流水线**而非单一提示任务，从而提升准确性、适应性和可信度。
- **整体含义**：提出了名为 **AMR（Adaptive Memory and Reflection）** 的智能体系统，集成了角色专属记忆、反思反馈、复杂度感知路由和伦理输出筛选，为可信医疗QA提供了一种新的系统性解决方案。

## 2. 论文提出的方法论

- **核心思想**：借鉴临床团队协作流程，采用多智能体分工协作；利用**图编排（LangGraph）** 实现动态路由和状态管理；通过**角色专属记忆**和**反思反馈循环**实现持续学习和推理改进。
- **整体架构（AMR流程）**：
  - **Moderator（主持人）**：评估问题复杂度。
  - **Recruiter（招募者）**：根据复杂度将问题路由至三种路径之一：
    - **低复杂度**：由单个普通医生（General Practitioner）直接回答。
    - **中等复杂度**：多智能体协作产生独立意见，再由共识促进者（Consensus Facilitator）总结共识与分歧。
    - **高复杂度**：迭代式分层智能体精炼（草稿生成→评审→改进→最终报告），最后由高级决策者（如首席顾问）选择最优答案。
  - **Summarizer（汇总器）**：将各智能体的推理理由整合为统一解释。
  - **Final Answer Picker（最终答案选择器）**：将解释映射为最终选项。
  - **Ethical Overseer（伦理监督者）**：在输出发布前审查候选回答，标记是否包含不安全内容（如直接诊断、有害建议、超范围治疗推荐），输出为APPROVED或FLAGGED，并记录理由供审计。
- **角色专属记忆与反思**：
  - 每个智能体维护**独立记忆**，而非共享单一存储。记忆条目包含：问题上下文、答案、事后笔记、角色元数据和时间戳。
  - **反思循环**：仅当预测答案与真实标签不一致时触发。系统为每个团队成员生成角色特定的反思条目（包含纠正性反馈），存储到对应记忆中，用于改善未来的检索——不更新模型参数，而是更新记忆库。
  - **算法流程（Algorithm 1）**：遍历每个问题 → AMR系统输出答案 → 与真实标签比较 → 若错误，则向团队中每个智能体的记忆添加反馈条目 → 继续下一个问题。
- **技术细节**：
  - 检索：FAISS作为持久向量库，使用text-embedding-3-large对智能体记忆嵌入并做语义检索，每个智能体检索最相似的top-5历史案例。
  - 实现：基于LangGraph的图执行流水线，输入输出为JSONL格式，使用GPT-4o（通过OpenAI API）作为基础LLM。
  - 防泄漏：测试问题、预测和反思反馈均未写入持久记忆；检索语料在评估前构建并保持冻结。

## 6. 主要结论与发现

- **组合最佳**：完整AMR（记忆 + 反思 + RAG）表现最强，在MedQA上达到 **93.2%**，在MedMCQA上达到 **90.0%**，显著高于Baseline（80% / 78%）。
- **组件互补**：消融实验显示，单独加入反馈（82% / 80.4%）或记忆（86% / 82%）均有提升，去掉RAG后降至90% / 87.4%，证明记忆、反思与外部检索三者具有互补增益。
- **复杂度感知路由有效**：AMR在不同复杂度问题上均达到约0.85以上准确率，在中等复杂度问题上平均准确率最高且标准差最低（归因于多智能体协作和迭代讨论）。
- **系统级设计的重要性**：将医疗QA视为结构化流水线（复杂度评估、协作推理、筛选）比单一大模型提示更有效，有助于提升可解释性和可控性。

## 7. 优点

- **方法创新**：提出了角色专属记忆与反思反馈相结合的多智能体框架，优于单一共享记忆和静态检索。
- **动态路由**：根据问题复杂度选择不同的推理深度，避免对所有问题采用同样的计算开销，兼顾效率与效果。
- **伦理审查显式化**：将输出安全筛选作为独立阶段（Ethical Overseer），使政策决策可检查，提升了可信度。
- **模块化设计**：基于LangGraph的图编排使每个智能体职责清晰，具有可扩展性和可解释性。
