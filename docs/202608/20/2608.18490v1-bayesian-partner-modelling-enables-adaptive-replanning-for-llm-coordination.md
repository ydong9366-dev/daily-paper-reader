## 摘要
多智能体大语言模型（LLM）系统往往难以与策略在任务中途发生变化的新队友协作。由于智能体执行多步骤或时间上扩展的技能，它们常常在公开证据表明伙伴已改变技能后，仍长期继续执行过时的计划。现有方法要么将伙伴跟踪视为被动上下文——使智能体意识到变化但行动迟缓——要么不加区分地重新规划。我们提出了BayesBeliefAgent，它将分层LLM规划器与贝叶斯跟踪模块相结合。我们的智能体并非持续重规划，而是仅当伙伴的行为直接与推断出的技能相矛盾时，才中断当前技能。除了标准奖励之外，我们使用重规划效率和信念-行动差距来评估性能：即在具有正确伙伴估计的智能体执行非互补技能的总决策中所占的比例。在基准Overcooked环境中，矛盾触发控制显著缩小了这种信念-行动差距，同时所需的重新规划次数比启发式方法少一个数量级。

## Abstract
Multi-agent Large Language Model (LLM) systems often struggle to collaborate with new teammates whose strategies shift mid-task. Because agents execute multi-step or temporally extended skills, they frequently continue executing outdated plans long after public evidence shows that a partner has changed its skill. Existing methods either treat partner tracking as passive context-leaving the agent aware of the shift but slow to act-or replan indiscriminately. We introduce BayesBeliefAgent, which pairs a hierarchical LLM planner with a Bayesian tracking module. Rather than replanning constantly, our agent interrupts its current skill only when a partner's actions directly contradict the inferred skill. Beyond standard reward, we evaluate performance using replanning efficiency and the belief-action gap: the fraction of total decisions where an agent with a correct partner estimate executes a non-complementary skill. Across benchmark Overcooked environments, contradiction-conditioned control drastically narrows this belief-action gap while requiring an order of magnitude fewer replans than heuristic methods

### 1. 核心问题与整体含义（研究动机与背景）

- **研究问题**：多智能体 LLM 协作系统在面对策略中途变化的队友时，常会持续执行过时计划，即使已有公开证据表明队友技能已改变。这并非由于智能体无法推断队友意图（即"字面心智理论"能力不足），而是由于**未能及时中断并重规划**，导致正确的信念无法转化为互补的行动。
- **核心矛盾**：论文提出"信念-行动差距"（belief-action gap）概念——智能体虽持有正确的队友技能估计，却仍执行非互补或过时的技能。这与 Riemer et al. (2025) 提出的"字面-功能心智理论差距"（literal-functional Theory of Mind gap）一脉相承。
- **现有方法的不足**：
  - 基于上下文的伙伴建模方法（如 ProAgent、Hypothetical Minds）虽能更新信念，但缺乏将信念转化为控制信号的机制；
  - 启发式重规划方法（周期性、事件触发）虽能响应变化，但重规划频率过高、效率低下；
  - 任务级失败信号驱动的重规划不适用——在多智能体协作中，技能可能在任何任务失败之前就已过时。

### 2. 方法论：核心思想、关键技术细节

- **总体架构**：BayesBeliefAgent 由三部分组成：
  1. 分层 LLM 规划器（高层技能选择 + 低层控制器执行）；
  2. 在线贝叶斯伙伴技能跟踪模块（递归更新队友技能的后验分布）；
  3. 信念引导的**矛盾触发式技能中断机制**（只在与推断技能矛盾时才重规划）。

- **贝叶斯信念更新（核心公式）**：
  - 将队友当前技能 `ψjt` 视为隐变量，基于观察历史 `τit` 维护后验 `bt(ψ) = Pr(ψjt = ψ | τit)`；
  - 通过贝叶斯公式递归更新（式 3/6）：

  ```
  bt(ψ) = η · bt′(ψ) · Π π_low(ajl | τil, ψ)
  ```

  其中 `bt′(ψ)` 是平滑初始化的先验（add-α 计数模型，α=1），似然项用自身低层控制器 `π_low` 近似队友行为模型；
  
  - 推理窗口限制为最近 k=10 步，同时保持分段更新以处理技能切换。

- **矛盾检测**：评估新观察到的队友动作在当前 MAP 技能估计 `ψ̂jt−1` 下的似然 `ℓt`，若低于阈值 `θobs=0.04` 则产生矛盾信号 `Ct = 1[ℓt < θobs]`。

- **门控中断条件（式 12）**：

  ```
  Replan_t = Ct ∧ stable(ψ̂) ∧ bt−1(ψ̂) ≥ Γconf ∧ midSkill_t ∧ cooldown_t = 0
  ```

  即：低似然 + MAP 估计稳定（连续 K=3 次更新不变）+ 置信度足够（≥0.65）+ 处于技能执行中 + 不在冷却期（6 步），才触发重规划。

- **重规划流程**：中断当前技能后，LLM 规划器接收最新后验 `bt` 和 MAP 估计 `ψ̂jt`，结合当前可行技能集选择新的互补技能。

- **关键设计洞察**：矛盾信号在信念更新**之前**评估——若先更新后验再判断，后验可能已向新技能偏移，从而无法检测到旧估计被推翻的时刻。同时，该方法不依赖预先知道互补技能是什么，只需检测队友行为与当前稳定估计不一致。

### 3. 实验设计

  - 技能预测准确率（字面心智理论评估）。

  - 四种消融：Full（信念+中断）、No prompt（仅中断无信念提示）、No replan（仅信念提示无中断）、No belief（两者皆无）；

### 6. 主要结论与发现

- **RQ1（协调性能）**：BayesBeliefAgent 在所有布局中优于 LLM 基线（ProAgent 和 Hypothetical Minds），尤其在 Open 和 Ring 布局中对 Group 1/Group 3 伙伴提升最大；但 RL 基线（TALENTS、GAMMA）整体仍强于 LLM 方法，表明底层 LLM 规划器本身仍是瓶颈。
- **RQ2（字面-功能心智理论差距）**：BayesBeliefAgent 与 ProAgent 的技能预测准确率几乎相同（差距 ≤0.01），但信念-行动差距大幅缩小（Open：0.41→0.20；Ring：0.38→0.28），证实准确推断不等于有效协调——必须将信念转化为控制信号。
- **RQ3（后验作为控制信号）**：No prompt 优于 No replan，说明后验作为中断信号比作为提示上下文更有效地改善协调；Full 与 No replan 的对比进一步证实中断机制在保持信念提示不变时仍能降低信念-行动差距（7 个设置中 5 个显著）。
- **RQ4（选择性重规划）**：矛盾触发式中断能以极少重规划次数（多为个位数）达到与通用触发方法（43–169 次/幕）相当的奖励，表明其价值在于**选择性**而非**频率**。
- **总体结论**：协作心智理论应被用于及时的行为变化，而非仅仅作为被动的上下文信息。信念-行动差距是 LLM 协作失败的独立维度，可通过矛盾条件化控制加以改善。
