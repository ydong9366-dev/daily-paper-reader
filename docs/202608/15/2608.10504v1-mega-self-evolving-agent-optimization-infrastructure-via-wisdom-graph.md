## 摘要
随着编码智能体日益承担实现任务，核心挑战从构建单个智能体转向构建一个系统化改进它们的基础设施。当前方法要么优化智能体系统而不积累可迁移知识，要么积累知识却缺乏对其的组合推理，并且缺少一种机制使这些知识通过运行证据自我进化。MEGA（元评估-接地自适应）作为一种自进化基础设施解决了这些空白：每个优化周期产生持久资产，对这些资产的组合推理指导后续优化，运行证据则同时完善累积的智慧和管理该推理的机制。第1层通过行为模式聚类和经验性A/B验证，从智能体会话中提炼可复用智慧，将每个过程转化为持久资产。第2层将这些资产分解为类型化智慧图中的原子性PCR（主-上下文-结果）单元，并进行演绎、溯因和归纳推理以扩展隐含关系；随后通过组合检索组装上下文特定的执行计划，该检索能呈现仅靠嵌入相似性无法触及的桥接知识。第3层在异构智能体工作流（代码节点、LLM调用和使用工具的智能体）上执行多智能体协作优化，通过受控评估消除数据方差，将改进效果归因于特定的策略变化。从第3层反馈的证据驱动管理智慧组合的策展策略以及跨运行累积的优化轨迹的自我进化。其结果是：优化智能体系统与进化指导优化的知识成为同一个过程的基础设施。

## Abstract
As coding agents increasingly handle implementation, the central challenge shifts from building individual agents to building an infrastructure that systematically improves them. Current approaches optimize agent systems without accumulating transferable knowledge, accumulate knowledge without compositional reasoning over it, and lack a mechanism for that knowledge to self-evolve through operational evidence. MEGA (Meta Evaluation-Grounded Adaptation) addresses these gaps as a self-evolving infrastructure: each optimization cycle produces durable assets, compositional reasoning over those assets guides subsequent optimization, and operational evidence refines both the accumulated wisdom and the reasoning that governs it. Layer 1 distills reusable wisdom from agent sessions through behavioral-pattern clustering and empirical A/B validation, transforming each process into a durable asset. Layer 2 decomposes these assets into atomic PCR (Primary-Context-Resultant) units within a typed Wisdom Graph and performs deductive, abductive, and inductive reasoning to expand implicit relations; it then assembles context-specific execution plans through compositional retrieval that surfaces bridging knowledge unreachable by embedding similarity alone. Layer 3 performs multi-agent collaborative optimization over heterogeneous agent workflows (code nodes, LLM calls, and tool-using agents), attributing improvement effects to specific strategy changes through controlled evaluation that eliminates data variance. Evidence fed back from Layer 3 drives the self-evolution of both the curation strategies that govern wisdom composition and the optimization trajectories accumulated across runs. The result is an infrastructure in which optimizing an agent system and evolving the knowledge that guides optimization are one and the same process.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：编码智能体已大量介入实际开发，但真正瓶颈不再是如何构建单个智能体，而是如何构建一套能够系统化、可持续改进智能体系统的基础设施。当前自动化工具（如 Ralph Loop、DSPy、GEPA、AFlow、Voyager、Reflexion 等）虽然在各自方向上取得进展，却存在三个根本性缺口。
- **三个核心局限**：
  1. **优化过程不积累可迁移知识**：优化器只在单一项目中改进智能体，但"何种策略在何种条件下有效"的因果理由没有被结构化保存，新项目须从零重启策略搜索。
  2. **存储的知识缺乏组合推理**：技能库/记忆系统只做相似性检索，不建模技能之间的依赖、互斥、条件适用等关系，存在"组合性鸿沟"（compositionality gap）。
  3. **知识无法依据运行证据自进化**：即使有了组合推理，缺乏由优化反馈闭环驱动的验证与修正机制，未经验证或过时的知识会污染检索质量。
- **整体含义**：论文提出 MEGA，将"优化智能体系统"与"演化指导优化的知识"统一为同一个闭环过程，形成一种**自进化基础设施**。

## 2. 方法论：核心思想、关键技术细节与流程

- **总体架构（三层循环）**：
  - 第 1 层（会话智慧生成）：从原始智能体会话中蒸馏可复用智慧。
  - 第 2 层（智慧推理与策展）：将智慧分解为原子 PCR 单元，构建类型化智慧图，并进行组合推理和组合检索。
  - 第 3 层（评估驱动优化）：对异构工作流进行多智能体协同优化，产生证据反馈回第 2 层，驱动策展策略与优化轨迹的自我进化。
- **第 1 层关键细节**：
  - 客户端隐私过滤后，先做领域预聚类，再用 BIRCH 聚类（CF = (N, LS, SS)，线性加性合并，半径阈值判据）进行单遍 O(n) 行为模式发现。
  - LLM 综合生成智慧候选，经结构过滤（哈希去重、冲突检测、跨运行语义去重）。
  - **行为级 A/B 验证**：对每个候选构造 teacher-student 测试集，在"注入智慧 vs 基线"两种条件下并行执行，比较准确率提升与 token 成本变化，作为接受/拒绝的 ROI 依据。
- **第 2 层关键细节**：
  - 安全审查门控：检测指令级（prompt 注入/流程劫持）与执行级（数据外泄/破坏性代码）威胁。
  - **PCR 分解**：每个智慧资产分解为原子三元组 ω = (vP, vC, vR, m)，即 Primary（核心动作）、Context（适用条件）、Resultant（预期结果）、Method（实现方法）。
  - **角色流动节点池**：同一概念在不同三元组中可分别充当 P 或 C，降低节点数并形成跨技能连接。
  - **双轴因果评分**：每条边带有 Sufficiency/Necessity 分数 σ(e) = (S(e), N(e)) ∈ [0,1]²，受 Pearl 因果理论启发。
  - **三类逻辑推理**：
    - 演绎（Deduction）：P→C 且 C→R 时传递推出 P→R，多跳乘法衰减抑制假阳性；
    - 溯因（Abduction）：当 P→R 与 C→R 共享结果时，利用高必要性分数反推隐藏的 P→C 关系；
    - 归纳（Induction）：多个 P 同时连接同一 C 和 R 时，用超几何检验判断 C→R 是否统计显著。
  - **PCST 组合检索**：将检索建模为 Prize-Collecting Steiner Tree 问题，在无向投影图上求含种子节点及低相似度但关键的"桥接节点"的连通子图。
  - **基于 ROI 的策展与自我进化**：预测效用、逐步聚合、自适应门控（冷启动/热启动切换）、四轴复合评分、组合模式晋升、内容级演化触发、离线模式整合。
  - **Wisdom 维护**：PCR 去重、矛盾消解（极性分析 + 上下文限定）、证据触发的内容更新。
- **第 3 层关键细节**：
  - 优化目标不是单个 prompt，而是异构工作流 A = (N, E)，节点类型包括确定性代码节点、单次 LLM 调用节点、使用工具的多轮推理智能体节点。
  - **Adapt 流水线**：资产扫描 → 自适应入口 →（条件性）研究智能体 → 逆向 PRD / 数据合成 → 共享优化循环 → 元学习智能体反馈。
  - **多智能体协作**：中心优化智能体统一决策（诊断→假设→修复→测量），科学家、代码审查员、重设计智能体等执行专门任务，避免深层委派带来的上下文稀释。
  - **数据感知优化**：先区分数据缺口与工作流问题，只对真正的覆盖率缺口做条件性合成数据增强（合成比例上限 50%），无缺口则零开销跳过。
  - **Seed-Epoch 机制**：同一 epoch 内所有迭代在固定种子采样的验证集上评估，Δi = Acc(De, vi) − Acc(De, vi−1)，消除数据方差，使性能增益可归因于策略变化；饱和后更换种子验证是否过拟合。
  - **优化保护机制**：反启发式强制（禁止内容感知正则、输入-输出查找表等），过拟合检测（验证集与训练集差距超阈值时限制为仅 prompt 优化），基于可修复性的目标校准。
  - **Verdict 反馈**：每次优化产生多维判定（Δacc, Δlat, Δtok），更新智慧的证据置信度 η(ω) 和历史迁移率 τ(·)，并提取优化轨迹注册回第 2 层。

## 7. 优点

- **闭环完整性**：首次把蒸馏、组合推理、优化归因三个环节统一为自进化循环，而不是碎片化工具组合。
- **原子化知识单元**：PCR 分解使复杂技能可被逐子单元推理，支持跨技能桥接，克服了"整技能编排"的粒度局限。
- **逻辑推理发现隐含关系**：演绎/溯因/归纳不仅检索显式知识，还能生成未记录的关系，并用因果充分性/必要性打分抑制错误推断。
- **严格归因纪律**：Seed-Epoch 固定验证集消除数据方差，Verdict 多维反馈（精度、延迟、token）支持条件化知识积累。
- **数据感知优化**：区分数据缺口与工作流问题，只在真正缺口处做有上限的合成数据增强，避免盲目扩数据。
- **工程健壮性**：行为 A/B 验证、安全审查门控、反启发式强制、过拟合检测、图卫生维护等设计都体现了实用导向。
- **效率优势**：PCST 检索无需 LLM 参与，显著降低策展延迟和 token 开销。
