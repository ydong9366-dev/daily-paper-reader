## 摘要
多无人机协同侦察常常受到间歇性空对空通信的阻碍，其中链路中断导致探索不协调和地图重复构建。现有方法依赖于高维空间数据或原始观测的显式交换，产生显著开销，并且通常在中断期间退化为反应式个体探索。本文提出了一种内存增强框架，其中每架无人机维护一个结构化的潜在状态，分解为地图、任务和内存组件。在中断期间，基于内存状态生成的预测器在潜在空间中推断替代的同伴消息，使估计任务更易处理，并直接与协同目标对齐。该框架在集中训练与分散执行的范式下进行端到端训练。仿真结果表明，所提出的框架在性能上接近全连接蜂群，同时在各种链路故障条件下保持鲁棒性。

## Abstract
Cooperative multi-unmanned aerial vehicle (UAV) reconnaissance is often hindered by intermittent air-to-air communications where link dropouts lead to uncoordinated exploration and redundant mapping. Existing approaches rely on explicit exchange of high-dimensional spatial data or raw observations, incurring significant overhead, and often revert to reactive individual exploration during outages. This paper proposes a memory-augmented framework in which each UAV maintains a structured latent state decomposed into map, task, and memory components. During dropout, a generative predictor conditioned on the memory state infers substitute peer messages in the latent space, making the estimation task more tractable and directly aligned with the cooperative objective. The framework is trained end-to-end under the centralized training with decentralized execution paradigm. Simulation results demonstrate that the proposed framework closely matches the performance of a fully connected swarm, while remaining robust across a wide range of link failure conditions.

## 2. 方法论

### 核心思想
提出一种**记忆增强的潜在状态估计框架**——每架UAV在本地维护一个结构化的潜在状态（隐状态），将协同所需信息压缩为紧凑的、任务对齐的语义表示，并在通信中断时利用生成式预测器在潜在空间中推断缺失的聚合同伴消息，而非在原始观测空间中做昂贵重建。

### 关键细节

1. **潜在状态三分量分解**
   - **地图状态 μᵢₜ**（语义表示）：压缩估计全局地图 M̂ₜ，由循环函数 E_φ 更新，并与解码器 D_η 联合训练以保证可解码回 M̂ₜ，满足"语义"判据（有外部指称和显式失真度量）。
   - **任务状态 τᵢₜ**（任务导向）：编码UAV运行状态与蜂群协调状态，由 F_θ 更新，驱动策略网络选动作。
   - **记忆状态 ρᵢₜ**：由 G_ψ（门控循环单元）递归累积观测、任务状态与历史通信，形成预测缺失消息所需的上下文条件。三者维度均为512。

2. **消息聚合**：每架UAV广播 z = [μ; τ]；接收方以均值池化聚合邻居消息，m = mean(z_j)，其参数少、排列不变，自然分解为地图分量 m^μ 和任务分量 m^τ。

3. **记忆生成式预测器**：当Nᵢₜ = ∅（无邻居可达）时，条件于记忆状态 ρᵢₜ、最新本地观测 oᵢₜ 和本体状态 eᵢₜ，生成替代消息 m̂ᵢₜ = P_ζ(ρᵢₜ, oᵢₜ, eᵢₜ)。该设计使得预测在低维语义空间中进行，比预测原始高维观测更易处理、更贴近协同目标。

4. **非对称更新策略**：地图状态 μᵢₜ 在中断时以零向量作为m^μ更新输入（不被幻觉污染），而任务/记忆状态接受完整预测消息。这防止了虚假地图信息累积误差。

5. **Actor-Critic架构**：策略 π_ξ(a|τ) 共享参数，映射任务状态到高斯分布的均值和方差采样速度/航向命令；集中式评论家 V_ω(s_t) 估计状态价值，使用GAE计算优势。训练采用MAPPO算法。

6. **端到端联合训练**（CTDE范式）：
   ```
   L = −L_CLIP(ξ) + c₁L_VF(ω) + c₂L_map(φ,η) + c₃L_pred(ζ,ψ)
   ```
   - 地图重建损失（L_map）：D_η(μᵢₜ) 与全局地图估计 M̂ₜ 的Frobenius范数平方；
   - 预测损失（L_pred）：有邻居时刻的预测消息与实际聚合消息的均方误差；
   - 训练中通过链路状态采样模拟dropout（pf=0.3）。

7. **信道模型**：Rician衰落下接收SINR公式 Γ = P·|h|²·d^(−α)·L_atm·ξ / (σ²+I)，链路活跃当且仅当 Γ ≥ β_th。

### 算法流程（文字简述）
每时间步：无人机观测环境 → 接收邻居消息（若有）→ 均值池化聚合 → 若无邻居则生成式预测替代消息 → 依次更新地图状态（非对称保护）→ 更新任务状态 → 更新记忆状态 → 策略根据任务状态输出动作 → 环境转移 → 奖励计算 → 训练时联合优化各损失。

- 消融分析表明：
  - 移除消息预测器是最有害的——覆盖率降至70.30%±3.61%，碰撞增加近6倍（54.90次），甚至**显著劣于完全无通信条件（83.44%）**，证明"以零向量替代缺失消息"会主动误导蜂群；

- 结论：间歇性通信不一定造成严重的性能惩罚，关键在于学习在语义潜在空间中进行预测性协调。

## 7. 优点

- **问题定位精准**：将间歇性连接视为蜂群无人机系统的"预期特性"而非"边缘情况"，抓住了现实部署的核心矛盾。
- **语义潜在表示的引入恰当**：将通信内容压缩为仅含协调相关信息的低维潜在表示，避免了原始观测重建的高昂代价，同时通过解码器与显式失真度量保证了语义内容的客观指称性（严格区分了"语义"与"任务导向"）。
- **非对称更新策略设计巧妙**：地图状态不被预测消息污染、任务/记忆状态接受预测消息，兼顾了地图准确性（防幻觉累积）与决策连续性（保持协调）的双重需求。
- **记忆与预测的耦合机制有效**：将预测条件建立在累计历史（记忆）之上，而非仅依赖瞬时观测，消融实验证实了这一耦合的必要性。
- **CTDE与共享策略的工程合理性**：集中训练利用全局信息稳定学习，分散执行时仅依赖本地信息，符合真实部署；共享策略参数天然支持蜂群规模扩展。
- **MAPPO+多损失联合训练的框架完整清晰**，公式（2）（3）（4）定义严谨，可复现性好。
- **结果具有说服力**：与上界差距<1.5%的性能保留程度在同类研究中表现突出，且消融实验逻辑自洽（预测器移除后性能断崖式下降、甚至低于无通信基线，揭示零填充消息的误导性）。
