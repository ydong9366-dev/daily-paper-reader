## 摘要
现代雷达系统需要根据变化的干扰、杂波和数据可用性调整其处理策略。本文提出了一种由小语言模型（SLM）驱动的自主体框架，用于语言条件认知雷达，作为一套阵列信号处理工具的智能控制器。给定自然语言命令，该自主体提取与雷达操作相关的线索，选择适当的信号处理方法序列，配置参数，并调用可执行工具进行数值计算。使用合成均匀线性阵列（ULA）雷达的实验表明，在给定自然语言命令的情况下，该自主体在旁瓣控制、干扰抑制、多零陷波束形成、相干源处理和低快拍波达方向（DOA）估计等不同场景中执行有意义的算法选择。消融结果表明，雷达特定提示和基于物理的工具执行对于可靠决策和无幻觉数值结果都是必需的。

## Abstract
Modern radar systems require adapting their processing strategies in response to changing interference, clutter, and data availability. This paper introduces a framework for a small language model (SLM)-driven autonomous agent designed for language-conditioned cognitive radar, functioning as an intelligent controller for a suite of array signal processing tools. Given a natural-language command, the agent extracts radar-operation-related cues, selects an appropriate sequence of signal-processing methods, configures parameters, and invokes executable tools for numerical computation. Experiments with a synthetic uniform linear array (ULA) radar demonstrate that, given a natural-language command, the agent performs meaningful algorithm selection across diverse scenarios for sidelobe control, jammer suppression, multiple-null beamforming, coherent-source handling, and low-snapshot direction-of-arrival (DOA) estimation. Ablation results show that radar-specific prompting and physics-grounded tool execution are both required for reliable decisions and hallucination-free numerical results.

## 2. 论文提出的方法论

### 核心架构
系统采用模块化设计，包含两大核心组件：

**（1）物理工具模块（Physics Tools）**

  - **阵列仿真器**：生成窄带 ULA 快照数据，支持多种窗函数（均匀、Dolph-Chebyshev、Taylor 加权）
  - **波束形成工具**：DAS、MVDR、MPDR、LCMV 四种波束形成器，自适应波束形成器支持对角加载
  - **DOA 估计工具**：MUSIC、ESPRIT、OMP 三种算法

**（2）SLM 智能体（推理引擎）**
- 使用 **Qwen3.5 9B 模型的 4-bit 量化版本**，通过 Ollama 本地服务运行
- 属于小型语言模型（SLM），紧凑到可在嵌入式平台（如 NVIDIA Jetson）部署
- 本地离线部署，避免分类或隐私敏感雷达应用中的数据泄露风险

### 关键技术细节

**Agentic 工作流（基于 ReAct 范式）**
- 采用"观察-推理-行动"循环：模型在每轮接收完整消息历史、系统提示和工具结果，可输出推理文本、工具调用或两者兼有
- 循环终止条件：模型产出无工具调用的回合视为最终回答
- 模型**从不直接进行算术计算**——所有数值计算（协方差估计、权重计算、子空间分解）都委托给物理工具，模型只负责决定调用哪个工具、传什么参数，并综合工具结果给出专家级解释

**系统提示词工程（五大组成部分）**
1. **角色定义与行为规则**：定义智能体为"专家雷达阵列信号处理智能体"，规定必须评估算法适用性、禁止手动数值计算、必须使用工具
2. **雷达领域知识嵌入**：编码算法选择先验规则（如"有干扰→仿真ULA建模干扰；有信号自由训练期→用MVDR，否则用MPDR"）
3. **不可违反的物理约束**：瑞利分辨率极限、N-1 源容量、MUSIC 秩条件、无锥削时最小旁瓣级等
4. **推理纪律要求**：每次工具调用前必须有一句显式推理说明观察、所选工具和理由；最终答案必须包含工具输出中的数值结果

**状态管理（RunContext）**
- 工具调用对模型而言是无状态的，但雷达处理循环有天然顺序（仿真→信号处理→分析），因此各处理器共享一个 RunContext 数据结构，在单次调用期间持久化存储数值结果

**智能体循环与恢复机制**
- 最大迭代 8 轮；检测到过早终止（无工具调用且内容为空）时，注入"提醒消息"并重试，成功解决 SLM 长上下文下的过早终止问题

**输出制品**
- 每次运行生成带时间戳的目录：完整决策轨迹 transcript 文件（可审计）+ 波束图和伪谱图；CLI 实时展示决策和工具调用

**可配置性与可扩展性**
- 通过 config.yaml 配置阵列默认值、模型身份、生成参数等；支持任何声明工具能力的 Ollama 托管模型；新增算法遵循"三步模式"：实现数学函数、添加 JSON schema、注册 handler

## 6. 论文的主要结论与发现

### 核心结论
1. **SLM 可以充当可靠的认知雷达控制器**——Qwen3.5:9b 在精心设计的系统提示词和物理工具支持下，能够正确完成 6 类自然语言雷达任务的算法选择和参数配置。
2. **雷达特定提示词与物理工具执行缺一不可**：
   - 去掉雷达提示词后，SLM 无法区分表面上相似但适用条件不同的算法（如 MVDR vs. MPDR），算法选择准确率从 91.1% 降至 67.8%
   - 去掉工具执行后，SLM 虽然能描述正确的算法（选择准确率高达 96.1%），但无幻觉率骤降至 52.8%，端到端成功率仅 52.2%
3. **物理接地有效抑制数值幻觉**：完整智能体的无幻觉率达到 98.9%，最终答案中的数值全部来自工具输出而非模型生成。
4. **规则控制器的天然局限**：基于关键字匹配的规则控制器在改写自然语言和欠指定提示上表现糟糕（算法准确率仅 15.0%），验证了自然语言理解和语义鲁棒性的价值。

### 代表性的物理性能结果
- **旁瓣控制**：Dolph-Chebyshev 锥削能精确满足 -30 dB 旁瓣要求（实现值 -30.00 dB），均匀加权旁瓣仅 -13.15 dB
- **干扰抑制**：MVDR 在单干扰下实现 -81.77 dB 零陷深度且目标增益 0.00 dB；LCMV 在双干扰下实现 -120 dB 零陷
- **DOA 估计**：MUSIC 在充足快拍下 RMSE = 0.000°；ESPRIT 在低快拍（L=10）下 RMSE 仅 0.316°-0.559°；OMP 在单快拍下 RMSE = 2.628°
