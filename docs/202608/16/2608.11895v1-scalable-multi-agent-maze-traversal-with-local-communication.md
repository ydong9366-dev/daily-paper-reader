## 摘要
洞穴网络、管道系统及类似的迷宫环境对未知环境中通信受限的多智能体导航提出了重大挑战。我们提出了一种分布式算法，使智能体能够集体遍历未知且可能带环的图。智能体在指定的起始节点依次进入，任务是在避免碰撞的同时定位并到达一个未公开的目标。它们通过局部通信，利用领导者-跟随者关系和领导者切换进行协调。在任何时刻，仅由其中一个智能体执行探索，该智能体运行单智能体迷宫求解器。我们证明了该算法是完备的，其总完工时间（以智能体数量衡量）渐近等价于最优全知策略，并推导出其时间和空间复杂度。多达625个智能体的模拟显示，随着智能体数量增加，平均总燃料消耗呈下降趋势，并表明所提方法优于所有智能体独立执行单智能体求解器的朴素基线方法。

## Abstract
Cave networks, pipe systems, and similar maze-like environments pose significant challenges for multi-agent navigation in unknown settings with limited communication. We propose a distributed algorithm that enables agents to collectively traverse an unknown, possibly cyclic graph. Agents enter sequentially at a designated start node and are tasked to localize and reach an undisclosed goal while avoiding collisions. They coordinate via local communication using leader-follower relationships and leader switching. At any moment in time, exploration is performed by only one of the agents, which runs a single-agent maze solver. We prove that the algorithm is complete, that its makespan is asymptotically equivalent (in the number of agents) to that of an optimal full-knowledge strategy, and derive its time and space complexity. Simulations with up to $625$ agents show a decreasing average sum-of-fuels as the number of agents increases and demonstrate that the proposed approach outperforms a naïve baseline in which all agents independently execute the single-agent solver.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究问题**：在未知、可能带环（cyclic）的图结构环境（如洞穴网络、管道系统）中，多个智能体仅通过**局部通信**进行协调，从起点依次进入，共同寻找并到达一个未公开的目标节点，同时避免碰撞。
- **难点**：环境未知且逐步揭示；通信距离受限（两跳以内，且消息不能穿过被占用节点）；需要预防顶点冲突和跟随冲突；多智能体协作与单智能体探索之间存在效率与竞争的权衡。
- **现有方法的不足**：单智能体算法（BFS、Trémaux 等）可搜索未知图，但不考虑多智能体碰撞与协调；已有的多智能体图探索研究多侧重穷尽式探索而非寻找目标，且部分不保证无碰撞；MAPF 类方法通常要求已知图或集中式规划；此前针对多智能体迷宫遍历（MAMT）的分布式方法仅支持树形图（acyclic graphs），且缺乏理论保证。
- **本文目标**：提出一种基于局部通信、适用于一般图（含环）的 MAMT 分布式算法，证明其完备性、近似最优性，并验证其可扩展性。

## 2. 方法论

### 核心思想
- **领导者-跟随者机制**：任意时刻只有唯一一个“头智能体”（head）负责运行单智能体迷宫求解器进行探索；其余智能体选择一个领导者进行跟随，形成以头智能体为根的树状领导结构。
- **领导权切换**：当头智能体探测到目标或需要让位时，通过“头消息”将领导权交给其他智能体，避免冲突并维持通信连通性。
- **同步离散时间步**：每个时间步内包括感知、决策、同步移动、移动后感知与消息交换等阶段。

### 关键技术细节
- **三种广播消息类型**：
  1. **状态消息**：每个活跃智能体每时间步发送，包含自身 ID、是否在目标节点、领导者指针。
  2. **竞争消息**：非头智能体发送，包含 ID 和 `competing` 标志，用于在多个跟随者争夺同一节点时协调。
  3. **头消息**：头智能体发送，包含其 ID、`competing` 标志、单智能体求解器状态以及下一时间步的头智能体信息（自身或移交对象）。
- **定向投递（directed cast）**：智能体沿特定边发送消息，可覆盖两跳且中间节点为空的范围；智能体移动后会向原节点方向发送定向消息，让跟随者知道其前一个节点。
- **冲突消解（ResolveConflict）**：非头智能体决定是否竞争移动；若目标节点是领导者前一位置且空闲，则广播竞争消息，在所有竞争者中通过确定性 `Selector` 选出获胜者；获胜者移动并保留领导者，失败者留在原地并改选获胜者为新领导者。
- **单智能体求解器可插拔**：可选用 Trémaux 算法、BFS 或均匀随机游走作为头智能体的探索策略。

### 算法流程（文字说明）
1. 初始化：智能体在起点激活，感知邻接节点；若收到状态消息则选择发送者为领导者，否则成为头。
2. 头智能体：若目标在邻接节点则直接移动过去；否则运行单智能体求解器得到候选节点，若该节点已被占用则移交领导权，否则沿该边定向发送消息并移动。
3. 跟随者：根据领导者位置、头智能体状态与竞争消息，决定移动、保持原位或更新领导者。
4. 移动后：发送状态消息与定向消息，更新通信邻域与领导者前位置信息。
5. 遇到目标后终止，不再发送消息。

## 3. 实验设计

- **仿真环境**：方形网格迷宫（square grid mazes），迷宫边长 $l \in \{5, 15, 25, 35\}$。

- **数据集**：每种组合使用同一组 20 个随机生成的迷宫，共 $4 \times 5 = 20$ 组主要实验组合，每组 20 次随机迷宫重复。
- **超时设置**：$10^4$ 个时间步。
- **对比方法**：
  - 本文方法 MAMT，分别配合 Trémaux 算法、BFS 和均匀随机游走。
  - **全知策略（Full Knowledge）**：智能体已知环境，沿最短路径逐次移动到目标，作为理论上限。
  - **朴素基线（Naïve Baseline）**：所有智能体各自独立运行同一个单智能体求解器，通过固定规则处理目标冲突与目标循环。
- **评价指标**：
  - **Makespan**：所有智能体到达目标所需的总时间步数。

## 6. 主要结论与发现

- **理论结果**：
  - 算法保证任意时刻只有一个头智能体（Lemma 1）；每个非起始节点的首次访问由头智能体完成（Lemma 2）；无顶点冲突和跟随冲突（Lemma 3、Corollary 1）；领导关系始终构成以头为根的入树（Lemma 5）。
  - **完备性**：若底层单智能体求解器完备，则所有智能体最终到达目标。
  - **渐近最优性**：设单智能体首次到达目标邻接节点的时间为 $k_g$，则 algorithm 的 makespan 至多为 $k_g + 2(n-1)$；与全知最优策略的 makespan 之比 $R(n)$ 随 $n$ 增大而趋于 1，渐近等价。
- **复杂度**：空间复杂度 $O(d \min(n, d^2) + \text{solver 空间})$；时间复杂度取决于求解器，例如 Trémaux 为 $O((E+n)\min(n,d^2))$，BFS 为 $O(((V+E)^2+n)\min(n,d^2))$，随机游走期望 $O((V^3+n)\min(n,d^2))$。
- **仿真结果**：
  - 所有 MAMT 实验均无碰撞；Trémaux 和 BFS 版本在所有随机迷宫中成功到达目标。
  - 随着智能体数量增加，makespan 逐渐接近全知策略，平均 sum-of-fuels 显著下降。
  - Trémaux 算法在该任务中优于 BFS，因为回溯更少、探索效率更高。
  - MAMT 在 makespan 和平均 sum-of-fuels 上均优于朴素基线；朴素基线在大规模场景中频繁超时（如 625 个智能体时 BFS 版全部超时）。
