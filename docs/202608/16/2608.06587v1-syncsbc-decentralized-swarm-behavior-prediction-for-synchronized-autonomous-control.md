## 摘要
机器人群体利用许多独立的、感知受限的智能体，无需集中控制即可产生复杂的涌现行为。然而，很少有研究探讨智能体如何仅从局部感知推断群体层面的行为，而这种能力对于检测故障和行为变化至关重要。本文介绍了同步群体行为分类（SyncSBC），它结合了机器学习和分布式共识方面的改进，以完全去中心化的方式对集体群体行为进行分类并同步群体决策。我们证明，SyncSBC实现了高分类精度和低同步延迟，适合实际部署。最后，我们使用SyncSBC在真实机器人上演示了两个有前景的群体应用，表明使用SyncSBC的群体能够准确识别机器人行为中的异常，并自主协调群体行为的集体变化。视频、代码和补充实验可在https://sites.google.com/view/sync-sbc/home获取。

## Abstract
Robot swarms utilize many independent limited-sensing agents to produce complex emergent behaviors without requiring centralized control. However, little research explores how agents can infer swarm-level behavior from purely local perception, a capability critical for detecting faults and behavior changes. In this paper, we introduce Synchronized Swarm Behavior Classification (SyncSBC), which combines improvements in machine learning and distributed consensus to classify collective swarm behavior and synchronize swarm decision-making in an entirely decentralized manner. We show that SyncSBC achieves high classification accuracy and low synchronization delay, making it suitable for real-world deployment. Finally, we use SyncSBC to demonstrate two promising swarm applications on real robots where we show that swarms utilizing SyncSBC can accurately identify anomalies in robot behavior and autonomously coordinate collective changes in swarm behavior. Videos, code and supplemental experiments are available at https://sites.google.com/view/sync-sbc/home.

## 1. 核心问题与研究动机

- **背景**：机器人集群（Swarm Robotics）依靠大量感知能力受限的独立智能体，通过局部交互即可涌现出复杂的群体行为，无需集中控制。这类系统在农业监测、水下监视、搜救和物体运输等场景中具有重要应用前景。
- **核心问题**：现有研究鲜有探讨**智能体如何仅凭局部感知（如距离传感器读数）推断群体层面的行为状态**。这一能力对于检测群体中的异常/故障机器人、感知行为变化并协调群体响应至关重要。
- **现实挑战**：
  - 智能体仅能观察到局部信息，而全局群体状态不可直接获取（部分可观测问题）；
  - 引入通信会带来消息开销、网络拥塞和稳定性问题，因此全局行为感知方法必须在严格的通信约束下运行；
  - 现有方法（如集中式视觉追踪、共识滤波）要么依赖中心系统或全局信息，要么只解决状态对齐而不解决**决策的时间同步问题**。
- **研究问题的形式化**：**如何利用局部感知和有限的去中心化通信，让每个个体智能体准确检测并同步适应群体层面的行为变化？**

## 2. 方法论

### 2.1 整体框架概述
SyncSBC 是一个**双阶段、完全去中心化**框架：
- **阶段一（代理级分类）**：每个机器人使用共享训练的深度神经网络（SBC模型）将自身局域网观察序列映射为群体行为类别的概率分布；
- **阶段二（同步信念形成）**：通过分布式共识机制实现邻居间信念的一致化，并通过同步机制使所有机器人在**时间上对齐**地达成群体决策。

### 2.2 Swarm Behavior Classifier（SBC）模型
- 输入为单个智能体**长度为T的局部观测窗口** `Oi,t ∈ R^(T×d_o)`（如ToF测距传感器的时间序列），输出为M类行为上的概率分布 `p_i(t) = φ(Oi,t)`。
- 训练方式：从多个稳定行为控制器运行中采集数据，每个观测窗口继承所在轨迹的群体行为标签，采用**监督学习**训练。
- 预测平滑：使用**指数加权移动平均（EWMA）** 对原始预测进行时域平滑。
- 架构选择：综合对比6种模型后，**时间卷积网络（TCN）** 在精度、F1分数、Brier分数和期望校准误差（ECE）上均最优。具体结构：5个残差因果Conv1D块（128滤波器，卷积核3，膨胀率{1,2,4,8,16}，dropout 0.2），头部为全局平均池化+全连接层+softmax输出。

### 2.3 阶段一：内部信念形成（Internal Belief Formation）
- 将SBC的连续预测 `P_i(t)` 映射为各智能体的**二元内部信念向量 `b_i(t)`**（每类一位），解决局部最优-M问题的共识。
- 对比了四种候选策略：
  1. **Averaging**：基于邻居平均共识更新信念；
  2. **Entropy-based Fusion**：共享softmax分布中最强选择及其熵（置信度）；
  3. **Neighbor Variance Update**：选取与邻居分歧最小的类别作为信念；
  4. **Sample-and-Hold**：基于事件触发的思想，当自分歧超过阈值时才更新内部估计；所选类别稳定且分歧低时设置内部信念。
- 实验表明 **Sample-and-Hold 性能最佳**，延迟最低。

### 2.4 阶段二：同步（Synchronization）
内部共识虽能达成一致，但缺乏**时间同步**，导致集群中不同机器人可能在不同时间做出决策，产生碎片化决策区域。为此提出两种同步方法：
- **布尔八卦（Boolean Gossip, BG）**：基于流行病式信息传播，机器人通过邻居间随机交互传播内部信念，使用逻辑 **AND** 操作合并信念，并配合轮次序号计数器对齐到共同epoch。优点：同步快；缺点：需要更多通信。
- **集成信念同步器（Integrated Belief Synchronizer, IBS）**：一种新提出的消息捎带同步机制。每个行为类别维护一个字段 `F_k=(τ_k, e_k, M_k)`（token持有者、Lamport风格epoch、支持该行为的成员集合）。机器人合并邻居状态时选择epoch最高的状态，防止分裂决策；仅当token空闲或本地持有时才修改成员集合。优点：通信量大幅降低。

### 2.5 通信压缩——事件触发通信（ETC）
- 取代周期性消息广播：仅在满足条件 `E_i(t) ≥ σ·n_i(t)` 时触发通信（其中 `E_i(t)` 为内部状态分歧，`n_i(t)` 为邻居分歧）。
- 与IBS结合可获得更大的通信节省。

## 6. 主要结论与发现

- **分类准确性**：SBC模型在独立测试数据上达到 **>95%准确率**（论文结论部分），其中TCN架构全指标最优。
- **同步延迟**：仿真中SyncSBC实现 **<1秒**平均同步延迟，对比纯共识方法（Agreement-only）的 **>10秒**延迟；真实机器人上实现 **<3秒**延迟，对比 **>15秒**。
- **内部信念策略**：Sample-and-Hold 延迟最低；Averaging次之。
- **同步方法**：ESB同步延迟最低但通信开销最高；ESI能以显著更少的通信量维持良好同步，尤其适合高密度/大规模集群。
- **规模效应**：增大通信半径和集群规模均可显著改善同步性能。
- **实际应用**：
  - **行为切换**：Pure SH 在连续切换中延迟累积、同步误差大；ESB/ESI能产生清晰可辨识的稳定行为并最小化同步延迟。
  - **异常检测**：SyncSBC使机器人能够进行**实时自评估的异常可能性**估计，单个或两个异常机器人在运行中被快速、准确识别，为自修复提供了基础。

## 7. 方法亮点与优势

- **完全去中心化**：整个流程从感知到决策不依赖任何集中节点或全局状态，适合通信受限的真实环境。
- **模块化设计**：SBC模型和共识策略可独立替换，针对不同应用场景灵活组合（如ESB优先快同步、ESI优先省通信）。
- **局部观测驱动的全局推理**：仅利用单个ToF传感器的时间序列即可预测群体行为，避免了对高分辨率全局视觉追踪系统的依赖。
- **双阶段共识+同步**：将“达成一致”与“时间同步”解耦，明确识别并解决了一个此前被忽视的关键问题——共识的时间碎片化。
- **通信效率**：事件触发机制（ETC）有效减少冗余消息，尤其与IBS结合时通信显著降低，有利于扩展。
- **实际部署验证**：在低成本真实机器人平台上验证了闭环行为切换和异常检测，展示了从仿真到真实的可迁移性。

## 8. 不足与局限性

- **感知模态单一**：仅验证了单ToF传感器的设置。实际复杂场景中，视觉、RGB-D等多模态信息的引入是否仍保持性能未探索。
- **行为类别有限**：仅覆盖3种行为。面对混合、层级或环境依赖的复杂行为，SBC模型的泛化能力有待考证。
- **仿真与真实之间的基础差异**：训练数据来自仿真，地面真值收敛时间依赖人工标注校准的阈值，存在标注主观性和仿真到现实的迁移偏差风险。
- **统计可靠性**：真实机器人实验结果未报告多次重复的均值/方差，降低了结论的稳定性证明力。
- **通信模型简化**：实验隐含假设有界延迟、无丢包和可靠信道，未验证在分组丢失、带宽受限或链路噪声条件下的鲁棒性。
- **同步机制的潜在限制**：IBS在聚集行为中出现多组分裂导致的同步延迟上升；当集群断开时（通信半径过小），同步性能会明显恶化。
- **扩展性验证有限**：最大仅16个机器人，真实部署仅8个，对于数百/数千规模集群的可用性尚无证据。
- **文中未报告算力消耗**，限制了生态成本和部署可行性的全面评估。
