## 摘要
视觉语言模型（VLM）在静态场景中的二维定位、空间推理和基于工具的主体规划方面表现出色。然而，考虑让家庭机器人回答“我的药还在柜子里吗？”答案可能物理上隐藏在一排容器后面，必须先移开这些容器才能看到。在真实世界的杂乱环境中回答此类问题需要在动态场景中进行推理：必须操纵干扰物以揭示被遮挡的物体，并且每个动作都会改变模型必须推理的场景。我们将这一设置形式化为基于操纵的视觉问答（MG-VQA），并引入PROBE，一个在此类任务上对VLM智能体进行基准测试和微调的框架。我们首先开发了PROBE-Sim，一个具有日常物体和配备抓取和推动工具的机器人操作器的高保真桌面模拟器。PROBE-Sim用于创建PROBE-Bench：一个包含150个任务、6种问题类型、覆盖杂乱桌面场景的评估套件，其中VLM在回答前先感知、拾取或推动物体。我们观察到所有前沿VLM的一致趋势：基于工具的主体方法在所有任务类型上均优于其仅感知的基线（平均提高8.0%）。我们进一步设计了PROBE-Agent，一种微调方法，通过混合数据配方从强大的教师基础模型中将成功轨迹蒸馏到较小的开源权重模型，该配方鼓励操纵高效的视觉问答。经过PROBE-Agent微调的模型优于其现成的主体基线（平均提高11.5%），并展示了对未见物体和保留任务的积极泛化。我们通过在真实世界桌面环境中部署PROBE-Agent微调策略来验证模拟到现实的迁移。

## Abstract
Vision-language Models (VLMs) excel at 2D grounding, spatial reasoning and agentic tool-based planning in static scenes. However, consider asking a home robot "Is my medication still in the cabinet?" The answer may be physically hidden behind a row of containers that must first be moved aside. Answering such questions in real-world cluttered environments requires reasoning in dynamic scenes: distractors must be manipulated to reveal occluded objects, and each action changes the scene the model must reason over. We formalize this setting as Manipulation-Grounded Visual Question Answering (MG-VQA) and introduce PROBE, a framework for benchmarking and finetuning VLM agents on such tasks. We first develop PROBE-Sim, a high-fidelity tabletop simulator with everyday objects and a robot manipulator equipped with grasping and pushing tools. PROBE-Sim is used to create PROBE-Bench: an evaluation suite of 150 tasks across 6 question types on cluttered tabletop scenes, where a VLM perceives, picks up or pushes objects before answering. We observe consistent trend across all frontier VLMs: agentic tool-based methods outperform their perception-only baselines (8.0% on average) across all task types. We further design PROBE-Agent, a finetuning recipe to distill successful trajectories from a powerful teacher foundation model to a smaller open-weight model using a mixed data recipe that encourages manipulation-efficient question answering. PROBE Agent finetuned models outperform their off-the-shelf agent baseline (11.5% on average) and demonstrate positive transfer to unseen objects and a held-out task. We validate sim-to-real transfer by deploying PROBE-Agent finetuned policies in real-world tabletop environments.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有的视觉语言模型（VLM）评测几乎都基于静态图像，答案可以从单张图中直接得出。但在真实世界杂乱环境中，许多问题的答案被遮挡物掩盖，需要机器人先通过物理操作（拿起、推开、移走物体）改变场景，才能推理出正确答案。例如“我的药还在柜子里吗？”这类问题，药瓶可能被其他容器挡住。
- **研究空白**：现有具身问答（Embodied QA）多聚焦于导航和观测，而非物理操纵；工具增强的VLM智能体评测也仍假设静态场景。缺少一个将“感知→操作→动态推理→回答”整合为闭环任务的基准和训练框架。
- **论文提出**：将这一设定形式化为 **操纵接地视觉问答（MG-VQA, Manipulation-Grounded Visual Question Answering）**，并构建 `PROBE` 框架（包含模拟器、基准、微调方法三部分），用于评测和训练能够在动态场景中通过物理交互来回答问题的 VLM 智能体。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **整体框架**：`PROBE = PROBE-Sim + PROBE-Bench + PROBE-Agent`。
  - `PROBE-Sim`（模拟器）：基于 PyBullet 实现物理仿真（重力、摩擦、接触、抓取、推动），使用 Blender-EEVEE 渲染 1024×1024 的俯视 RGB 图像。包含 **1,796 个真实扫描的日常物体**（来自 Megapose、Digital Twin Catalogue、BOP 数据集），覆盖 481 个类别；场景含 UR5 机械臂 + Robotiq 2F-140 夹爪、一个用于放置清除物体的收纳篮；桌子纹理从 108 种真实材质中采样；每场景约 15 个物体，紧密分布在一个 50×50 cm 区域内，并经过 30s 物理稳定过程。
  - `Toolshed`（工具库）：为 VLM 智能体提供 5 种工具：
    - 感知类：`perceive scene`（场景图、空间谓词）、`find object`（输出精确 2D 点和掩码）；
    - 操纵类：`grasp and remove`（6-DoF 抓取并移出场景）、`push`（闭夹爪线性推动物体用于清理场景）。
    - 工具具有非零失败率（抓取不可行、分割过/欠分割、接触动力学不确定性），以模拟真实环境中行动的不确定性。
  - `PROBE-Bench`（基准）：包含 **150 个任务、6 种问题类型**，通过算法生成并经人工验证：
    - `Count`（计数）、`Find`（查找并给出2D点）、`Compare`（比较两个匿名物体属性）、`Size`（尺寸判断）、`Reduce`（移除指定数量物体，作为强制操纵控制）、`Beneath`（推理被遮挡物体）。
    - 每个任务有模拟器导出的、与智能体交互无关的 ground-truth 答案，选项为多项选择。
  - `PROBE-Agent`（微调方案）：
    - 使用最强的教师模型（Gemini 3.1 Pro）在 `PROBE-Sim` 中以直接模式和代理模式生成成功轨迹，构成 2,947 条训练样本（训练场景与评测场景的物体和布局不重叠）。
    - 对两个开源小模型进行监督微调（SFT）：**Qwen3-VL-8B** 和 **NVILA-15B**，超参为学习率 2e-5、batch size 32、2 epochs、8×A100 GPU。
    - 训练数据**刻意排除 `Beneath` 任务**，以测试模型能否组合已学技能（命名封面识别、空间接地、移除-观察序列）泛化到新任务类型。
    - 混合直接和代理模式的轨迹，鼓励模型学会“何时应操纵、何时可直接回答”的高效决策。

## 3. 实验设计：使用的数据集 / 场景、基准、对比方法

- **模拟基准**：`PROBE-Bench` 共 150 个任务，每个问题类型 20–30 个任务；所有任务经人工验证是可解的（人类专家上界为 100%）。
- **模型评测**：
  - 5 个专有模型：Gemini 3.1 Pro、Gemini Robotics ER 1.6、GPT-5.4、Opus 4.7、Grok 4.3；
  - 3 个开源模型：Nemotron 2-VL-12B、Qwen3.5-VL-235B-A22B、Gemma-4-31B。
  - 每种模型在两种模式下评估：**Direct VQA**（仅图像+问题）和 **Agentic VQA**（可以调用工具进行感知和操纵）。
  - 每个任务进行 3 次运行，结果报告成功率。
- **微调评测**：对比 `Qwen3-VL-8B` 和 `NVILA-15B` 的 base 模型与 SFT 模型，在 PROBE-Bench 的 150 个任务上评估，并单独报告 held-out `Beneath` 任务表现；参考上界为教师 Gemini 3.1 Pro 的 agentic 表现。
- **真实机器人实验**：使用 **Kinova Jaco** 机械臂，固定前向 RGB-D 摄像头，25 个物体、15 个任务。对比模型：Gemini 3.1 Pro（Direct/Agentic）、Qwen3-VL-8B-Base（Agentic）、Qwen3-VL-8B-SFT（Agentic）。工具库与模拟器相同。

- **充分性评估**：
  - 优点：覆盖专有/开源、大/小模型；任务类型多样；含强制操纵控制（`Reduce`）和保留任务泛化测试；有人工验证保证任务可解性；统计检验增强了结论可信度。

## 6. 论文的主要结论与发现

- **工具访问普遍提升性能**：所有前沿 VLM 的 agentic 模式平均比 direct 模式高 **8.0%**（统计显著）。例如 Opus 4.7 提升 14.4%，Gemma-4 提升 16.0%。说明工具访问对较弱模型帮助更大，起到“均等化”作用。
- **基准远未饱和**：最强智能体（Gemini 3.1 Pro agentic）平均成功率仅 69.2%，在需要精准多步操纵的 `Reduce` 任务上仅有 30.4%，人类专家上限为 100%。
- **工具的帮助有选择性**：当任务指明“操纵对象”（如 Compare、Size）时工具帮助大；当需要智能体自己判断“操纵什么、何时操纵”（如 Count、Reduce）时，错误使用工具的概率增加，甚至会损害表现。
- **SFT 蒸馏有效**：`Qwen3-VL-8B-SFT` 在训练任务上达到 67.8%（base 为 48.1%），`NVILA-15B-SFT` 达到 69.1%（base 为 51.7%），两者均接近或超过教师（67.6%）。对 held-out `Beneath` 任务分别提升 7.6% 和 15.4%，表明技能可组合泛化。
- **模拟到真实迁移可行**：真实机器人上，Qwen3-VL-8B-SFT 成功率从 base 的 34.4% 提升到 70.0%，接近教师 Gemini 3.1 Pro 的 78.9%，且从未在真实数据上微调、相机视角也不同（模拟用俯视，真实用前视）。

## 7. 优点

- **问题定义新颖且具有实际意义**：首次系统性提出“操纵接地 VQA”，将 VLM 评测从静态图像推进到需要主动改变场景的动态闭环。
- **模拟器真实度高**：使用 1,796 个真实扫描物体、真实纹理、高保真渲染和物理仿真，工具调用带有噪声与失败概率，使评测更接近真实部署。
- **基准设计严谨**：任务由算法生成、ground-truth 由模拟器导出、经人工验证；包含强制操纵控制类型（Reduce）和泛化测试类型（Beneath），可定位不同能力缺陷。
- **方法完整闭环**：从基准评测到微调配方，再到真实机器人验证，形成了“评测—训练—迁移”的完整流程。
- **结论可统计验证**：使用 CMH 检验证明工具访问带来的提升不是偶然，增强了可信度。
- **微调配方高效**：只用 2,947 条轨迹、2 epochs 就能让 8B/15B 小模型接近 235B 教师水平，显示数据质量和策略蒸馏的重要性。

## 8. 不足与局限

- **场景和工具受限**：仅覆盖桌面平台、固定机械臂、离散预定义工具库，未扩展到移动操作、多机械臂、更复杂工具或开源工具创建；无法处理工具失败后的自适应恢复。
- **评估场景规模有限**：PROBE-Bench 只有 150 个任务，真实实验只有 15 个任务；物体类别虽多但单场景物体数（15个）和场景复杂度有限。
- **人工验证偏差**：只用单一专家验证任务可解性，可能引入主观偏差；多标注者、多场景多样性可提高任务质量。
- **模型性能仍偏低**：最强模型平均仅 70% 左右，尤其在需要多步精准操纵的任务（Reduce）上成功率低（30%–50%），说明“何时/何处操作”的决策能力仍是瓶颈。
- **SFT 泛化能力有限**：虽然 held-out 任务有提升，但差距仍大（如 NVILA-15B-SFT 的 Beneath 45.8% vs 教师 76.9%），表明稳健的组合技能学习仍是开放问题。
- **真实实验边界**：sim-to-real 验证仅在一个机械臂、一种相机配置、少量任务上完成，未测试多样化真实环境、光照和物体状态的鲁棒性；相机视角变化虽存在但未做系统分析。
- **未报告部分细节**：训练数据生成的算力开销、具体提示模板、工具调用失败率统计、不同随机种子下的方差等未充分披露。
