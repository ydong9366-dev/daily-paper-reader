## 摘要
用户中心的多轮智能体必须根据不断变化的用户意图、积累的工具事实、缺失信息和执行约束，在不断演变的任务情境中采取行动。现有的上下文管理方法改善了过去交互历史的使用，但很少维护一个将事实与任务状态判断区分开的显式情境状态。因此，智能体往往需要从对话痕迹中隐式推断细粒度属性、任务依赖关系和约束满足情况。我们提出意图驱动情境状态（IDSS），一种无需训练的框架，在对话之外维护显式的情境状态。IDSS解析工具返回结果，形成具有来源意识的实体和属性，跟踪用户意图、所需变量、约束和执行状态，并将新事实传播到任务约束上以更新动作可执行性。这使得智能体能够避免不可行动作、推进依赖目标，并无需重复搜索原始历史即可重用相关信息。在八个LLM上对三个交互式基准的实验表明，IDSS提高了任务完成度、偏好引导和交互效率，在多实体协调、用户约束演变和约束感知重规划的任务上尤为明显。消融和错误分析表明，这些改进来源于事实持久化、以意图为中心的状态跟踪和约束建模之间的交互。这些结果表明，对于可靠的用户中心多轮智能体，显式情境跟踪为以历史为中心的上下文管理提供了一种有效替代方案。

## Abstract
User-centric multi-turn agents must act on an evolving task situation shaped by changing user intents, accumulated tool-grounded facts, missing information, and execution constraints. Existing context-management methods improve the use of past interaction history, but rarely maintain an explicit situation state that separates grounded facts from task-state judgments. As a result, agents often need to infer fine-grained attributes, task dependencies, and constraint satisfaction implicitly from dialogue traces. We propose Intent-Driven Situation States (IDSS), a training-free framework that maintains an explicit situation state alongside the dialogue. IDSS parses tool returns into provenance-aware entities and attributes, tracks user intents, required variables, constraints, and execution status, and propagates new facts to task constraints to update action executability. This allows agents to avoid infeasible actions, advance dependent goals, and reuse relevant information without repeatedly searching raw history. Experiments on three interactive benchmarks across eight LLMs show that IDSS improves task completion, preference elicitation, and interaction efficiency, with clear gains on tasks involving multi-entity coordination, evolving user constraints, and constraint-aware replanning. Ablations and error analyses show that these improvements come from the interaction between fact persistence, intent-centered state tracking, and constraint modeling. These results suggest that explicit situation tracking offers an effective alternative to history-centric context management for reliable user-centric multi-turn agents.

## 2. 方法论：核心思想、关键技术与流程

- **核心思想**：提出 **Intent-Driven Situation States（IDSS）**，在对话历史之外维护一个显式、可更新的情境状态，将工具所返回的事实与任务状态判断分离，并通过跨层传播将新事实与约束关联，以决定当前动作是否可执行。
- **形式化定义**：
  - 情境状态记为 \( D_t = (F_t, S_t) \)，其中 \( F_t \) 为事实层，\( S_t \) 为状态层。
  - 智能体的策略由仅依赖历史的 \(\pi(H_t, A)\) 变为情境增强的 \(\pi(D_t, H^{comp}_t, A)\)，其中 \( H^{comp}_t \) 为去除已覆盖信息的紧凑残差历史。
- **事实层（Fact Layer）**：
  - 将工具返回解析为带来源（provenance）的结构化实体集合：\( F_t = \{ e_i = (type_i, id_i, attrs_i, src_i) \} \)。
  - 更新操作为原子操作序列 \(\Delta_t = Parse(o_t)\)，包括 **ADD、UPDATE、DELETE、MERGE** 等，以支持增量更新与冲突消解。
  - 通过按来源可信度排序（工具观测优于智能体推断）、同一类型内新值覆盖旧值来避免幻觉或陈旧信息污染。
- **状态层（State Layer）**：
  - 记录意图集 \( I_t \)、变量集 \( V_t \)、约束集 \( C_t \)。
  - **意图跟踪**：识别显式/隐式目标，为每个意图标注 active / pending / completed / blocked 状态，并根据任务语义与执行前置条件推断意图依赖关系。
  - **变量跟踪**：标注信息槽的来源（askable / retrievable / derivable）及 known/unknown 状态，从而指导下一步是询问、检索还是推导。
  - **约束建模**：将用户偏好、工具前置条件和规则表示为约束，并标注 satisfied / unsatisfied / violated 状态。
- **跨层约束传播（Cross-Layer Constraint Propagation）**：
  - 每当事实层更新属性时，确定性比较约束参数更新约束状态；若约束 violated，则阻塞关联意图并记录事实依据与约束链条。
  - 例如在 τ-bench Airline 任务中，发现 basic_economy 舱位违反修改约束后，自动阻塞 modify_flight、激活 cancel_and_rebook，同时保留用户对托运两件行李的需求。
- **流程总结**：工具返回 → 确定性解析入事实层 → 触发约束传播 → 更新状态层 → 渲染到下一轮 prompt 中（零额外 LLM 调用）。

## 6. 论文的主要结论与发现

- IDSS 在三个基准、八种 LLM 上均显著优于 ReAct 及基线方法，特别是在 **多实体协调、用户约束演变、约束感知重规划** 的任务上增益最明显。
- Fact Persistence（事实持久化）、Intent-Centered State Tracking（意图中心状态跟踪）与 Constraint Modeling（约束建模）三者协同，而非单独贡献。
- 消融实验显示：事实层对 τ-bench 最关键，状态层对 UserBench 最关键，两者对 VitaBench 几乎同等重要。
- 错误分析表明 IDSS 显著降低 **事实遗漏**（14%→8%）和 **缺失信息**（8%→5%）类错误，对约束违反改善较小（约束违反更多源于模型规则理解而非状态缺失）。
- 效率分析显示 IDSS 以**最少交互轮数（7.8 轮）**和**最高的平均性能（50.5%）**达到最佳效果，并保持提示词紧凑。

## 7. 优点

- **方法简洁且无需训练**：IDSS 不依赖任何微调或额外监督，仅通过重构上下文结构即可获得一致提升，易于迁移到不同 LLM 和领域。
- **显式状态设计合理**：分离事实与任务状态判断，提供决策导向的视图，避免模型从冗长历史中反复重构现状。
- **零额外 LLM 调用**：通过确定性解析与 prompt 内状态块实现高效维护，不增加推理成本。
- **跨层约束传播机制新颖**：将事实更新与动作可执行性联动，能主动阻塞不可行路径、激活可行替代方案。
- **实验全面**：覆盖多样化 benchmarks、模型与指标，并辅以消融、错误分析和效率分析，支撑有力。
- **雷达图与效率图展示综合能力**：表明 IDSS 不是偏科的单点提升，而是多项指标上的均衡增强。

## 8. 不足与局限

- **适用范围受限**：IDSS 假定工具返回为可解析为结构化事实的文本字段；对于非文本/多模态/更复杂的工具输出格式，需要额外设计以适应。
- **模拟用户偏差**：实验全部基于 GPT-4.1 用户模拟器，与真实用户的自发表达、纠错和偏好表达存在差异，缺乏真人验证。
- **约束违反改善有限**：错误分析显示约束违反率下降不明显，说明模型规则理解能力仍是瓶颈，而非单纯状态建模能解决。
- **消融仅基于单模型**：消融实验只在 GPT-4.1 上进行，因子贡献在更弱或更不同模型上的推广性未知。
- **确定性解析的脆性**：对工具输出格式多样化或非标准返回，解析器可能失败，影响事实层质量。
- **扩展性问题**：状态块本身随任务复杂度增长可能引入新的上下文压力；论文未深入讨论状态规模极长时的表现。
