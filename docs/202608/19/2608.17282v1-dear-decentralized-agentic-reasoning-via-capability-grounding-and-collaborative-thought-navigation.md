## 摘要
现有智能体推理系统通常依赖中心化协议。这种设计引入了路由瓶颈和静态角色分配，在处理复杂多模态查询时往往失效。我们提出DeAR（去中心化智能体推理），一个从中心控制转向自主对等协作的框架。DeAR基于三种机制：（1）用于查询相关智能体特化的去中心化能力锚定，（2）用于定向对等交互的思维图谱导航，以及（3）用于自适应纠错的拓扑更新。在9个多样化多模态推理和基于文本的QA基准上的评估表明，DeAR持续优于最近的基线方法，验证了智能体之间的去中心化和自适应协作能提升知识密集型推理任务的准确性。源代码将在https://open_upon_acceptance提供。

## Abstract
Existing agentic reasoning systems typically rely on centralized protocols. This design introduces routing bottlenecks and static role allocations that often fail when handling complex multimodal queries. We propose DeAR (Decentralized Agentic Reasoning), a framework that shifts from central control to autonomous peer-to-peer collaboration. DeAR is built on three mechanisms: (1) decentralized capability grounding for query-dependent agent specialization, (2) thought map navigation for targeted peer interactions, and (3) topology update for adaptive error correction. Evaluations across 9 diverse multimodal reasoning and text-based QA benchmarks indicate that DeAR consistently outperforms recent baseline methods, validating that decentralized and adaptive collaboration among agents enhances accuracy in knowledge-intensive reasoning tasks. The source code will be available at https://open_upon_acceptance.

- **核心痛点**：现有智能体推理系统多采用集中式协议，具有以下结构性缺陷：
  - **路由瓶颈**：中心协调器垄断路由与信息聚合，成为性能与可靠性的单点瓶颈；
  - **静态角色分配**：预定义角色标签（如"数学智能体"）与实际能力脱节，在开放场景中易引发能力幻觉；

## 2. 方法论：DeAR 框架

DeAR 将系统定义为 \(S = (Q, A, C, K)\)，其中 \(Q\) 为查询，\(A\) 为智能体集合，\(C \in \mathbb{R}^{N \times N}\) 为动态协作倾向矩阵（Collaboration Propensity Matrix），\(K\) 为知识状态序列。框架包含三个核心机制：

### 2.1 去中心化能力锚定（Decentralized Capability Grounding）

- **替代静态角色**：智能体不再被预分配固定标签，而是基于其底层模型的技术报告/模型卡中可验证的基准数据建立能力画像。
- **五维能力画像**：每个智能体维护能力向量 \(\tau_i = (\tau_i^{cr}, \tau_i^{ea}, \tau_i^{nc}, \tau_i^{fr}, \tau_i^{cm})\)，分别对应常识推理、解释能力、数值计算、事实可靠性和自然语言理解。
- **量化校准**：原始基准分数（如 GSM8K→数值计算、MMLU→常识推理、TruthfulQA→事实可靠性）经 Softmax 归一化（式 3），确保所有智能体的能力值在同一尺度上可比且数值稳定。
- **查询依赖能力状态**：收到查询后，智能体结合自身技术报告与能力画像，通过内部推理算子动态生成查询相关的能力状态 \(\tau_i(q) = \Phi_i(q, P_i, \tau_i)\)，在此基础上产生中间推理结果 \(K_i = \Theta_i(q \mid \tau_i(q))\)。

### 2.2 自组织协作与思维图谱导航（Thought Map Navigation）

- **协作倾向向量**：每个智能体 \(a_i\) 量化评估与其他智能体协作的潜在效用，形成协作倾向向量 \(c_i = [c_{i,1}, \dots, c_{i,N}]\)。
- **协作倾向计算**：\(c_{i,j}\) 通过温度缩放的 Softmax 计算（式 7），\(T\) 控制路由锐度；由于 \(\tau_d^j \in [0,1]\) 有界，天然避免指数溢出；禁止自协作（\(c_{i,i}=0\)）。
- **协作矩阵**：聚合所有向量形成有向协作矩阵 \(C\)，编码智能体间的异构偏好与任务特定需求。
- **本地图遍历**：当前活跃智能体作为本地导航器，选取未访问的、协作倾向最高的下游智能体（式 10-11），避免全局路由。
- **动态终止**：当所有未访问智能体的倾向低于阈值或全部智能体被遍历时终止，由活跃智能体直接输出最终答案，无需固定步数。

### 2.3 拓扑更新与渐进式精炼（Topology Update / Progressive Refinement）

- **失败检测**：终端智能体（而非外部法官）验证累积上下文 \(K_N\) 是否满足查询要求；不满足则触发拒绝。
- **局部回退**：先在当前深度尝试替代路由；若失败，逐步回溯至上游边，而非全路径丢弃。
- **拓扑更新**：对失败边施加衰减因子 \(\alpha\)（如 0.5）：\(c_{i,j} \leftarrow \alpha \cdot c_{i,j}\)（式 14），修剪失效边并重新导航，保留已有推理进展，渐进收敛到有效路径。

## 8. 综合评述

DeAR 提出了一个新颖且自洽的去中心化智能体推理框架，通过能力锚定、思维图谱导航和渐进式拓扑更新三个组件，系统性地回应了集中式协作中的路由瓶颈、角色僵化与错误传播问题。其实验设计覆盖面广，消融分析清晰，证实了架构创新而非模型规模是性能提升的主要来源。尽管在统计严谨性、系统开销量化与可复现性方面仍有提升空间，但该工作为智能体协作推理提供了一条具有启发性且可扩展的研究路径，尤其强调了“自主协商、自组织协作”相对于“中心化指挥”的结构性优势，对后续研究具有较高的参考价值。
