## 摘要
多智能体大语言模型通过在共享环境中协调多个策略来解决复杂任务。然而，现有强化学习方法通常分别优化每个响应或轨迹，即使多个输出共同导致一次状态转移。因此，更新单元与系统执行的动作不一致。为解决该问题，我们提出 SRPO（Setwise Relative Policy Optimization，集合式相对策略优化），它将活跃集（active set）——即一次状态转移所消耗的最小输出集合——视为一个多智能体动作。具体而言，SRPO 将成员对数比合并为一个按基数归一化的集合比，分配一个相对优势，并对该集合进行一次裁剪。该表述将分工与联合共同演化统一为具有不同集合大小的动作。在数学推理和多轮搜索上的实验表明，一个训练接口可适用于四种模型规模下的固定、混合和动态路由工作流，并在所报告的比较中取得了最强的宏平均结果。优化诊断进一步刻画了其在不同事件归约和集合大小下的稳定性。

## Abstract
Multi-agent large language models solve complex tasks by coordinating several policies in a shared environment. However, existing reinforcement learning methods usually optimize each response or trajectory separately, even when several outputs jointly cause one state transition. Consequently, the update unit differs from the action executed by the system. To address this problem, we propose SRPO (Setwise Relative Policy Optimization), which treats the active set the minimal set of outputs consumed by one transition, as one multi-agent action. Specifically, SRPO combines member log-ratios into one cardinality-normalized set ratio, assigns one relative advantage, and clips the set once. This formulation unifies division of labor and joint co-evolution as actions with different set sizes. Experiments on mathematical reasoning and multi-turn search demonstrate one training interface for fixed, mixed, and dynamically routed workflows across four model scales, with the strongest macro-average results among the reported comparisons. Optimization diagnostics further characterize its stability under different event reductions and set sizes.

## 2. 方法论：核心思想、技术细节与算法流程

- **核心思想**：定义“活跃集”（active set）\(S_e\)，即一次状态转移中环境共同消费的最小新采样输出集合。对应动作 \(a_e=\{a_{e,j}:j\in S_e\}\)。若 \(K_e=|S_e|=1\)，表示分工；若 \(K_e>1\)，表示联合共演化；混合或动态路由则表现为 \(K_e\) 随时间变化。
- **事件概率分解**：一个事件的动作概率为
  \[
  \pi_\Theta(a_e|s_e)=\prod_{j\in S_e} q_{e,j}(a_{e,j}|o_{e,j})
  \]
  其中 \(q_{e,j}\) 可来自路由器、工作智能体或聚合器。该定义与参数是否共享、硬件是否相同无关。
- **成员对数比**：对每个成员输出计算掩码后的序列对数比：
  \[
  \ell_{e,j}=\sum_u m_{e,j,u}\log\frac{q^{cur}_{e,j}(a_{e,j,u}|o_{e,j,u})}{q^{old}_{e,j}(a_{e,j,u}|o_{e,j,u})}
  \]
  其中 \(m\) 用于排除 prompt、padding 和环境 token。
- **集合比归一化**：将同一事件内所有成员的对数比合并，并按基数 \(K_e\) 做平方根归一化：
  \[
  L^{set}_e=\frac{1}{\sqrt{K_e}}\sum_{j\in S_e}\ell_{e,j},\quad
  \rho^{SRPO}_e=\exp(L^{set}_e)
  \]
  当 \(K_e=1\) 时，退化为普通响应级似然比。
- **单一相对优势**：每个事件只分配一个团队相对优势：
  \[
  \hat A_e=\frac{R_e-\mu_{g(e)}}{\sigma_{g(e)}+\epsilon}
  \]
  同一优势赋给该事件的所有成员，不按成员分别裁剪或平均。
- **集合级裁剪与事件平均**：目标函数为
  \[
  J^{SRPO}(\Theta)=\frac{1}{|B|}\sum_{e\in B}
  \min\left(\rho^{SRPO}_e\hat A_e,\ \text{clip}(\rho^{SRPO}_e,1-\epsilon,1+\epsilon)\hat A_e\right)
  \]
  即“一个事件、一个比率、一次裁剪”，并在事件级别平均，而非在 token 或成员行级别平均。
- **算法流程**：
  1. 与环境交互时识别完整事件，记录活跃集及成员输出；
  2. 计算每个成员的对数比；
  3. 用 \(1/\sqrt{K_e}\) 归并为一个集合对数比；
  4. 为事件分配一个团队相对优势；
  5. 对整个集合做一次 PPO 式裁剪；
  6. 在事件批次上更新所有可训练策略。
- **实现要求**：每个响应需存事件 ID、前动作状态 ID、成员索引、期望基数、策略版本和行为 log-prob；同一事件的所有行必须留在同一 mini-batch；缺失成员会使事件无效，而不是静默改变动作。

## 6. 主要结论与发现

- **统一动作表示有效**：SRPO 将分工、联合共演化和混合路由统一为不同基数的活跃集动作，并保持 rollout、奖励、优势估计和优化器接口基本不变。
- **数学推理结果**：
  - Qwen3-4B：SRPO 三 seed 宏平均 Avg@16 为 \(61.3\pm0.5\)，Pass@16 为 \(77.9\pm0.8\)；
  - Qwen3-8B：Avg@16 为 \(62.5\pm0.5\)，Pass@16 为 \(77.8\pm0.7\)；
  - 论文称均超过表中最强 Dr. MAS 行 0.2 个百分点。
- **多轮搜索结果**：
  - Qwen2.5-3B：Avg@16 为 \(40.1\pm0.5\)，Pass@16 为 \(56.1\pm0.8\)；
  - Qwen2.5-7B：Avg@16 为 \(45.6\pm0.4\)，Pass@16 为 \(61.6\pm0.7\)；
  - 相比最强 Dr. MAS，3B 提升约 3.2/3.1 个百分点，7B 提升约 1.8/3.3 个百分点。
- **消融结论**：
  - 在 Search 上，五成员 SRPO 的 \(1/\sqrt K\) 归一化优于无归一化求和与 \(1/K\) 平均；
  - 五成员 SRPO 也优于单例边界，但作者指出这不是等算力比较。
- **训练动态**：
  - event-uniform 8B run 梯度范数保持在 \([56.97,108.10]\)，变异系数 0.107；
  - 其平均活跃集大小从 2.233 增至 2.421，说明事件归约在变基数下仍稳定；
  - 自适应路由器平均活跃集大小为 1.638，说明模型可学习非整数、变化的团队规模。
- **成本趋势**：
  - 输出侧代理 \( \bar K\bar T \) 从首 checkpoint 到末 checkpoint 并未单调增长；
  - Search 中 3B 每 query 约 2.00 次工具调用，7B 为 2.04–2.27 次。
- **核心原则**：一起改变环境的输出，应该被一起优化。

## 7. 优点

- **动作定义清晰且工作流无关**：从环境转移边界定义活跃集，不依赖角色、顺序、轮次或编排布局。
- **统一性强**：分工是 \(K=1\) 的特例，联合共演化是 \(K>1\)，混合和动态路由自然纳入同一框架。
- **改动局部**：
