## 摘要
合作式多智能体强化学习（MARL）系统依赖过往经验来学习协调行为，但如果训练期间环境或任务目标发生变化，这些经验可能变得不可靠。在这种情况下，智能体首先需要一种方法来识别情况已经发生变化，然后再决定如何适应。本文研究使用奖励衍生信号对合作式MARL进行在线变点检测。我们提出“过往奖励模式”（Patterns of Past Rewards, PPR），一种轻量级、算法无关的检测器，它对智能体的回报流进行平滑，突出近期变化，并应用统计漂移检测器来标记显著偏移。我们在基于多智能体粒子环境（Multi-Agent Particle Environment）构建的自定义 Speaker-Listener 环境中，在两种受控非平稳场景下评估 PPR。结果表明，检测速度与报警稳定性之间存在权衡。平滑回报基线检测得更早，但会产生许多重复报警。相比之下，将检测器直接应用于原始回报往往会漏掉变化。PPR 通过限制冗余检测，同时仍能识别受控变化，提供了一种更平衡的方法。这些发现凸显了 PPR 作为一种轻量级、基于奖励的监控工具，使合作式 MARL 系统能够在训练期间可靠地识别重大变化。

## Abstract
Cooperative multi-agent reinforcement learning (MARL) systems rely on past experience for learning coordinated behaviour, but this experience may become unreliable if the environment or task objective changes during training. In such cases, agents first need a way to recognize that the situation has changed before deciding how to adapt. This paper studies online change-point detection for cooperative MARL using reward-derived signals. We propose \emph{Patterns of Past Rewards} (PPR), a lightweight algorithm-agnostic detector that smooths agents' return streams, highlights recent changes, and applies a statistical drift detector to flag significant shifts. We evaluate PPR in a custom Speaker-Listener environment based on the Multi-Agent Particle Environment under two controlled non-stationarity scenarios. Our results show a trade-off between detection speed and alarm stability. A smoothed-return baseline detects earlier but produces many repeated alarms. In contrast, applying the detector directly to raw returns often misses the shift. PPR offers a more balanced approach by limiting redundant detections while still identifying the controlled shifts. These findings highlight PPR as a lightweight, reward-based monitoring tool that enables cooperative MARL systems to reliably identify major changes during training.

## 2. 方法论：Patterns of Past Rewards（PPR）

- **核心思想**：奖励信号隐含环境动态、任务目标与协调质量信息；若这些方面发生显著变化，应反映在 episodic return 流中。PPR 不修改底层 MARL 算法，只读取训练中产生的回报流，进行在线漂移检测。
- **总体流程**：  
  `R_e → SMA → \bar R_e → EMV → V_e → KSWIN → d_e`  
  其中 `R_e` 为第 e 个 episode 的回报，`d_e ∈ {0,1}` 表示是否检测到漂移。
- **关键技术细节**：
  - **SMA（简单移动平均）**：对回报流做平滑，降低探索噪声、随机转移和普通学习波动造成的短期扰动。  
    公式：`\bar R_e = (1/w) Σ_{i=e-w+1}^e R_i`。需要至少 w 个 episode 作为 warm-up。
  - **EMV（指数移动方差）**：把平滑后回报的变化转换为正的可变性信号，使突变更明显。  
    公式：`V_e = β(\bar R_e - \bar R_{e-1})^2 + (1-β)V_{e-1}`。  
    β 越大越敏感，β 越小越平滑。
  - **KSWIN 漂移检验**：在变换后的 `V_e` 上使用 Kolmogorov–Smirnov 滑动窗口检测。设最近测试窗口 B 大小为 m，参考样本 A 来自其前部窗口 W，比较经验累积分布函数 `F_A`、`F_B`：  
    `D = sup_x |F_A(x) - F_B(x)|`。  
    阈值：`τ_α = sqrt(-ln(α)/m)`，当 `D > τ_α` 时标记漂移。
- **参数设置**：主实验使用 `w=8`、`β=2/3`、`α=2×10^-4`、`W=25`、`m=10`。
- **算法属性**：轻量、在线、算法无关，可直接与现有 MARL 训练流程并行运行。

## 3. 实验设计

- **场景 / 环境**：自定义 Speaker–Listener 任务，基于 Multi-Agent Particle Environment（MPE）。
  - 两个智能体：speaker 观察目标颜色并发送消息；listener 观察 landmark 位置和消息并选择移动动作。
  - 二者共享团队奖励，目标是学习颜色到 landmark 的通信约定。
- **受控非平稳场景**：
  - **Landmark 颜色改变**：例如把 landmark 颜色从红、绿、蓝改为青、品红、黄，颜色到 landmark 的关联改变，旧通信约定可能失效。
  - **奖励函数改变**：将“离原目标最远的 landmark”设为新目标，团队奖励重新计算，合作任务仍在但通信约定不再匹配。
- **训练协议**：使用 MADDPG 在线训练；每个 episode 25 个环境步；训练 1,000,000 步；在 500,000 步即第 20,000 episode 处引入受控变化。MADDPG 参数包括 actor/critic 学习率 `3×10^-4` / `10^-3`、隐藏层 128 和 64、batch size 1024、replay buffer `10^6`、warm-up 5000 步。
- **对比方法 / 消融**：
  - 完整 PPR：`SMA → EMV → KSWIN`。
  - `SMA + KSWIN`：去掉 EMV，直接对平滑回报做 KSWIN。
  - `raw return + KSWIN`：去掉 SMA 和 EMV，直接对原始回报做 KSWIN。
  - 同时将 shifted runs 与 matched no-shift runs 的学习曲线进行对照。
- **评估指标**：
  - **Detection delay**：真实变化点到首次正确检测之间的 episode 数。
  - **Pre-shift detections**：变化前误报数。
  - **Excess detections**：首次正确检测后的重复报警数。
  - **Missed detection**：训练范围内未检测到变化则计为漏检；delay 只在检测到的 run 上计算。
- **Benchmark 说明**：论文未使用公开标准 benchmark，而是使用自定义 MPE 衍生环境和内部消融作为主要比较基准。
