## 摘要
基于LLM的多智能体系统（MAS）通过角色专门化的智能体之间的通信来解决复杂任务。然而，智能体间依赖会带来超出孤立智能体故障的可靠性风险。例如，中间消息中的错误可能被下游智能体继承并放大。现有的不确定性量化（UQ）方法主要针对孤立响应或单智能体推理，因此无法捕捉MAS中的不确定性传播。为此，我们提出PropUQ-MAS，一种感知错误传播的UQ框架，它将MAS执行表示为通信结构图，并通过结合局部不确定性与从上游消息继承的不确定性来估计每一步的可靠性。大量实验表明，PropUQ-MAS能够持续提升MAS中的UQ，在AUROC和PRR上分别取得+6.10%和+47.58%的平均相对提升。

## Abstract
LLM-based multi-agent systems (MAS) solve complex tasks through communication among role-specialized agents. However, inter-agent dependencies introduce reliability risks beyond isolated agent failures. For instance, errors in intermediate messages could be inherited and amplified by downstream agents. Existing uncertainty quantification (UQ) methods mainly target isolated responses or single-agent reasoning, and therefore fail to capture uncertainty propagation in MAS. To this end, we propose PropUQ-MAS, an error propagation-aware UQ framework that represents MAS execution as a communication-structured graph and estimates each step's reliability by combining local uncertainty with uncertainty inherited from upstream messages. Extensive experiments demonstrate that PropUQ-MAS consistently improves UQ in MAS, with average relative gains of +6.10% in AUROC and +47.58% in PRR.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：基于 LLM 的多智能体系统（MAS）通过角色专门化智能体的多步通信协作，在自主软件工程、多步网页导航等任务上展现出较强灵活性。
- **核心问题**：MAS 的智能体间依赖使可靠性瓶颈从"单个智能体故障"转移到"系统级错误传播"。上游智能体的错误中间消息可能被下游当作有效上下文接受、并入后续推理，甚至被放大，形成级联风险。
- **现有方法的不足**：
  - 传统 LLM UQ 方法（token 概率、自评估、语义一致性、隐层表示等）只估计**孤立单轮输出**的局部不确定性，无法建模错误继承。
  - 近期"智能体式 UQ"方法虽将局部估计扩展到多步轨迹，但假设**单智能体顺序链**，无法适配 MAS 的多样通信拓扑（多父节点、多接收者、层次结构等）。
  - MATU 等 MAS 级方法通过多次采样执行的一致性估计**轨迹级**不确定性，属于事后（post-mortem）设计，既未建模传播，也不支持实时逐节点 UQ。
- **目标定位**：提出一个**拓扑无关（topology-agnostic）**、**可在线计算（online-computable）**的逐步传播感知 UQ 框架，为 MAS 提供实时风险监控、自适应干预与事后失败归因的诊断信号。
- **整体含义**：将 MAS 可靠性视为由交互动态决定的**集体属性**，把不确定性建模从"孤立响应"推进到"通信结构上的传播过程"。

## 2. 方法论

### 2.1 核心思想

将 MAS 执行轨迹展开为**有向无环执行图（DAG）** \(G=(V,E)\)，把每个节点的不确定性分解为"局部生成错误"与"从父节点继承的污染"两部分，并用递归规则在单次前向传播中逐节点计算传播感知不确定性。

### 2.2 关键建模细节

- **图表示**：节点 \(v=(i,t)\) 表示智能体 \(i\) 在第 \(t\) 步的输出（中间消息、工具结果或最终回答）；边 \((p,v)\) 表示 \(v\) 的生成以 \(p\) 的信息为条件；父集合记为 \(\mathrm{Pa}(v)\)。有反馈/重复通信的执行按时间顺序展开，因此任意拓扑（含循环通信）都可形成 DAG。
- **目标量**：传播感知不确定性定义为节点错误事件的边缘错误概率 \(r_v := \Pr(E_v=1)\)。
- **局部错误**：\(I_v \in \{0,1\}\) 表示在父输入正确的前提下，节点因智能体自身推理/生成缺陷而出错；\(u_v := \Pr(I_v=1)\)，可用现成的单智能体 UQ 方法估计（自评估、token 概率、自一致性等）。
- **边级交互模式**：每条边 \((p,v)\) 对应两种互斥模式——接受（A）或批判（C）。定义
  - \(\alpha_{pv} := \Pr(M_{pv}=A \mid E_p=1)\)：父节点出错时被接受的概率；
  - \(\beta_{pv} := \Pr(M_{pv}=C \mid E_p=1)\)，且 \(\alpha_{pv}+\beta_{pv}=1\)。
  - 在线执行中 \(E_p\) 不可观测，故用智能体**自报接受度** \(\hat\alpha_{pv}\) 作为插值估计（plug-in estimate）。
- **边级事件**：污染事件 \(Z_{pv} := \mathbb{1}\{E_p=1, M_{pv}=A\}\)，修正事件 \(Y_{pv} := \mathbb{1}\{E_p=1, M_{pv}=C\}\)；对应概率 \(\Pr(Z_{pv}=1)=\alpha_{pv}r_p\)，\(\Pr(Y_{pv}=1)=\beta_{pv}r_p\)。
- **结构分解**：节点错误当且仅当发生局部失败或被至少一个错误父节点污染：
  \[
  E_v = I_v \vee \left(\bigvee_{p\in \mathrm{Pa}(v)} Z_{pv}\right)
  \]
- **两条独立性假设**：
  - 假设 1（边级条件独立）：入边污染事件按边缘概率处理为相互独立；
  - 假设 2（局部—传播独立）：局部错误事件 \(I_v\) 与入边污染事件独立。
- **递归传播规则**（核心公式）：
  \[
  r_v = 1-(1-u_v)\prod_{p\in \mathrm{Pa}(v)}(1-\alpha_{pv}r_p)
  \]
  源节点（\(\mathrm{Pa}(v)=\emptyset\)）退化为 \(r_v=u_v\)。
- **算法流程（Algorithm 1）**：① 对 \(G\) 做拓扑排序；② 按拓扑序逐节点：估计局部不确定性 \(u_v\) → 对每个父节点通过模型自报得到 \(\hat\alpha_{pv}\) → 若无父节点则 \(r_v=u_v\)，否则按上式更新；③ 返回 \(\{r_v\}\)。整个过程无需训练、无需等待完整轨迹，可流式计算。

### 2.3 理论性质

- **命题 1（有界性）**：若 \(u_v, r_p, \alpha_{pv}\in[0,1]\)，则 \(0\le r_v \le 1\)；源节点满足 \(r_v=u_v\)。
- **命题 2（不确定性衰减）**：当 \(u_v < R_v\)（\(R_v=\max_p r_p\)）且聚合污染 \(B_v < (R_v-u_v)/(1-u_v)\) 时，\(r_v < R_v\)。即传播规则**非单调**，下游可通过低局部不确定性或严格批判（小 \(\alpha_{pv}\)）降低风险。
- **命题 3（线性可扩展）**：单次拓扑前向传播即可精确计算全部节点不确定性，时间复杂度 \(O(|V|+|E|)\)，空间复杂度同阶，支持实时 UQ。

## 6. 主要结论与发现

- **最终输出 UQ 稳定提升**：跨数据集、模型家族与拓扑，AUROC 中位相对增益 **+7.32%**，PRR 中位相对增益 **+41.36%**；局部基线越弱或越噪声，提升越明显。
- **中间步骤 UQ 同样有效**：去中心化 MAS 中间智能体上平均相对增益 **+6.10% AUROC**、**+47.58% PRR**；LLM 判官评估下 Critic 与 Refiner 也一致改善（如 Refiner AUROC 0.6709 → 0.7886）。
- **规模鲁棒**：在顺序链长度 2–10、层次宽度 2–10 的所有设置下均优于局部基线，说明传播规则可处理更长链与更大父集合。
- **自报接受度 \(\hat\alpha\) 有效**：w/ \(\hat\alpha\) 在三种拓扑、两个指标上均优于边权全为 1 的消融版本；分箱分析显示自报分数与经验错误继承率单调对齐（最低箱 0.050 → 最高箱 0.973）。
- **效率优势**：相比 MATU（41.4 s/样本）与 UProp（11.3 s/样本），PropUQ-MAS 传播层仅增加约 0.2 s 开销（1.129 → 1.328 s），且性能最优。
- **可解释性**：案例表明"局部高置信但继承上游错误"的失败模式可被传播感知不确定性捕获（如 Summarizer 局部 0.10、传播后 0.469；顺序链末端局部 0.10、传播后 0.738）。

## 7. 优点

- **问题定位准确且新颖**：明确指出现有 UQ 无法覆盖 MAS 的**通信诱导不确定性传播**，并给出"逐步、在线、拓扑无关"的清晰需求刻画。

- **实验覆盖较广且结果一致**：跨 3 领域、3 拓扑、4 模型、2 局部 UQ 基线，最终与中间步骤双向验证；消融与边权验证直接支撑关键设计；对负结果如实标注。

## 8. 不足与局限

- **\(\hat\alpha_{pv}\) 为自报代理，校准性无保证**：理论上的 \(\alpha_{pv}\) 是"父节点出错条件下被接受"的概率，在线不可观测；自报分数只是插值估计，可能存在系统性偏差。作者也承认未来需用校准/验证器/学习式估计器替代。
- **独立性假设较强**：边级条件独立与局部—传播独立
