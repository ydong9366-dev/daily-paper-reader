## 摘要
由大型语言模型构建的多智能体系统已被广泛部署，但当两个 LLM 必须协调而非单独行动时，性能会损失多少仍不清楚。我们将协作税形式化为具有私人信息的两人合作博弈中的团队去中心化损失，并用两个命题刻画其符号及其与最大超可加性违背的等价性。我们在 32 个可单人完成的任务上操作化这一定义，这些任务按接地摩擦来源分组，并在来自 7 家提供商的 11 个模型上测量该税。该税沿两个无例外的轴呈现结构：在每个模型上都存在的类别排序，以及随能力单调下降。其近端机制不是推理缺陷，而是一个四阶段对话级联：智能体提出缺乏依据的论断，未能询问伙伴，跳过整合双方观点，并在不重新推导的情况下接受答案。该税可由对话特征机械地预测，并且部分可解：针对所有四个阶段的提示干预弥合了相当大一部分差距，而主要瓶颈因类别而异。在异质配对中，该税被拉向较强伙伴，而不是可加中点，从而在实证上实现了我们框架预测的最大超可加性违背。这些结果共同将 LLM 系统中的协作重新界定为一种可测量、可预测且部分可解的成本。

## Abstract
Multi-agent systems built from large language models are deployed widely, yet how much performance is lost when two LLMs must coordinate rather than act alone remains unclear. We formulate the collaboration tax as the team-decentralisation loss of a two-player cooperative game with private information, with two propositions characterising its sign and its equivalence to a max-superadditivity violation. We operationalise this definition on 32 solo-tractable tasks grouped by source of grounding friction and measure it on 11 models from 7 providers. The tax is structured along two no-exception axes: a category ordering across every model and a monotonic decrease with capability. The proximate mechanism is not a reasoning deficit but a four-stage conversational cascade in which agents make ungrounded claims, fail to query the partner, skip integrating both views, and accept the answer without re-derivation. The tax is mechanically predictable from conversation features and partly tractable: a prompt intervention targeting all four stages closes a substantial fraction of the gap, with the dominant bottleneck differing across categories. In heterogeneous pairs the tax is pulled toward the stronger partner rather than the additive midpoint, empirically realising the max-superadditivity violation predicted by our framework. Together these results recast collaboration in LLM systems as a measurable, predictable, and partly tractable cost.

## 1. 核心问题与整体含义

- **研究动机**：LLM 多智能体系统已被广泛部署于软件工程、规划、社会模拟、推理时辩论等场景，业界普遍将"协作"视为免费原语——只要把足够强的模型组队、分配清晰角色，团队就应当优于任何单个成员。这一前提很少被直接检验。
- **核心问题**：当两个（或多个）LLM 必须协调解决一个各自单独也能处理的问题时，它们是否真的能"合作成功"？如果不能，性能损失有多大、由什么决定、发生在对话的哪个环节、能否在不重训练的前提下缓解？
- **整体含义**：论文将"协作税"（collaboration tax）定义为一种**任务无关、符号已知、可结构化解释**的协调成本量，将其锚定在 Marschak（1955）的团队去中心化框架与 Shapley 等人的合作博弈论中。作者主张协作成本不是单一数字，而是一种可测量、可预测、部分可解的结构性现象——这重新界定了多智能体系统的部署假设。
- **三个结构性开放问题**：(1) 配对执行是否存在系统性协调成本，其大小由能力、任务结构还是二者交互决定；(2) 失败源自推理、信息获取、智能体间沟通，还是验证环节；(3) 该成本能否在不重训练的情况下通过提示层干预降低。

## 2. 方法论

### 2.1 形式化定义

- **协作税定义（Definition 1）**：对任务 T=(X, μ, U)，U 为确定性评分器（值域 [0,1]），x 被划分为 v₁(x)∪v₂(x)=x 且任一视图单独都不足以确定答案（union-necessary），则
  - `tax((M₁,M₂),T) = V_solo − V_pair`
  - 其中 `V_solo = max_i E_x[U(x, M_i(x))]`，`V_pair = E_x[U(x, Π(M₁,M₂; v₁(x), v₂(x)))]`
  - 同质配对时退化为 `tax(M,T) = s_solo-full(M,T) − s_homo(M,T)`，并以比值 `c_tax/s_solo-full` 做跨任务归一化。

### 2.2 合作博弈论刻画（两个命题 + 两个补充命题）

- **命题 1（信息支配）**：若配对协议产出的答案分布关于 (v₁(x), v₂(x)) 可测，且 V_solo 由全信息下的最优可测策略实现，则 tax ≥ 0。解释了为何绝大多数测量单元为正；操作估计中因单 LLM 策略未必最优，允许出现少量负值。
- **命题 2（最大超可加性等价）**：tax > 0 **当且仅当**合作博弈违反 `v({1,2}) ≥ max(v({1}), v({2}))`。为异质配对的不对称效应提供了博弈论词汇。
- **命题 3（Shapley 值）**：两人博弈中 `φᵢ = ½(v({i}) + v({1,2}) − v({j}))`。
- **命题 4（次可加性 ⇒ 双方均损失 Shapley 份额）**：若 `v({1,2}) < v({1}) + v({2})`，则双方 φᵢ 均严格低于其单干收益，且损失绝对值相同。

### 2.3 任务设计的四项原则

- **Solo-trivial**：全信息下单个智能体应高成功率求解，使 s_solo-full 接近上限，差距才反映协调成本而非解题能力。
- **Union-necessary**：每个实例被划分为互补视图，任一视图单独无法确定答案。
- **Algorithmically verifiable**：真值由确定性程序计算（BFS 最短路径、拓扑排序、SAT 式求解器），输出连续 [0,1] 分数；路径类任务在 16 种原点/朝向/轴序方案上枚举。
- **Multiply expressible**：同一内容允许多种等价表层表征（坐标原点、轴序、命名约定、序数方向、关系词汇），构成接地摩擦来源。

### 2.4 四阶段对话级联机制

- 从 700 条开放式 LLM 失败描述中聚类出 16 个行为具体主题（k=16，采用反偏见命名规则禁用"verification/share/communicate"等泛化词），映射到 Clark & Brennan 的接地管道：
  - **L1 Grounding（接地）**：论断可追溯到任一方陈述过的信息；一旦编造未陈述的值，下游无法挽救（严格必要条件）。
  - **L2 Querying（询问）**：至少一方对伙伴提出具体事实请求；是最独立的维度，CSP 上区分度最大。
  - **L3 Integration（整合）**：决定性论断之前出现显式的"双方视图合并状态"消息；是协作税最强的单变量预测器，其边际贡献在多元回归中唯一为正，Spatial 上效应最强。
  - **L4 Re-derivation（重推导）**：接收方在任一方发出 ACTI! 前展示真实重算工作；绝对相关性与 L3 相当，但在观测数据中超越 L3 的边际贡献几乎为零（与 L3 高度共线）。

### 2.5 预测与干预

- **预测模型**：Ridge 回归（λ=1，输入标准化），因变量为每单元比值差距，自变量为对话结构特征（样本量、长度、同意/分歧标记密度、视图披露比、坐标 token 密度、轮次节奏统计）+ 模型与类别哑变量；采用**按任务分组的 k 折**防止泄漏。
- **提示干预**：在同质协作系统提示中追加四条阶段针对性条款（L1 接地引用条款、L2 第二消息查询强制、L3 整合块、L4 重推导要求），并做 4 组 leave-one-out 消融。

## 3. 实验设计

### 3.1 任务与 Benchmark

- **32 个程序生成的可单人完成谜题任务**，分三个结构家族：
  - **Spatial（12 个）**：maze、blueprintmaze、conflictpath、cube、floodfill、geomaze、numberlink、rulemaze、streetmap、terrain、timedpath 等，答案为坐标序列，评分器按有效前缀长度/最优路径长度归一化。
  - **Relational（11 个）**：aliasedtaxonomy、ancestorpath、dagorder、eulerpath、graph、graphattr、graphpath、noderanking、relaquery、treesum、trianglecount，评分为逐查询精确匹配或 Kendall tau、集合 IoU 等。
  - **CSP（10 个）**：attrcombo、binpack、cipherdecode、crossword、eventlog、logic、meetingmatrix、order、schedule、seating，评分为约束满足比例、单元准确率等。
- 三个家族分别对应三类接地摩擦：参照系对齐（Spatial）、词汇与类别对齐（Relational）、索引与序数对齐（CSP）。

### 3.2 模型与模式

- **11 个模型，7 家提供商**：OpenAI（gpt-5、gpt-5-nano、gpt-4.1-mini、gpt-4.1-nano、gpt-4o-mini）、Anthropic（claude-sonnet-4-5）、Google（gemini-2.5-flash-lite）、DeepSeek（DeepSeek-V4-Pro）、以及三个开放权重模型 Llama-4-Maverick、Phi-4、Qwen3-8B。
- **四种规范模式**：
  - `solo-full`：单智能体获得合并实例，一次补全 + 一次 critic 修订（作为协调无关上界）。
  - `solo` 对照：用于验证 critic 步骤不构成差距来源。
  - `homogeneous collaboration`：同一模型两份独立上下文，各持一个视图，通过共享系统提示交换消息，直到一方发出 `ACTI!` 加候选答案，或达到 50 轮交换上限。
  - `heterogeneous collaboration`：两个角色由不同模型填充，是配对组合分析的基础。

### 3.3 对比与验证设置

- **异质配对矩阵**：选取两组强弱对比，弱槽固定为 gpt-4.1-nano，分别搭配 claude-sonnet-4-5（跨家族）与 gpt-5（同家族），每种配对双向交换角色，共 4 种异质配置（未跑满 11×11 全矩阵）。
- **人工验证**：4 名独立专家对 100 条分层抽样的同质 rollout 重新标注，计算 Fleiss' κ、两两 Cohen's κ 以及自动评判器与专家多数票的一致性。
- **消融**：干预条件的 leave-one-out（5 个条件）；solo critic 消融（gpt-4o-mini，32 任务 × 50 rollout）；异质级联签名迁移验证。

## 4. 资源与算力

- **论文未明确提及任何 GPU 型号、数量或训练时长**。所有实验均通过 OpenAI 兼容的 chat API 完成，**无微调、无参数访问**。
- 唯一给出的"资源"性参数：
  - 生成温度 0.7，默认 top-p，无输出 token 上限；
  - 对话轮次上限 50 次交换；
  - 每 (任务, 模式, 模型或配对) 单元 **50 次独立种子 rollout**；
  - 评分器固定为 gpt-4o-mini，温度 0.5，跨所有单元保持一致；
  - API 调用统一 120 秒超时，瞬时故障最多 5 次指数退避重试，路径类任务因 Azure 内容过滤额外允许 6 次更长退避重试。
- 因此**总调用量虽大（32 任务 × 11 模型 × 多模式 × 50 rollout + 配对矩阵），但算力开销体现为 API 调用成本而非本地 GPU 训练**，论文未做量化披露。

## 5. 实验数量与充分性

- **主实验规模**：32 任务 × 11 模型 × 3 类模式（solo-full / 同质 / 异质部分）× 50 rollout，构成约数百个 (模型, 任务) 单元。
- **异质实验**：仅 4 种配置（2 组配对 × 2 种角色顺序），作者自述为"定性模式的存在性证明"而非定量刻画。
- **消融与验证**：
  - 干预消融 5 个条件（all-four + 4 个 no-Lk），每类别分别报告 Δs_homo 与闭合比例及 95% CI；
  - critic 消融 1 组（32 任务 × 50 rollout）；
  - 回归预测的 leave-one-task-out 与 leave-one-model-out 两种泛化检验；
  - 人工验证 100 条 rollout、4 名标注者、四维度一致性；
  - 700 条失败描述的聚类分析（k=16）。
- **充分性与公平性评价**：
  - **优点**：评分器跨所有单元固定，异质对比不受评分侧能力差异混淆；按任务分组交叉验证避免泄漏；50 次 rollout 与 95% CI 报告提供统计稳健性；人工验证直接检验了自动评判器标签。
  - **不足**：异质配对样本过少（2 对，每对 1 个家族侧），家族级效应不可检测；numberlink 与 crossword 未达 solo-tractability 目标，其比值差距仅作探索性报告；部分 leave-one-out 置信区间较宽甚至跨零（如 no-L4 on Spatial、no-L1 on Relational），类别瓶颈结论强度有限；no-L1 on Spatial 与 no-L3 on CSP 的点估计超过 all-four 条件，虽 CI 重叠但削弱了"类别选择性提示更优"的论断。

## 6. 主要结论与发现

- **协作税是结构化的，而非单一数字**，沿两条无例外的轴排列：
  - **类别排序**：在每一行模型上均为 Spatial ≻ Relational ≻ CSP（空间协调损失最大，约束满足损失最小）；
  - **能力单调性**：差距随模型能力单调递减，最弱模型损失约一半的单干成功率，但顶级模型也受影响；三个最弱行来自三个不同模型家族，说明能力排序不是家族风格假象。
- **近端机制是四阶段对话级联，而非推理缺陷**：接地 → 询问 → 整合 → 重推导。67% 的失败 rollout 同时触发至少两个阶段；L3 与 L4 纠缠最深（Jaccard 0.67），L2 最独立（独占触发率 13.9%），L3 从不单独触发。
- **协作税可由对话特征机械预测**：M1 ridge 回归达到 **OOF R² = 0.475、Spearman ρ = 0.760、Pearson r = 0.705**；加入级联评判标签不会显著改善拟合（说明结构特征已编码大部分信号）。
- **能力设定截距，对话形状设定斜率**：leave-one-task-out 保持正泛化方差与强秩相关；leave-one-model-out 保持单元秩序但无法外推绝对水平。最大正贡献者是弱模型哑变量，最大负贡献者是 CSP 哑变量与对话形状特征。
- **提示干预可闭合相当部分差距**：all-four 条件整体闭合 **38.3%**，CSP 最高（52.5%）、Relational 次之（41.4%）、Spatial 最低（27.1%），所有类别 95% CI 下界均远高于零。
