## 摘要
持续改进的智能体需要超越静态监督的动态交互反馈，然而直接与现实环境交互成本高昂、速度缓慢、不安全且难以并行化。世界建模提供了一种自然的中间代理，使智能体在采取实际行动之前能够查询成本更低、更可控的反馈。经典世界模型主要通过未来物理状态预测来实例化此代理，这种表述对于需要超越原始状态转换的可操作反馈的智能体而言虽有用但过于狭窄。在这项工作中，我们概念化了以智能体为中心的交互式世界代理，将基本范式从物理状态转换转变为智能体可用的信息转换，例如执行结果、检索到的经验或技能，以及验证信号，从而拓宽了世界建模的范围，为持续改进的智能体提供多功能的反馈。为了系统地映射这一设计空间，我们根据其反馈模态将世界代理组织为六种功能形式：动态代理、空间代理、执行代理、记忆/经验代理、技能代理和奖励/验证代理，这些共同表征了世界建模服务智能体改进的主要方式。我们进一步分析了这些代理如何在三个递进层次上赋能智能体：L.1 推理时引导，代理输出丰富上下文信息以做出更优决策；L.2 训练时优化，代理输出产生奖励、批评或合成轨迹用于策略学习；以及 L.3 智能体-代理共同进化，真实环境证据持续更新代理和智能体以实现共同进化。最终，这项工作将世界建模重塑为以智能体为中心的范式，为构建能够赋能智能体更好地规划、更快地学习和持续进化的世界代理制定了路线图。

## Abstract
Continually improving agents require dynamic interaction feedback beyond static supervision, yet direct real-environment interaction is costly, slow, unsafe, and hard to parallelize. World modeling offers a natural intermediate proxy that allows agents to query lower-cost, more controllable feedback before committing to real actions. Classical world models instantiate this proxy primarily through future physical-state prediction, a formulation useful yet narrow for agents that require actionable feedback beyond raw state transitions. In this work, we conceptualize Agent-Centric Interactive World Proxies, shifting the fundamental paradigm from physical state transitions to agent-usable information transitions, such as execution outcomes, retrieved experiences or skills, and verification signals, broadening the scope of world modeling to provide versatile feedback for continually improving agents. To systematically map this design space, we organize world proxies into six functional forms based on their feedback modalities: dynamics, spatial, execution, memory/experience, skill, and reward/verification proxies, which together characterize the primary ways world modeling serves agent improvement. We further analyze how these proxies empower agents across three progressive levels: L.1 Inference-Time Guidance, where proxy outputs enrich in-context information for superior decisions; L.2 Training-Time Optimization, where proxy outputs yield rewards, critiques, or synthetic rollouts for policy learning; and L.3 Agent-Proxy Co-Evolution, where real-environment evidence continuously updates both the proxy and the agent for co-evolution. Ultimately, this work recasts world modeling into an agent-centric paradigm, establishing a roadmap for building world proxies that empower agents to plan better, learn faster, and evolve continually.

### 2. 论文提出的方法论

#### 2.1 核心思想：从“世界模型”到“世界代理”

- 世界代理（World Proxy）被定义为：
  > 一种环境锚定的代理机制，模拟或预测**以智能体主动发起的交互为条件的信息转换**，旨在为智能体改进提供信息增益。
- 形式化定义：  
  \[
  \hat{s}_{\ell+1} = \mathcal{WP}(s_\ell, u^\mathcal{F}_\ell), \quad s_\ell \in \mathcal{S}
  \]
  - \( \ell \)：**交互步**，不限物理时间；
  - \( \mathcal{S} \)：**信息状态空间**，涵盖物理状态、观测、记忆、执行结果、验证反馈等；
  - \( \mathcal{F} \)：代理功能类型（动态、空间、执行、记忆、技能、奖励/验证）；
  - \( u^\mathcal{F}_\ell \)：智能体主动提出的查询、动作或干预；
  - \( \hat{s}_{\ell+1} \)：代理返回的反馈（未来状态、执行结果、检索经验、验证信号等）。
- **三大关键轴心转变**（表 2）：
  - 物理时间步 \( t \to t+1 \) → 交互步 \( \ell \to \ell+1 \)；
  - 状态转换 → 信息转换；
  - 外部给定条件 → 智能体主动发起的交互。

#### 2.2 六种代理功能（世界代理的实例化）

| 代理类型 | 智能体输入 | 代理输出 | 典型示例 |
|---|---|---|---|
| **动态代理**（经典世界模型） | 状态/历史 + 动作/未来查询 | 未来状态、轨迹、预测奖励 | 视频预测、动作条件视频生成、机器人动力学模型、基于模型的 RL |
| **空间代理** | 场景上下文 + 视角/位姿查询 | 新视角观测、渲染视图 | NeRF、3D Gaussian Splatting、导航中的视觉想象 |
| **执行代理** | 代码/命令/点击/API/工具调用 | 执行结果、状态变化、stdout/stderr | 浏览器模拟器、GUI 模拟器、代码执行预测器 |
| **记忆/经验代理** | 任务上下文 + 检索查询 | 检索到的经验、失败案例、约束 | 经验记忆、反思记忆、失败记忆 |
| **技能代理** | 目标/上下文 + 技能查询 | 技能建议、行动先验 | 技能库、可复用行为模块 |
| **奖励/验证代理** | 计划/轨迹/答案/动作 | 奖励、批评、偏好、验证结果 | 奖励模型、验证器、批评家、LLM-as-Judge |

#### 2.3 三个赋能层次

- **L.1 推理时指导（Inference-Time Guidance）**：代理输出（如检索经验、模拟结果、验证反馈）被拼接到智能体上下文中，帮助智能体“看得更多、推理更准、行动更安全”。不改变智能体参数，代价低、可逆。  
  \[
  \hat{s}^{guide}_{\ell+1} = \mathcal{WP}(s^{agent}_\ell, u^\mathcal{F}_\ell), \quad s^{agent+}_\ell = s^{agent}_\ell \oplus \hat{s}^{guide}_{\ell+1}
  \]
- **L.2 训练时优化（Training-Time Optimization）**：代理作为奖励模型、验证器、批评家或模拟器，生成训练信号（奖励、批评、偏好、合成轨迹），通过 SFT、DPO、PPO、GRPO 等目标直接优化智能体策略。  
  \[
  \hat{s}^{opt}_{\ell+1} = \mathcal{WP}(s^{agent}_\ell, u^\mathcal{F}_\ell), \quad \text{agent}^+ = \text{Train}(\text{agent}, \hat{s}^{opt}_{\ell+1})
  \]
- **L.3 智能体-代理共同进化（Agent-Proxy Co-Evolution）**：真实环境证据（真实轨迹、失败、新发现）更新代理，代理的强化知识又蒸馏回智能体，形成持续闭环的共同进化。  
  \[
  (\text{agent}^+, \mathcal{WP}^+) = \text{CoEvolve}(\text{agent}, \mathcal{WP}, \hat{s}^{proxy}_{\ell+1}, s^{env}_{\ell+1})
  \]

#### 2.4 有效世界代理的评价标准

- **锚定性**（Groundedness）：依赖真实环境数据/规则/轨迹，而非脱离现实的生成；
- **可控性**（Controllability）：支持智能体主动发起的查询和干预；
- **反馈有用性**（Feedback Usefulness）：改善规划、决策、策略学习或持续改进；
- **成本与可扩展性**（Cost & Scalability）：降低真实交互成本并安全扩展；
- **前瞻性**（Forward-Looking Ability）：在实际执行前预测结果、反事实或风险。

### 6. 论文的主要结论与发现

- **范式转变**：世界建模应从“预测世界”（物理状态预测）转向“服务智能体”（信息转换反馈），核心目标从视觉保真度转向**可操作的信息增益**。
- **世界代理的可行性**：动态、空间、执行、记忆、技能、奖励/验证六种代理共同构成了世界代理的设计空间，每个代理都对应一种智能体可用的反馈类型。
- **三层赋能阶梯**：
  - L1 让智能体在当前回合“做得更好”；
  - L2 让智能体“学得更快”；
  - L3 让智能体与代理“共同进化”，持续缩小想象与真实之间的鸿沟。
- **开放挑战**：
  - 保真度局限（生成模型可能违反物理规律，长轨迹误差累积）；
  - 代理信任判断（智能体何时信任代理、何时回到真实环境）；
  - 奖励黑客与安全（代理作为奖励源时可能被利用盲点）；
  - 以智能体为中心的评测体系（应衡量反馈是否帮助智能体规划/学习，而非仅衡量代理的预测精度）。
