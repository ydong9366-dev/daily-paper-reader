## 摘要
基于大型语言模型的多智能体系统近年来在复杂、长周期任务中展现出强大潜力。然而，现有方法主要依赖粗粒度的提示级别区分，而不针对不同子任务进行参数自适应，导致智能体间异质性不足，且专门化能力有限，成为复杂需求任务性能的瓶颈。为解决这一问题，我们提出了一种具有角色-子任务专家混合体（MoRSE）的任务导向型多智能体系统，该系统在任务结构和参数级别上均以（角色，子任务）条件专门化来区分智能体。为使智能体的职责在任务结构层面明确，我们构建了一个任务导向的多智能体系统，将每个任务分解为具有依赖关系的有向无环子任务图，并为每个智能体分配特定的（角色，子任务），从而在协作智能体间引入任务级专门化。此外，为满足多样化的角色和子任务参数自适应需求，我们提出了一种动态的（角色，子任务）LoRA专家混合模块，并配备基于原型的子任务语义路由器，以成本有效的方式在共享LLM基底上增强智能体的参数级专门化。然后，为在稀疏任务奖励下稳定地协同优化专家和路由器，我们进一步提出了一种具有两层信用分配的分层组相对策略优化，该优化将专家更新与路由决策引入的跨路由方差分离，从而将专家质量与路由质量解耦。在三个骨干网络上的代码生成基准实验证明了我们方法的有效性，在整体任务和逐步性能上均有提升，且训练所得专门化的收益可泛化到未见的任务类别和领域。

## Abstract
Large language model-based multi-agent systems have recently shown strong potential for complex, long-horizon tasks. However, existing methods mainly rely on coarse prompt-level differentiation without parameter adaptation for diverse subtasks, resulting in insufficient inter-agent heterogeneity and limited specialized capability that bottleneck performance on tasks with complex requirements. To address this, we introduce a Task-Oriented Multi-Agent System with Mixture of Role-Subtask Experts (MoRSE) that distinguishes agents with (role, subtask)-conditional specialization at both the task structure and parameter levels. To make agents' responsibility explicit at the task structure level, we formulate a task-oriented multi-agent system that decomposes each task into a dependency-aware Directed Acyclic Graph of subtasks and assigns each agent a specific (role, subtask), introducing task-level specialization across collaborating agents. Additionally, to address the diverse role and subtask parameter adaptation demands, we propose a dynamic Mixture of (role, subtask) LoRA Experts module with a prototype-based semantic router for subtasks, augmenting agents with parameter-level specialization on a shared LLM substrate cost-effectively. Then, to co-optimize experts and router stably under sparse task rewards, we further propose a hierarchical group-relative policy optimization with two-layer credit assignment that isolates expert updates from the cross-route variance introduced by routing decisions, disentangling expert quality from routing quality. Experiments on code-generation benchmarks across three backbones demonstrate the effectiveness of our approach, with improvements in both whole-task and step-wise performance, and the gains from trained specialization generalize across held-out task categories and domains.

## 2. 论文提出的方法论：核心思想、关键技术细节与算法流程

### 2.1 总体框架
MoRSE 由三个紧耦合模块组成，共同实现“结构分工 + 参数专门化 + 稳定协同优化”：

### 2.2 任务导向型多智能体系统（ToMAS，结构层面专门化）
- **DAG 分解与执行**：规划器（Planner）将每个任务实例分解为依赖感知的**有向无环子任务图** G=(V,E)，每个节点 vi 携带自然语言子任务描述 si。每个智能体被分配特定（角色 r，子任务 s）对。图以拓扑序执行，每个节点先由 **Merger**（汇总上游产物，r=merge）再由 **Executor**（执行当前子任务，r=execute）处理，可扩展至 review/refine 等角色。
- **规则验证器**：每个 DAG 节点上应用规则验证器（rule-based verifier）产生**逐步奖励** ui，并阻断失败的产物向下游传播，防止错误累积。这是后续策略优化的关键训练信号。

### 2.3 原型路由的（角色×子任务）LoRA 专家混合模块（MoLE，参数层面专门化）
- **双因子分解专家池**：专家池分为角色专家 Φr（每角色一个）和子任务专家 Φs（跨子任务共享），全部以 LoRA 对形式注入冻结骨干的最后 8 层 {q_proj, v_proj, o_proj}，秩 ρ=8。每次智能体调用，激活集 Ei = {e(ri)} ∪ Es,i（角色专家 + top-K 子任务专家，默认 K=2），通过加权求和合成 LoRA 投影：Wℓ(i) = Wℓ + Σk∈Ei wk·αρ·Bℓ,kAℓ,k。
- **合并节点的特殊处理**：Merger 节点从上游 Executor 继承子任务专家子集（而非经路由器选择），使合并角色接触产生上游产物时的相同子任务适配方向。
- **原型语义路由器**：通过冻结嵌入器 + 可训练投影 hη 将子任务描述 si 映射到与专家原型 P∈R^{Ks×D} 同一潜空间，用余弦相似度 + softmax 计算路由概率 πψ(k|si)，训练时随机采样 top-K、推理时贪心选取。该设计在开放子任务空间上诱导软语义划分，而非硬聚类。

### 2.4 分层组相对策略优化（HGRPO，稳定协同优化）
- **两层信用分配**：每节点采样 B=4 条专家路由（每条固定一个专家组合），每路由生成 M=4 个候选，由验证器打分。据此构造两种优势：
  - **路由内优势** A_within = (u(b,m) − μ(b))/(σ(b) + ε)，用于更新 LoRA 专家；
  - **跨路由优势** A_cross = (μ(b) − μ̄)/(σC + ε)，用于更新路由器参数。
- **方差减少理论保证**：分层 GRPO 与标准 GRPO 共享相同期望梯度，但**严格降低** LoRA 专家梯度的方差：Var[g_HGRPO] = Var[g_single] − σ²_C·E‖∇Φ log p‖²。（Prop. 3.1；归一化形式见 Cor. G.1，经每路由标准化处理后方差减少以加权形式保留。）该构造将路由决策引入的跨路由方差从专家更新中分离，确保专家质量与路由质量不互相纠缠。
- **更新流程**：LoRA 损失（式 7）和路由损失（式 8，权重 απ=0.15）分别更新、互不干扰。

### 2.5 训练算法流程
算法 1 概述了一次 HGRPO 更新：ToMAS 分解任务 → 按拓扑序遍历节点 → 路由器采样 B 条路由 → 每路由生成 M 个候选 → 验证器打分 → 计算分层优势 → 分别累积 LoRA 梯度与路由器梯度 → 更新参数。Merge 节点不涉及路由决策，仅用路由内优势更新合并角色专家。

## 6. 论文的主要结论与发现

- **结构分解本身有效**：未经训练的 MoRSE base 已超越全部基线（SRDD Exec 77.00 vs. 最佳基线 67.01，Qwen3-4B），证明（角色，子任务）DAG 分解在无训练时即优于角色提示型 MAS。
- **参数专门化带来进一步增益**：完整 MoRSE 在 Test Set 上实现全部指标列最优（SRDD Exec 86.25、ECI Product 0.360 via Qwen3-4B），且 MoLE 与 HGRPO 紧密耦合——移除任一个都导致增益大幅回落。
- **HGRPO 稳定训练是关键**：标准 GRPO 联合优化专家与路由器时，训练崩溃、增益消失；HGRPO 通过两层信用分配实现稳定协同优化，方差分析（Prop. 3.1）实证支撑。
- **学到的规格化可泛化（OOD）**：对保留类别/领域，MoRSE 一致优于未训练变体和固定 LoRA 微调基线（SRDD OOD Exec 提升 +6.25~+7.50），表明子任务级技能具有可迁移性。
- **跨骨干一致性**：从 4B 到 31B 规模，MoRSE 的框架级与训练级增益均保持，但在最强骨干（Gemma-4-31B）上提升幅度收窄——基座能力接近饱和 + 固定 LoRA 配置导致可训练参数占比随模型宽度缩小（0.170% → 0.048%）。

## 7. 优点与亮点

- **双层异质性的补充**：首次在任务结构（DAG 分解 + （角色，子任务）标签）与参数级（动态 MoLE 专家）两个层面同时实现智能体异质化，弥补了现有方法仅提示级区分的不足。
- **理论驱动的设计**：论文包含理论支撑：子空间分歧诊断（Figure 2）刻画了基座模型内部的角色/子任务失配；Theorem L.2 证明单一共享 LoRA 无法同时覆盖分歧子空间（覆盖上限 (1+√(1−Δ))/2≈0.75）；Prop. 3.1 证明 HGRPO 的方差减少性质。
- **预算意识的训练设计**：MoLE 在共享冻结骨干上以每调用 1 角色 + top-2 子任务专家（激活参数 3.24M vs. 总参数 6.49M）实现参数级专门化，成本接近单模型。
- **信用分配的清晰解耦**：HGRPO 通过条件基线将“专家质量”与“路由质量”分离，是一种在路由器-专家结构轴上的信用分解，与沿时间轴的层级 GRPO 变体正交且可组合。
- **充分的验证手段**：除标准基准外，包含预算匹配对照组、OOD 评估、执行验证的独立评估、路由器利用诊断、训练动力学对比等多角度证据，提高结论可信度。

- **子任务专家规模固定**：默认 Ks=4 个子任务专家，文中承认“刻意保守且从未在验证集上调参”，不声称最优；重尾子任务分布可能需要更大专家池 + 每实例自适应分配。
