## 摘要
人工智能代理预计将在未来的决策系统中发挥越来越重要的作用。在本文中，我们考虑了由异构多智能体系统（MAS）组成的协作系统，其中各个成员具有不同的能力和运营成本。我们研究了智能体如何相互委托任务，以便在资源受限的场景下有效完成某些研究任务。我们首先开发了一种基于多智能体强化学习（MARL）的委托训练方法，使智能体能够做出顺序委托决策，同时最小化总执行成本。然后，我们将这种方法扩展到具有预定委托拓扑的MARL。此外，我们引入了两个用于多智能体系统中协作与委托的新框架。第一个框架提出，智能体的策略不仅依赖于底层马尔可夫决策过程的当前状态，还依赖于交互历史，包括先前的联合动作。这种历史相关表述即使在完全可观察的环境中也能改善协调，而传统MARL方法通常将策略限制为仅依赖于当前状态。第二个框架提出了一种新颖的、可能是多维的货币机制，以促进多智能体系统的协作与委托。

## Abstract
AI agents are expected to play an increasingly important role in future decision-making systems. In this paper, we consider collaborative systems composed of heterogeneous multi-agent systems (MAS), where their members have different capabilities and operating costs. We study how agents can delegate tasks to one another so that certain research tasks can be completed effectively under resource-constrained scenarios. We first develop a multi-agent reinforcement learning-based (MARL) delegation training that enables agents to make sequential delegation decisions while minimizing the total execution cost. We then extend this approach to MARL with prescribed delegation topologies. Furthermore, we introduce two new frameworks for collaboration and delegation in multi-agent systems. The first framework proposes that an agent's policy depends not only on the current state of the underlying Markov decision process but also on the interaction history, including previous joint actions. This history-dependent formulation can improve coordination even in fully observable environments, where conventional MARL methods typically restrict policies to depend only on the current state. The second framework proposes a novel, potentially multi-dimensional monetary mechanism to facilitate the collaboration and delegation for MAS.

## 2. 论文提出的方法论

### 2.1 核心思想

论文将任务委托建模为一个**协作马尔可夫博弈（Markov Game, MG）**，作为底层预训练策略之上的一个"包装层（wrapper layer）"。代理可以选择**执行自己的预训练策略、委托给其他代理、或不执行（no-op）**。联合目标是最大化团队总回报，其中考虑环境奖励与执行/委托成本。

### 2.2 三类委派机制

1. **管理约束（Management Constraints）**：
   - 采用严格的等级结构（如 A → B → C），上级可以强制向下级委托任务。
   - 每个代理的动作空间扩展为：原始动作 ∪ 委托动作 ∪ {no-op}。
   - 每步只有一个代理实际执行任务。
   - 单步奖励定义为：\( R_i(s,a) = \alpha \bar{R}(s, a_{\text{exec}}) - \beta C_i(a_i) \)，其中环境奖励与执行/委托成本以缩放因子加权。

2. **委托约束（Delegation Constraints）**：
   - 通过**有向图**表示任意代理之间的委托关系（不再是严格的等级链）。
   - 允许多个代理同时执行（只要有人被委托且其选择执行）。
   - 每个 episode 开始时由"oracle"选择一个非空启动子集，然后各代理选择是否执行或委托。

3. **货币交易机制（Transferable Money）**：
   - 引入与**环境奖励分离**的虚拟货币余额 \( w_{it} \)，作为历史交互的**紧凑摘要**。
   - 代理可以选择物理动作 \( a_{it} \) 和货币转移动作 \( p_{it} \)。
   - 货币转移动作由合同 \( \text{Cr}_i: A \to \mathbb{R}^{n-1} \) 决定，即根据联合动作支付固定价格。
   - 余额不足时（\(\|p_{it}\|_1 > w_{it}\)），目标联合动作不可行，需转为可负担的动作。
   - 货币不直接进入奖励函数，仅作为内部协调和委托的媒介。

### 2.3 历史依赖策略（History-dependent Policies）

- **定义**：策略不仅依赖当前状态 \( x_t \)，还依赖公共历史 \( h_t = (x_1, a_1, x_2, a_2, \ldots, x_{t-1}, a_{t-1}, x_t) \)，其中包含所有过去的状态和联合动作。
- **理论动机**：通过一个两代理、两步博弈的实例证明，历史依赖策略可以支持**互惠机制**（agent B 根据 agent A 是否在第一步做出代价高昂的助人行为来决定第二步是否回报），从而达成**更高收益的纯策略纳什均衡**；而 Markov 策略无法表达这种跨期激励。
- **算法**：提出**两步纳什值迭代算法（Algorithm 1）**，通过逆向归纳求解确定性历史依赖纯策略纳什均衡（在多个均衡中优先选择对指定代理有利的策略），并给出**定理 1** 证明其输出的策略是一个纯策略子博弈完美纳什均衡。该算法可递推扩展到 n 步动态博弈。

## 3. 实验设计

### 3.1 数据集与基准

- **基准数据集**：GSM8K（小学数学应用题）。选择原因：有参考答案可自动判分；能力差异显著；规模足够划分固定能力映射、训练池和测试集。
- **三个冻结求解器**：
  - Solver A：Nemotron 3 Ultra（最强、最贵）
  - Solver B：Llama 3.2 3B Instruct（中等）
  - Solver C：Llama 3.2 1B Instruct（最弱、最便宜）
- **价格设定**：合成 token 价格（实验参数，非真实账单）。
- **离线缓存**：每个求解器对所有问题一次性回答并缓存答案和正确性标签，训练过程中不实时调用求解器，保证可复现性。

### 3.2 对比方法与基线

- **always-Ultra**：所有问题始终发送给最强求解器 A（无委派）。
- **管理约束实验**：学习到的 DQN 协调器（3 条链式路由：A 单独、A→B、A→B→C）。
- **委托约束实验**：学习到的图协调器（7 种启动子集 × 3^3 局部选择 = 189 个离散联合动作），同时对比冻结的管理协调器（Mgmt. π）在同一批测试数据上的表现。
- **货币机制实验**：独立 Q-learning（IQL）有/无货币转移机制两种对比。

### 3.3 主要实验结果

**实验 1：管理约束**
| 指标 | DQN+map | always-Ultra |
|---|---|---|
| Return | 27.56 ±0.32 | 23.90 ±0.30 |
| Accuracy | 0.982 ±0.002 | 0.971 ±0.002 |
| Cost ($/ep) | 0.033 ±0.002 | 0.063 ±0.002 |

→ 收益约 +3.7，成本约减半（1000 episodes 累计 $31.1 vs $60.8），20 个种子全部优于基线（Wilcoxon 检验 p = 2⁻¹⁹）。

**实验 2：委托约束**
| 指标 | DQN+map | always-Ultra | Mgmt. π |
|---|---|---|---|
| Return | 25.20 ±0.42 | 23.31 ±0.30 | 28.70 ±0.18 |
| Accuracy | 0.961 ±0.005 | 0.971 ±0.002 | 0.986 ±0.001 |
| Cost ($/ep) | 0.043 ±0.002 | 0.068 ±0.002 | 0.024 ±0.001 |

→ 图委派优于不委派，但严格层级管理策略在当前设定下更强、成本更低。

**实验 3：货币交易机制**
- 5000 episodes、每 episode 20 步的两代理交替主动博弈（帮助他人需付出个人成本 -1 但使对方获得 +100）。
- 无货币的 IQL：两代理均学会不合作，episodic 回报为 0。
- 有货币的 IQL：代理学会在对方回合支付 1 单位货币以契约式要求对方选择 Yes，实现全额合作，episodic 环境回报达 990。

## 6. 论文的主要结论与发现

1. **委托策略可以显著节省成本**：学习到的 MARL 委派层能以约一半的执行成本获得比"全用最强模型"更高的任务收益和准确率。
2. **历史依赖策略优于 Markov 策略**：在完全可观测环境中，基于交互历史的策略可以支持互惠、信任和跨期激励，实现传统 Markov 策略无法表达的更高收益均衡。
3. **货币转移机制能促成协作**：与环境奖励分离的可转移货币余额可作为历史交互的紧凑摘要，在分布式 Q-learning 中成功促成完全合作（从 0 回报提升到 990）。
4. **委派拓扑结构影响效果**：在给定实验设定下，严格层级委派优于自由图委派（自由委派导致过度依赖弱求解器和多代理同时执行，反而降低整体表现）。

## 7. 优点

- **问题新颖且实用**：将"委派"本身建模为可学习的序贯决策，区别于集中式路由方法，允许代理自主决定是否执行、委托或拒绝，更贴近真实组织协作。
- **理论贡献扎实**：通过具体反例证明了历史依赖策略相对于 Markov 策略的表达力优势，并提供了可证明收敛到纯策略子博弈完美纳什均衡的算法（含定理和完整证明）。
- **方法设计具有独立性**：委派层与底层预训练策略解耦，可与其他 LLM-MARL 方法（如 MAGRPO、CoLLM）互补结合；货币机制可与环境奖励分离，适用场景更广。
- **实验规范且可复现性高**：离线缓存答案避免训练中调用求解器的不确定性；20 个种子+统计检验；附录 D 详细记录了超参数、数据划分、成本核算方式等复现所需细节。
- **对领域有清晰定位**：在相关工作部分明确区分了与 FrugalGPT、RouteLLM、MAGRPO、GPTSwarm、peer-incentive、reputation-based 等方法的差异，研究边界清晰。

## 8. 不足与局限

- **实验覆盖有限**：仅在 GSM8K（数学应用题）上验证了管理/委托约束的有效性，未覆盖代码、对话、工具使用等其他 LLM 任务场景；货币机制实验使用简化的两代理博弈，未在更复杂 MAS 或真实 LLM 成本上进行验证。
- **对比欠缺广度**：未与现有路由方法（如 RouteLLM、MasRouter）和 LLM-MARL 方法（如 MAGRPO、CoLLM）在同一基准上进行直接数值对比；此外"always-Ultra"是一种比较简单的基线，更强的放送基线（例如基于难度阈值的规则路由）也可纳入比较。
- **均衡求解效率问题**：论文使用的两步纳什值迭代算法依赖对纯策略纳什均衡的枚举和穷举搜索，计算复杂度高，难以扩展到大规模代理和多步场景（作者在结论中已承认需要更高效的算法）。
- **货币机制设计有待深化**：文中指出未解决基于历史的联合动作定价问题；货币转移机制在实验中的设定较简化（固定价格、单次转移），未探索多维货币、动态定价、历史依赖合同等更丰富的设计。
- **委派策略与预训练策略的关系**：委派策略的训练假设底层智能体是"冻结"的，未考虑当受委托代理知道自己被选择时是否会改变行为（即策略对选择的反应性），在对抗或自私场景下可能出现策略循环。
- **环境假设简化**：采用完全信息假设（知道所有代理的能力和成本），在现实环境中这一信息往往不可得，需要额外的估计机制。
