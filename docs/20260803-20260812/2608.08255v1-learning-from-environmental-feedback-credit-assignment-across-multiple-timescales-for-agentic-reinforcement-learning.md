## 摘要
智能体强化学习（Agentic RL）在现实环境中常常面临奖励延迟且稀疏的问题。为解决这一挑战，信用分配（credit assignment）提供了一种有前景的方案，其目标是将轨迹级别的奖励进行分解，并为中间决策提供更细粒度的监督。然而，现有的信用分配方法忽略了环境交互过程中自然产生的丰富过程信息，例如交互历史。我们认为，这类信息为识别单个动作的贡献提供了宝贵的监督信号。为此，我们提出了基于环境反馈的信用分配方法（EFCA），一种面向长时程智能体强化学习的多时间尺度信用分配方法。EFCA 用两种基于环境的信号补充长期结果信号：捕捉当前动作即时效应的短期反馈信号，以及从近期交互中识别无效模式的中间状态-历史信号。这两种信号均直接源于环境反馈，并通过回报重加权机制进行整合。在 ALFWorld 和 WebShop 上的实验表明，EFCA 在任务成功率和任务质量上均持续优于强基线，凸显了基于环境的多时间尺度信用分配在长时程智能体强化学习中的有效性。

## Abstract
Agentic reinforcement learning (RL) often suffers from delayed and sparse rewards in real-world environments. A promising solution to this challenge is credit assignment, which aims to decompose trajectory-level rewards and provide more fine-grained supervision for intermediate decisions. However, existing credit assignment approaches ignore the rich process information naturally generated during environment interaction, e.g., interaction history. We argue that such information provides valuable supervision for identifying the contribution of individual actions. To this end, we propose Environmental Feedback-based Credit Assignment (EFCA), a multi-timescale credit assignment approach for long-horizon agentic RL. EFCA complements the long-term outcome signal with two environment-grounded process signals: a short-term feedback signal that captures the immediate effect of the current action and a medium-term state-history signal that identifies ineffective patterns from recent interactions. Both signals are directly extracted from environment feedback and integrated through a return reweighting mechanism. Experiments on ALFWorld and WebShop demonstrate that EFCA consistently improves both task success and task quality over strong baselines, highlighting the effectiveness of environment-grounded multi-timescale credit assignment for long-horizon agentic RL.

## 2. 论文提出的方法论

### 2.1 核心思想
- 在原有步骤级回报（`R_base_t`，通常由折扣累积未来奖励得到）基础上，引入两种**环境扎根的过程信号**：
  - **短期反馈信号（short-term feedback signal）**：判断当前动作是否产生即时的、有意义的局部进展。
  - **中期状态-历史信号（medium-term state-history signal）**：利用近期动作-反馈历史，识别重复无效行为或短视行为循环。
- 两种信号通过**回报重加权机制**整合进原有步骤级回报，以增强对局部有效动作的监督并抑制重复无效行为。

### 2.2 关键技术细节

#### 步骤级回报基础定义
给定轨迹 `τ = {(o_t, a_t, f_t, r_t)}_{t=1}^T`，基础步骤回报为：

```
R_base_t = Σ_{t'=t}^{T} γ^{t'-t} r_{t'}
```

其中 `r_{t'}` 是第 `t'` 步奖励，`γ` 是折扣因子。该定义无法区分同一轨迹内部不同步骤的贡献差异。

#### 综合信用得分
```
C_t = α · c_fb_t + β · c_hist_t
```
- `c_fb_t`：短期反馈信用；`c_hist_t`：中期状态-历史信用；`α`、`β` 为权重系数。

#### 短期反馈信用 `c_fb_t`
- 对反馈文本 `f_t` 进行归一化处理（`φ`），并与预定义的正/负反馈模式集合匹配：
  - 若匹配到负向模式（如 “Nothing happens”），`c_fb_t = -1`；
  - 否则若匹配到正向模式（如 “You open …”、“You pick up …”），`c_fb_t = +1`；
  - 否则 `c_fb_t = 0`。
- 正负模式集直接来源于环境反馈文本（如 ALFWorld、WebShop 中的环境消息），无需外部标注。

#### 中期状态-历史信用 `c_hist_t`
- 定义大小为 K 的近期反馈窗口：
  ```
  W_K(t) = {i | max(1, t-K+1) ≤ i ≤ t}
  ```
- 统计窗口中负反馈和正反馈数量：
  ```
  N_t^- = Σ I[c_fb_i = -1]
  N_t^+ = Σ I[c_fb_i = +1]
  ```
- 规则：
  - 若窗口填满 K 且全部为负反馈：`c_hist_t = -1`（捕获连续失败模式）；
  - 否则若窗口填满 K 且没有任何正反馈：`c_hist_t = -η`（η∈(0,1)，轻度停滞惩罚）；
  - 否则 `c_hist_t = 0`。

#### 回报重加权
```
w_t = clip(1 + λ · C_t, w_min, w_max)
R_tilde_t = w_t · R_base_t
```
- `λ` 控制整体重加权强度；`w_min`、`w_max` 为裁剪边界，保证稳定性。
- 当 `C_t > 0` 时放大步骤回报，当 `C_t < 0` 时抑制步骤回报，从而提供更具判别性的步骤级监督。

#### 算法流程（文字说明）
1. 对轨迹中每一步计算基础折扣回报 `R_base_t`。
2. 对每一步环境反馈进行归一化，并根据正负模式集分配短期反馈信用 `c_fb_t`。
3. 基于最近 K 步的反馈信用统计正负信号数量，计算中期状态-历史信用 `c_hist_t`。
4. 线性组合两种信用得到综合信用得分，并经裁剪变换为步骤权重。
5. 用该权重乘以基础回报，得到最终重加权回报，供步骤级策略优化方法（如 GiGPO、HGPO）使用。

### 2.3 特点
- 不引入显式价值网络或奖励模型；
- 作为插件式模块，可直接嵌入现有步骤级优化管线；
- 计算开销极低（仅需文本匹配、窗口计数和标量乘法）。

## 6. 论文的主要结论与发现

- EFCA 在 ALFWorld 上优于 HGPO、GiGPO、GraphGPO 等强基线，且在两个骨干规模下均取得最高总体得分：
  - Qwen2.5-1.5B：总体得分 95.31，比 HGPO 高 +3.32，比 GiGPO 高 +4.43，比 GraphGPO 高 +2.60；
  - Qwen2.5-7B：总体得分 96.03，比 HGPO 高 +4.04，比 GiGPO 高 +1.76，比 GraphGPO 高 +0.72。
- 在 WebShop 上，EFCA 的 **Task Score** 在两个骨干下均最优（1.5B 达 89.81，7B 达 89.06），说明 EFCA 不仅能提高动作完成度，更能提升最终购买与用户需求的任务级匹配质量。
- 训练动态显示：EFCA 的平均重加权比例随训练逐渐上升并稳定在 1.4–1.5 左右，说明策略逐渐产生更多被过程证据支持的优秀动作；重加权回报的标准差更大，说明信用分配更具判别性。
- 消融实验表明：短期反馈信号与中期状态-历史信号均不可缺失，两者互补；中等强度的重加权（λ=0.4）、适中的状态历史系数（β=0.8）和反馈系数（α=1.5）效果最佳，过强惩罚或过重加权会引入噪声，降低性能。

- **模式设置有可靠性设计**：模糊的反馈不赋予信用（设为 0），降低了噪声注入风险。
