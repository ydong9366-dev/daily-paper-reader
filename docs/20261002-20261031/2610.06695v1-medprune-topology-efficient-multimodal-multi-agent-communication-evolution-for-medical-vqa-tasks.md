## 摘要
尽管医学多模态大语言模型（Med-MLLMs）推动了医学视觉问答（VQA）的发展，现有受临床工作流启发的多智能体框架仍受交互模式以及冗余通信拓扑带来的过高计算开销困扰。本文提出MedPrune，一种高效的医学多模态多智能体协作框架，可从通信拓扑中动态剪枝节点和边，以增强推理能力并提升token效率。具体而言，我们首先将诊断过程建模为异质通信图，其中节点表示来自不同科室的专科智能体，边刻画科室内与科室间交互。基于该图，我们引入两种稀疏化机制以实现自适应协作演化：（1）异质节点稀疏化，通过强化学习驱动的拓扑优化剔除与当前多模态问题无关的专科智能体；（2）异质边稀疏化，通过联合优化任务性能与拓扑复杂度，仅选择性保留最具诊断显著性的科室内和科室间连接。在完整集和少样本训练设置下的大量医学VQA实验证明，MedPrune优于多智能体基线，并在具有强对抗鲁棒性的同时提升token效率。

## Abstract
While medical multimodal large language models (Med-MLLMs) advance medical visual question answering (VQA), existing clinical workflow-inspired multi-agent frameworks suffer from interaction patterns and excessive computational overhead caused by redundant communication topologies. In this paper, we propose MedPrune, an efficient medical multimodal multi-agent collaboration framework that dynamically prunes both nodes and edges from the communication topology to enhance reasoning ability and token efficiency. Specifically, we first formulate the diagnostic process as a heterogeneous communication graph, where nodes represent specialist agents from various departments and edges capture intra- and inter-departmental interactions. Building on this graph, we introduce two sparsification mechanisms to enable adaptive collaborative evolution: (1) Heterogeneous Node Sparsification, which eliminates task-irrelevant specialist agents irrelevant to the current multimodal question via reinforcement learning-driven topological optimization, and (2) Heterogeneous Edge Sparsification, which selectively retains only the most diagnostically salient intra- and inter-departmental connections by jointly optimizing task performance and topological complexity. Extensive medical VQA experiments under full-set and few-shot training settings prove MedPrune surpasses multi-agent baselines and boosts token efficiency with strong adversarial robustness.

## 二、方法论

### 2.1 核心思想
- 将多轮诊断对话建模为异质图 \(G=(V, E_T, E_S, M)\)：
  - 节点 \(V\)：各专科智能体（如放射科、呼吸科、心内科的主任/普通医生）；
  - 边：**空间边** \(E_S\)（同轮连接）与**时间边** \(E_T\)（跨轮连接），并进一步区分**科室内**与**科室间**；
  - 记忆 \(M\)：每个智能体按 MLLM 函数聚合自身记忆、问题 \(q\) 及时空邻居消息进行更新。
- 最终由总结智能体汇总各科主任意见输出答案。
- 两级稀疏化：先剪**节点**（无关专科），再剪**边**（冗余连接），全程冻结 MLLM 参数，仅优化轻量软邻接矩阵。

### 2.2 异质节点稀疏化
- **边权初始化**：由二值邻接矩阵 \(A_S, A_T\) 出发，用 **Gumbel-Softmax** 参数化为可微软邻接矩阵 \(\tilde A_S, \tilde A_T\)，并按轮次 \(t\) 分别参数化。
- **消息传递**：科室内、科室间分别按软邻接矩阵 softmax 归一化得到注意力权重，聚合同科室/跨科室空间消息；时间消息传递类似。
- **优化目标**：最大化期望任务性能 \(\arg\max_{\tilde A_S,\tilde A_T} \mathbb{E}_{G\sim\mathcal{G}}[\phi(G)]\)。
- **策略梯度**：因 MLLM 可能为不可微 API，采用 REINFORCE 式近似，采样 \(K\) 个图实例估计梯度：
  \[
  \nabla \mathbb{E}[\phi(G)] \approx \frac{1}{K}\sum_{k=1}^{K}\phi(G_k)\nabla\log P(G_k)
  \]
- **一次性剪枝**：按加权入度+出度排序，剪掉每轮中度数最小的 \(\alpha\) 比例节点及其关联边。

### 2.3 异质边稀疏化
- 在节点剪枝后的子图上**重新初始化边权**，采用复合目标：
  \[
  \arg\max \mathbb{E}_{G\sim\mathcal{G}_{Node}}[\phi(G)] - \|\tilde A_S\|_* - \|\tilde A_T\|_*
  \]
  即最大化任务性能同时用**核范数**惩罚鼓励低秩稀疏结构，并约束与原始二值矩阵的 Frobenius 偏差不超过 \(\delta\)。
- 分别对**科室内**与**科室间**边做类似优化。
- **渐进式剪枝**：先剪科室内边、再剪科室间边；每轮保留权重最高的 \((1-p^{(t)})\) 比例边，剪枝率按指数衰减 \(p^{(t)}=p^{(t-1)}\cdot e^{-t/T}\)。

### 2.4 迭代训练流程
- 两阶段交替：节点稀疏化损失 \(L_n=-\mathbb{E}[\phi(G)]\)；边稀疏化损失 \(L_e=-\mathbb{E}[\phi(G)]+\|\tilde A_S\|_*+\|\tilde A_T\|_*\)。
- 仅优化拓扑模块参数，视觉语言主干完全冻结；训练后经 DAG 采样得到最终通信图 \(\hat G\)。

- **超参稳健**：轮数 \(T\)、噪声 \(\delta\)、智能体数量、剪枝率在一定范围内性能稳定，过度剪枝或过少剪枝均次优。

## 七、优点

- **问题建模清晰**：将临床多科会诊形式化为异质时空图，科室内/科室间、空间/时间边区分细致，贴合医学协作语义。
- **两级稀疏化互补**：节点剪枝直接消除无关专科的 token 开销，边剪枝进一步去除冗余对话，二者结合从根源上缓解多智能体通信膨胀。
- **训练轻量**：冻结 MLLM 主干，仅用策略梯度优化软邻接矩阵，1.5 GPU 小时即可完成拓扑训练，适合资源受限场景与不可微 API 模型。
- **无需微调即具少样本与跨域泛化能力**，避免训练密集型方法的数据依赖与灾难性遗忘。
- **鲁棒性设计有亮点**：节点-边联合剪枝天然具备隔离被污染智能体的能力，对抗攻击下性能保持率高。
- **实验矩阵较全面**：多数据集、多骨干、多训练预算、多攻击、提示敏感性、跨域迁移、案例可视化，论证链条完整。

## 八、不足与局限

- **超参未充分优化**：节点剪枝率 \(\alpha\)、噪声容限 \(\delta\)、渐进剪枝率等关键超参未在所有科室组合与成像模态上穷举调优，最优剪枝强度可能随问题复杂度变化，缺乏自适应调度机制。
- **部门选择依赖外部启发式**：候选科室由冻结的 Qwen3.6-Plus 做相关性排序筛选，未纳入强化学习联合优化，流程仍依赖外部排序模块，增加部署复杂度。
- **规模验证有限**：仅在最多 15 个智能体、3 个科室场景下验证；未评估数十个亚专科智能体的大规模场景，策略梯度在组合动作空间扩大后的可扩展性未知。
- **通信轮数偏少**：主实验固定 \(T=2\)，虽做了 \(T=4/6/8\) 的补充，但更长轮次下的拓扑演化与收敛性讨论不足。
- **对抗鲁棒性验证范围窄**：仅在 MIMIC-CXR + Qwen3-VL 上做两类攻击，未覆盖多模态输入扰动、跨数据集攻击或针对拓扑本身的攻击。
- **评测指标局限**：MIMIC-CXR 采用 BLEU/ROUGE/BERT-F1/METEOR 等生成指标，与临床诊断正确性之间存在差距；缺少临床医生人工评估或真实临床工作流验证。
- **潜在偏差风险**：智能体角色提示为人工模板（11 个科室固定描述），可能引入对特定科室组合的先验偏好；部门相关性排序由大模型完成，存在继承其偏见的风险。
- **应用限制**：依赖多轮 MLLM 调用，推理延迟与 API 成本在真实临床部署中仍需评估；对不可微 API 模型只能做黑盒策略梯度，方差较大、样本效率有限。
- **复现性**：代码与数据声明“接收后发布”，当前无法独立复现；部分基线（ARG-Designer）经作者改造适配多模态，比较公平性存在一定不确定性。
