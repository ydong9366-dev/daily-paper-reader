## 摘要
现有多智能体协作（MAC）方法主要探索了一种群体思考协作拓扑，其中智能体独立生成解决方案并聚合其输出。在本工作中，我们研究了一种替代的接力思考拓扑，其中推理所有权在智能体之间动态转移，使后续智能体能够继承并改进不断演化的推理轨迹。我们引入了多智能体置信度引导接力（MACR）框架，该框架能够在智能体之间实现动态接力协作。关键挑战在于确定何时应接力推理以及哪个智能体应继续该过程。该方法通过置信度引导的接力触发以及一种根据智能体置信度选择下一智能体的竞价机制来应对这一挑战。在四个基准上的实验表明，该方法在准确率上优于最强的单模型策略，例如在 MathVista 上 +3.3%、在 MMStar 上 +3.9%，并且在 HallusionBench 和 MMStar 上消耗的 token 开销少 6.0 倍，同时与多智能体策略保持相当。进一步分析表明，接力协作使异构智能体能够逐步整合互补见解，在推理各阶段结合异构能力。我们的源代码可在 https://github.com/67L1/MACR 获取。

## Abstract
Existing multi-agent collaboration (MAC) methods have primarily explored a group thinking collaboration topology, where agents independently generate solutions and aggregate their outputs. In this work, we investigate an alternative relay thinking topology, where reasoning ownership is dynamically transferred across agents, allowing subsequent agents to inherit and refine an evolving reasoning trajectory. We introduce Multi-Agent Confidence-guided Relay (MACR), a framework that enables dynamical relay collaboration among agents. The key challenge is determining when reasoning should be relayed and which agent should continue the process. method addresses this challenge through confidence-guided relay triggering and a bidding mechanism that selects the next agent based on its confidence. Experiments on four benchmarks show that method outperforms the strongest single-model strategies in accuracy, e.g., +3.3% on MathVista and +3.9% on MMStar, and remains on par with multi-agent strategies while consuming 6.0x less token overhead on HallusionBench and MMStar. Further analysis demonstrates that relay collaboration enables heterogeneous agents to progressively integrate complementary insights, combining heterogeneous capabilities across reasoning stages. Our source code is available at https://github.com/67L1/MACR.

## 1. 核心问题与研究动机

- **背景**：LLM/MLLM 在复杂推理中常遇到“中间推理瓶颈”，单一模型难以继续推进；多智能体协作（MAC）被视为利用互补能力突破瓶颈的有效途径。
- **现有范式局限**：主流 MAC 采用“群体思考”（group thinking）拓扑——各智能体**并行独立**生成完整解答，再通过讨论、投票或聚合得到最终答案。其问题是推理轨迹彼此割裂，后续智能体无法继承、修正前序智能体的中间推理。
- **论文主张**：借鉴认知科学中的“接力思考”（relay thinking）——一名参与者形成中间想法后，把“推理所有权”移交他人继续精炼——提出**接力式 MAC 拓扑**：推理轨迹在异构模型间顺序传递、逐步演化与整合。
- **关键挑战**：需要回答三个问题——**何时**接力（触发时机）、**谁来**接力（下一棒选择）、**谁先**开始（初始主导模型）。
- **置信度信号的双重障碍**：置信度可指示推理可靠性，且正确/错误轨迹在置信度上可分；但异构模型（架构、词表、概率分布不同）的原始置信度**不可直接比较**（ANOVA F=13.31），必须先校准。

## 2. 方法论：MACR 框架

### 2.1 核心思想
以**校准后的局部（窗口级）置信度**为统一信号，构建在线“**initiation → monitoring → bidding → relay**”闭环，在主导模型出现推理瓶颈时实时中断生成，把生成权移交给当前置信度最高的模型，并让其输出直接续接共享上下文。

### 2.2 关键技术细节

- **局部置信度计算**：对模型 $m$ 的 token 对数概率序列，用大小 $w$ 的滑动窗口取均值，得到窗口级置信度 $W^{(w)}_{i,m}$，用于捕捉“局部瓶颈”而非整段序列置信度。
- **置信度偏移验证**：在 MMMU 随机采样 1,000 条实例，让三个模型（Qwen3-VL-8B-Instruct、InternVL3.5-8B、MiniCPM-V-4.5-8B）推理，KDE 可视化 + 单因素 ANOVA。原始置信度 **F=13.31 ≫ 1**，证明组间差异远大于组内噪声，跨模型不可比。
- **标准化校准**：用历史参考数据统计每个模型在每个窗口尺寸下的局部均值 $\mu^{(w)}_m$ 与标准差 $\sigma^{(w)}_m$，做 z-score 标准化 $Z^{(w)}_{i,m}=(W^{(w)}_{i,m}-\mu^{(w)}_m)/\sigma^{(w)}_m$。校准后 **F 降至 1.01 ≈ 1**，跨模型偏移被消除。
- **正确性可分性验证**：按答案正确/错误分组绘制标准化置信度 KDE，正确轨迹局部置信度更高，支持“低置信度≈遇到瓶颈”的假设。

### 2.3 在线调度流程（算法 1）

1. **Initiation（初始化）**：所有候选模型基于初始上下文各生成 $w$ 个 token，计算平均对数概率并校准，选 $Z$ 最大者为初始主导模型 $m^*$。
2. **Monitoring（监控）**：主导模型正常自回归生成，每步用滑动窗口计算并校准局部置信度；若 $Z^{(w)}_{t,m^*}<\tau$，判定遇到瓶颈，**立即停止生成**并触发竞价。
3. **Bidding（竞价）**：将当前上下文同步给所有模型，各自试生成 $w$ 个 token 候选序列，按校准置信度取最大者：$m^*=\arg\max_m \frac{1}{w}\sum_j \log p_m(\cdot)-\mu_m^{(w)}/\sigma_m^{(w)}$。
4. **Relay（接力）**：把胜出模型的候选序列**直接拼接**进共享上下文 $X_{t+w}=X_t\oplus T_{m^*}$；各模型**独立维护自己的 KV cache**，避免重复 prefill；生成权移交后继续监控，直至完成。
- **超参数**：窗口 $w=16$、阈值 $\tau=-0.3$，在 RealWorldQA 的 600 条采样实例上搜索得到，且与所有评估集不相交。

  - HallusionBench（951）：视觉与知识幻觉诊断。
- **模型池**：Qwen3-VL-8B-Instruct、InternVL3.5-8B、MiniCPM-V-4.5-8B（三个异构 8B 级 MLLM）。
- **对比基线**：

  - 多智能体策略：Majority Vote（MV）、H-DMAD（为不同智能体分配 CoT/CCoT/DDCoT 等不同推理策略后融合）。

## 6. 主要结论与发现

- **准确率**：MACR 全面优于最强单模型策略——MathVista 78.00% vs 74.70%（+3.30），MMStar 72.00% vs 68.13%（+3.87），LogicVista 55.80% vs 54.24%，HallusionBench 74.66% vs 73.61%。
- **效率**：与多智能体策略精度相当，但 token 开销显著更低——HallusionBench 4,414 vs 26,375（约 6.0×），MMStar 4,150 vs 24,677；IBC 全数据集领先（MMStar 21.35，远高于 H-DMAD 的 2.83）。
- **定性表现**：单模型 CoT 常锚定局部线索（光照、纹理、局部形状），MACR 能将碎片线索整合为全局推理链；即使在最终答错的失败案例中，MACR 仍表现出更全面的全局整合倾向。
- **能力互补**：转移矩阵显示双向接力频繁（MiniCPM 自转移 59.7%，仍有 40.3% 让渡；InternVL→Qwen 22.4%，Qwen 回流 26.9%），无单一模型绝对主导。
- **阶段互补**：生存分析显示 MiniCPM 早期存活最强（number at risk 3,151，约为另两者两倍），InternVL 长程保持更好，Qwen 长程保持最弱——模型在不同推理阶段各有所长。
- **任务无关的瓶颈定位**：逻辑类任务（LogicVista、MathVista）接力集中在早期，视觉类任务（MMStar、HallusionBench）集中在后期，末段接力频率收敛。
- **词汇层面的瓶颈差异**：InternVL 多在分析性证据提取处卡顿（analyze/examine/identify），MiniCPM 多在空间定位与属性绑定处（position/top/left），

，Qwen 则更多出现在结论归纳/选项比对类词汇处，说明不同模型的“瓶颈语义”不同，接力恰好能把不同模型从各自不擅长的局部环节中解救出来。

## 7. 局限性与可讨论之处

- **模型池规模与同质性**：主实验仅使用三个 8B 级 MLLM，且均为开源中文/中英双语能力较强的模型；论文虽用 RPH/TDH 两种同质化协作模式作为对照，证明“异构性”是收益来源之一，但未验证在更大模型（如 30B+、闭源 API 模型）或能力差距悬殊的模型池中，校准与竞价是否仍然稳定。
- **校准依赖参考数据**：z-score 校准需要为每个模型、每个窗口尺寸预先统计局部置信度的均值与方差，这部分参考数据的来源、规模与领域覆盖度未被充分披露；若部署到分布外任务，校准参数可能漂移，进而影响阈值 $\tau$ 的有效性。
- **阈值与窗口的敏感性**：$w=16$、$\tau=-0.3$ 仅在 RealWorldQA 上搜索得到，论文未给出 $\tau$ 与 $w$ 的敏感性曲线（如 $\tau$ 在 $[-0.6,0]$ 区间变化时精度/token 的权衡），因此该超参配置的鲁棒性证据有限。
- **系统开销未量化**：竞价阶段需要所有候选模型对同一上下文并行试生成 $w$ 个 token，且每个模型维护独立 KV cache；虽然 token 数远低于多智能体基线，但**并行前向的 wall-clock 延迟、显存峰值**未报告，实际部署的性价比仍不明确。
- **“置信度≈正确性”的假设**：方法以低置信度作为瓶颈信号，但低置信度也可能出现在“困难的正确推理”处（如长链计算中的正常不确定），此时中断并换手可能引入不必要的上下文切换成本；论文未分析误触发（false trigger）的比例及其对最终精度的影响。
- **统计严谨性**：仅报告 3 个种子的均值±标准差，未做配对显著性检验；部分提升幅度（如 LogicVista +1.56、HallusionBench +1.05）相对标准差是否显著，读者难以判断。

## 8. 学术贡献与启示

- **概念贡献**：把认知科学中的“接力思考”形式化为可计算的多智能体拓扑，与主流“群体思考/并行聚合”形成清晰对照，为 MAC 研究提供了一个新的拓扑维度（顺序接力 vs. 并行独立）。
- **技术贡献**：指出并实证了异构模型置信度不可直接比较这一被广泛忽视的问题（ANOVA F=13.31 → 校准后 1.01），并给出轻量、无需训练的窗口级 z-score 校准方案，该组件可迁移到任何需要跨模型置信度融合的场景（如路由、集成、early-exit）。
- **调度贡献**：将“何时接力 / 谁来接力 / 谁先开始”三个问题统一为“校准置信度驱动的 initiation–monitoring–bidding–relay”闭环，且完全在推理时完成，不需要额外训练或标注，工程落地门槛低。
- **实证贡献**：在 4 个多模态基准上同时给出精度、token 与 IBC 三维证据，说明“顺序接力”在效率上显著优于“并行多智能体讨论”（约 6× token 节省），为多智能体系统的成本-收益权衡提供了可复用的评测范式（IBC 指标）。
- **分析贡献**：转移矩阵、生存分析、瓶颈位置分布与词汇分布四类机制分析，从“模型间”“阶段间”“任务间”“词元间”四个粒度刻画了能力互补的具体形态，超出了单纯的精度对比，具有一定的可解释性价值。
