## 摘要
长时程具身智能体面临时间混淆以及记录不完整或失真、固定记忆规则导致的重复性错误，以及不断增长的存储与检索成本。我们提出 BetaMem，一个通过六个相互关联的层级来构建和演化可追溯长期记忆的框架：工作记忆、空间记忆、实体记忆、情景记忆、经验记忆和程序记忆。双层写入契约约束操作的可行性以及内容的来源支撑：监督微调学习合规的记忆操作，而强化学习将重复采样与教师对原始观测的验证相结合，以奖励完整、准确的记录，并惩罚遗漏、失真和无支持的内容。我们将失败驱动的策略递归自我改进形式化为沿记忆操作因果序列进行诊断，并在独立回放门控下进行局部规则修复。原子工具将存储、更新、检索和遗忘刻画为存储与读取预算下的成本—效用分配。使用开源 Qwen3.5-9B 模型进行记忆生成时，BetaMem 在 M3-Bench-robot 上取得 48.08%、在 LoCoMo 上取得 92.08%、在 OpenEQA EM-EQA 上取得 72.6%、在 EgoLifeQA 上取得 62.4% 的总体得分，在各自评估协议下为所列记忆方法中最高。为记忆生成训练该模型将契约通过率从 50.9% 提升至 86.2%，同时使每个存储动作的输出 token 数减少 47.3%。另一项在 EMem-Bench 上使用 Qwen3-VL-8B-Instruct 的评估取得 38.4% 的平均成功率和 24.9% 的平均错误复现率。在使用规模相近的开源模型的评估方法中，我们表现最佳。分类结果表明，我们在跨观测整合信息、从长历史中回忆事件以及推断个人习惯方面具有优势。

## Abstract
Long-horizon embodied agents face temporal confusion and incomplete or distorted records, recurring errors from fixed memory rules, and growing storage and retrieval costs. We present BetaMem, a framework for building and evolving traceable long-term memory through six linked layers: working, spatial, entity, episodic, experiential, and procedural memory. A dual-level write contract constrains operation executability and source support for content: supervised fine-tuning learns compliant memory operations, while reinforcement learning combines repeated sampling with teacher verification of the original observations to reward complete, accurate records and penalize omissions, distortion, and unsupported content. We formulate failure-driven policy recursive self-improvement through diagnosis along the causal sequence of memory operations and local rule repairs gated by independent replay. Atomic tools frame storage, updates, retrieval, and forgetting as cost-utility allocation under storage and read budgets. Using the open-source Qwen3.5-9B model for memory generation, BetaMem achieves overall scores of 48.08% on M3-Bench-robot, 92.08% on LoCoMo, 72.6% on OpenEQA EM-EQA, and 62.4% on EgoLifeQA, the highest among the listed memory methods under their respective evaluation protocols. Training the model for memory generation raises the contract pass rate from 50.9% to 86.2% while reducing output tokens per stored action by 47.3%. A separate Qwen3-VL-8B-Instruct evaluation on EMem-Bench achieves an average success rate of 38.4% and an average error recurrence rate of 24.9%. We perform best among evaluated methods using comparably sized open-source models. Category results show that we have advantages in integrating information across observations, recalling events over long histories, and inferring personal habits.

## 1. 核心问题与研究背景

- **应用场景**：长时程具身智能体需要在跨越数小时甚至数天的交互中，利用累积经验回答问题、跟踪不断变化的环境状态，并指导后续动作。其观测来自部分、间歇的多模态传感器流（RGB、深度、音频、位姿、动作元数据）。
- **核心矛盾**：记忆的价值取决于能否保留**时间语境**与**支撑证据**，而现有方法在这两点上普遍不足。
- **三大耦合挑战**：
  - **时间混淆、遗漏与失真**：历史观测易被误当作当前状态；遗漏事件或缺乏来源支撑的写入会扭曲实体历史。例如“钥匙曾被放进抽屉”只是搜索线索，不等于“钥匙现在在抽屉里”。
  - **固定规则导致重复错误**：修正单条记录并不改变写入、保留、检索规则，同类错误会在后续任务中反复出现。
  - **长时程存储与检索成本**：连续传感器流使存储、维护、复查成本持续增长；紧凑摘要会丢失未来问题所需的细节，全量保留则耗尽存储与读取预算。
- **整体含义**：论文主张把记忆视为一种**持续演化的证据维护过程**——不仅管理“记了什么”，还要管理“何时有效、依据何在、规则如何随失败而修正”，并在有限资源约束下做取舍。

## 2. 方法论

### 2.1 核心思想
以“**证据接地 + 时间范围 + 来源可查**”为组织原则，把观测组织为可追溯的分层记忆，并用“学习式写入 + 失败驱动规则自改进 + 预算化原子操作”三条机制闭环：记忆形成 → 记忆使用 → 反馈修正。

### 2.2 六层关联记忆（L0–L5）
- **L0 工作记忆**：当前传感器窗口、任务阶段、动作历史。
- **L1 空间记忆**：地图、地点、路线、坐标系与地图版本。
- **L2 实体记忆**：物体与人的身份、带时间范围的属性与关系。
- **L3 情景记忆**：事件参与者、动作顺序、结果与来源链接。
- **L4 经验记忆**：跨多次经历佐证后归纳的规律，需显式标注适用范围与例外。
- **L5 程序记忆**：任务前置条件、地点/实体引用、可调用技能、预期观测、成功检查、恢复分支。
- 六层共享同一数据库（链接索引与视图），并由**追加式事件日志**、**源证据索引**、**有限源数据档案**贯穿，保证跨层溯源。L4/L5 的归纳必须有多段独立经历佐证，单一事件不足以支撑。

### 2.3 时间化状态记录与验证式修订
- 状态记录定义为 `s = (e, f, v, S, T, c, E, ν, σ)`，其中 `T = (I_valid, t_obs, t_commit)` 分别表示有效区间、源捕获时间、修订提交时间；`σ` 区分 observed / inferred / conflicting / stale / unknown。
- 流程：观测 → 生成源记录 → 按场景变化、物体交互、动作边界或最大时长切分窗口 → 生成类型化的实体/关系/事件提议 → 关联检查（外观、类别、位置、时间连续性），歧义时**保留竞争假设** → 提交前校验源证据、时间范围与所引用记录的版本 → 接受后追加事件并修订状态，同时保留历史。
- 关键区分：**历史记录用于定位搜索线索，当前状态必须由新观测确认**。

### 2.4 双层写入契约与两阶段训练
- **接口层**：动作格式、字段、标识符、值类型是否合法（可执行性）。
- **内容层**：来源支撑、覆盖度、时间一致性、跨层链接是否成立。
- **数据构造**：前沿教师模型生成候选动作，确定性检查器用 26 条可追踪规则修复/剔除违规样本，构成 SFT 监督数据。
- **覆盖目标构造（解决“遗漏无监督信号”）**：SFT 后对每个训练视频独立运行 K=4 次，出现 ≥2 次的项目构成“应记录集” V_w，单次出现的项目被排除；投票数衡量记录一致性。随后用教师模型（qwen3.7-max）**回放原始帧与可用历史**，核查实体身份、属性、时间对应、状态变化、事件参与者/顺序/结果，返回支撑源帧并经确定性检查校验时间戳。被验证的低票项目获得有界的遗漏补偿加权（2→3→4 票递减，归一化保持平均权重）；证据不足者不加权，被观测反驳者排除。

…抑制“投机式刷分”行为（例如无证据地堆砌实体名、重复提交同一记录以骗取覆盖分），并与零方差过滤配合，使组内奖励保持可区分度。

- **训练与推理的一致性**：训练时的观测窗口、历史记忆快照与推理阶段保持一致；写入决策被隔离在单窗口内评估，避免模型通过“改写历史”而非“正确写入”获得奖励。

### 2.5 预算化的记忆操作与检索

- **原子操作集合**：论文把记忆维护拆解为可计价的原子操作，包括写入（append）、状态修订（revise）、假设合并（merge）、失效标记（invalidate）、摘要压缩（summarize）、证据复查（re-audit）与检索（retrieve）。每次操作都需声明作用层（L0–L5）、引用记录 ID 与源证据，从而使成本可核算、行为可审计。
- **分层预算分配**：存储与读取预算按层与任务阶段分配——工作记忆高频覆盖、情景记忆按事件边界归档、实体记忆只保留“当前有效 + 有限历史版本”、经验/程序记忆因条目稀少而可长期保留。预算紧张时优先压缩低复用率的源数据档案，而非删除带时间范围的索引条目。
- **检索策略**：检索以“查询意图 → 时间范围 → 实体/地点锚点 → 层优先级”逐级收窄，先返回当前有效状态与支撑证据链接，再按需回溯历史版本；对冲突状态返回竞争假设及其证据，而不是强行给出单一答案。
- **成本可控性**：由于写入前需通过契约校验、检索前需限定范围，论文主张记忆开销随“事件数”而非“帧数”增长，从结构上缓解长时程流数据带来的线性膨胀。

### 2.6 失败驱动的规则自改进

- **闭环位置**：这是对“固定规则导致重复错误”这一挑战的直接回应。系统在任务失败或答案被判定为与证据不符时，不只修正单条记录，还回溯到产生该记录的写入/保留/检索规则。
- **规则表示与修订**：规则以可读的条件—动作形式存在（如“当物体被遮挡超过阈值时长时，其位置状态应标记为 stale 而非沿用旧值”），修订包括增补前置条件、收紧触发阈值、增加校验步骤或引入新的恢复分支；修订需在历史失败案例上回放验证，避免过拟合单例。
- **与训练的关系**：规则层面的修正既可作为推理期的在线改进，也可沉淀为后续 SFT/GRPO 数据的构造依据，使“从失败中学习”不止停留在参数层面。

## 3. 实验设置

- **任务形态**：围绕长时程具身问答与状态跟踪，覆盖“当前状态查询”“历史事件回溯”“跨时段变化推理”“需要多跳证据链的问答”等题型，并包含需要区分“曾经”与“现在”的对抗性提问。
- **对比基线**：包括全量上下文/滑动窗口、摘要式记忆、向量检索式长期记忆、以及不带时间范围与来源链接的结构化记忆变体，用于分离“结构化”与“时间化+证据接地”各自的贡献。
- **评价维度**：除答案正确率外，还评估时间混淆率、无证据断言率、覆盖度（应记录项被记录的比例）、存储与检索成本、以及跨任务的重复错误率。
- **训练配置**：SFT 冷启动 + 窗口级 GRPO；教师模型仅用于数据构造与覆盖目标验证，推理阶段不参与。

## 4. 主要结果

- **准确性**：在需要时间区分的题型上提升最明显，说明“历史记录 ≠ 当前状态”的显式建模是主要收益来源；对纯当前状态查询，收益相对温和。
- **证据可查性**：来源链接使答案可回溯到源帧，显著降低了无支撑断言的比例，并让错误可定位到具体写入或检索环节。
- **成本**：在可比准确率下，存储与读取开销随事件数增长的趋势优于全量保留方案；相比紧凑摘要方案，在需要细节回溯的问题上优势更大。
- **重复错误**：规则修订机制使同类错误在后续任务中的复发率下降，这是与纯参数更新方案的关键差异。

## 5. 消融与机制分析

- **分层结构**：去除 L4/L5 后，跨经历归纳类问题明显退化；去除时间范围字段后，时间混淆率上升最快。
- **来源证据与校验**：关闭提交前校验会引入大量“看似合理但无源”的记录，且这些错误难以通过下游检索纠正。
- **覆盖目标与遗漏补偿**：投票构造的“应记录集”配合有界加权，缓解了“遗漏无监督信号”问题；去掉补偿后模型倾向保守少写，覆盖度下降。
- **奖励分层**：可解析性优先的分层奖励避免了内容分被格式错误淹没，惩罚项对抑制刷分行为有效。
- **GRPO 与固定观测**：固定观测与历史以隔离写入决策，是让组内比较有意义的前提；否则奖励差异会被历史差异污染。

## 6. 贡献与创新点

1. 将记忆重新定义为**持续演化的证据维护过程**，把“何时有效、依据何在、规则如何修正”纳入一等公民。
2. 提出六层关联记忆与贯穿式源证据索引，实现跨层可溯源与历史/当前状态的显式分离。
3. 设计双层写入契约与两阶段训练（SFT + 窗口级 GRPO），并给出可追踪的确定性检查规则与分层奖励。
4. 用投票 + 教师回放构造覆盖目标，解决“遗漏缺乏监督信号”的数据构造难题。
5. 引入失败驱动的规则自改进，把纠错从“改记录”推进到“改规则”。

## 7. 局限与未来方向

- **依赖检测与标注质量**：实体关联、事件切分与覆盖目标均受感知与标注质量影响，感知失败会被结构化地“固化”。
- **教师模型依赖**：覆盖目标的验证依赖强教师模型回放，成本较高，且可能继承教师偏差。
- **规则修订的验证范围有限**：在历史失败案例上回放难以保证对未见情境的泛化，存在过拟合单例的风险。
- **评测覆盖**：长时程、多天尺度的真实部署评测仍有限，跨环境迁移与多人/多智能体共享记忆尚未充分讨论。
- **未来方向**：更轻量的自监督覆盖信号、规则修订的形式化验证、记忆的遗忘与隐私治理、以及与规划模块的更紧耦合。

## 8. 总体评价

论文的核心洞见在于：长时程记忆的难点不是“存不下”，而是“分不清时间、说不清依据、改不掉规则”。BetaMem 通过分层结构 + 时间化状态 + 证据接地 + 预算化操作 + 失败驱动规则修订，把记忆系统从“检索组件”提升为“可审计、可修正的证据维护系统”。其方法设计在工程上较为自洽：契约校验与确定性检查器保证了数据与运行时的可控性，投票式覆盖目标与分层奖励则针对性地补上了监督信号缺口。主要风险集中在对外部感知/教师模型的依赖，以及规则自改进的泛化保证；这些也是该方向后续最值得投入的验证点。
