## 摘要
近期研究探索了通过多智能体强化学习（MARL）优化LLM协作，但许多方法仍依赖预定义工作流，限制了效率与可扩展性。去中心化LLM协作具有挑战性，因为智能体独立执行且通信受限、共享联合目标，并且必须从通信轨迹中推断有用信息。本文提出BCMAAC，一种信念条件多智能体演员-评论家方法，该方法维护对上下文信息的信念，并利用这些信念促进训练。在Minecraft游戏、网页搜索和工具使用任务上的实验表明，与朴素演员-评论家基线相比，BCMAAC提升了任务性能和协作行为。在多轮任务中，当上下文信息更丰富时，改进尤为显著，信念建模展现出明显优势。

## Abstract
Recent work has explored optimizing LLM collaboration through Multi-Agent Reinforcement Learning (MARL), but many approaches still rely on predefined workflows, limiting efficiency and scalability. Decentralized LLM collaboration is challenging because agents execute independently with limited communication, share a joint objective, and must infer useful information from communication traces. In this paper, we propose BCMAAC, a Belief-Conditioned Multi-Agent Actor-Critic method that maintains beliefs over contextual information and uses them to facilitate training. Experiments on Minecraft game-playing, web searching and tool-using tasks show that BCMAAC improves task performance and collaborative behavior compared to naive actor-critic baselines. The improvements are particularly pronounced in multi-turn tasks with richer contextual information, where belief modeling provides a clear advantage.

## 1. 核心问题与研究背景

- **背景**：LLM 智能体已能通过多轮交互完成任务，强化学习可验证奖励（RLVR）因成本低、可扩展、反馈客观，成为训练这类智能体的主流范式。多 LLM 协作（角色分工、智能体间通信）已被证明能提升复杂任务表现。
- **现有方法的局限**：
  - 基于提示（prompt）的多智能体系统（如 Multi-Agent Debate、ChatDev、AutoGen、CAMEL）依赖**人工预设的交互协议**，协作模式固定，无法从任务经验中自适应改进。
  - 基于 RL 的方法（MAGRPO、Dr. MAS、MAPoRL、MARFT、MAAC）虽可让协作策略随任务反馈演化，但大多**直接把原始交互历史作为上下文**，让 actor 和 critic 从长文本历史中自行重建任务状态与队友知识，表示学习困难。
- **去中心化 LLM 协作的固有挑战**：
  - 部分可观测：智能体只能看到本地观测、历史与收到的消息，需推断环境隐藏状态与队友内部状态；
  - 动作是自然语言 token 序列，动作空间巨大，决策同时依赖任务推理与对他人的推断；
  - 长时程、稀疏、延迟奖励：奖励集中在终局，难以判断哪些中间通信或交互真正促成了成功。
- **论文主张**：应显式维护**信念（belief）**——对任务状态与队友意图的压缩隐表示——并将其条件化到多智能体 actor-critic 中，以改善信用分配与协作行为。

## 2. 方法论

### 2.1 问题形式化

- 将去中心化 LLM 协作建模为**合作式 Dec-POMDP**：\(\mathcal{M}=\langle I,V,C,M,S,\{O^i\},\{A^i\},R,T,H,\gamma\rangle\)，其中全局状态分为系统可见状态 \(S^{sys}\) 与用户隐藏状态 \(S^{usr}\)，每个智能体 \(i\) 依据本地历史 \(h_{i,t}\)（受上下文窗口 \(C\) 限制）生成响应序列 \(a_{i,t}\)，联合策略在去中心化执行下因子分解为 \(\pi_\theta(a_t|h_t)=\prod_i \pi_{\theta_i}(a_{i,t}|h_{i,t})\)。
- 目标为最大化折扣期望回报；对比基线 MAAC 使用集中式 critic \(V_\phi(h_t)\)（以联合历史为条件）和优势 \(\hat A_t = r_t+\gamma V_\phi(h_{t+1})-V_\phi(h_t)\)，但其受限于长历史中状态提取困难、缺乏对他人知识与未来动作的显式建模。

### 2.2 核心思想：结构化侧信息 + 循环信念编码

- 每个智能体除语言历史外，还接收**结构化侧信息** \(x_{i,t}\in\mathcal{X}^i\)（如网格通道 + 归一化标量），关键约束是 \(x_{i,t}\) **只依赖执行时智能体自身可获得的信息**（含收到的通信），不泄露全局答案或隐藏标签。
- 用循环信念编码器 \(f_\psi\) 维护跨轮隐状态：
  \[
  (c_{i,t},\,z_{i,t+1},\,\hat b_{i,t},\,\hat p_{i,t}) = f_\psi(x_{i,t}, z_{i,t})
  \]
  其中 \(c_{i,t}\) 为信念上下文（送入 actor 与 critic），\(z_{i,t}\) 为循环状态，\(\hat b_{i,t}\) 为任务信念预测，\(\hat p_{i,t}\) 为队友动作预测（后两者仅为训练期辅助头）。

### 2.3 演员-评论家结构

- **Actor（去中心化）**：\(\pi_{\theta_i}(a_{i,t}\mid h_{i,t}, c_{i,t})\)，即 LLM 策略同时以本地语言历史和本地信念上下文为条件。
- **Critic（集中式，仅训练期）**：拼接各智能体信念上下文 \(c_t=\mathrm{Joint}(\{c_{i,t}\})\)，估计联合价值 \(V_\phi(c_t)=\mathbb{E}_\pi[G_t\mid c_t]\)；优势为 \(\hat A_t = r_t+\gamma V_\phi(c_{t+1})-V_\phi(c_t)\)。
- **损失函数**：
  - 策略损失 \(L_\pi=-\sum_t\sum_i \hat A_t\log\pi_{\theta_i}(a_{i,t}|h_{i,t},c_{i,t})\)；
  - 价值损失 \(L_V=\sum_t\big(V_\phi(c_t)-r_t-\gamma V_\phi(c_{t+1})\big)^2\)；
  - 辅助损失 \(L_{aux}=\lambda_b L_b+\lambda_p L_p\)：\(L_b\) 为带掩码的 BCE（任务信念，仅监督未解决/必需的条目），\(L_p\) 为四类动作分类的交叉熵（队友动作类型预测）；附录中还包含答案就绪损失 \(L_r\) 与动作偏好损失 \(L_a\)。
- **训练期特权标签**：辅助标签由标注规则 \(\Gamma_\xi(\tau)\) 在 rollout 后读取完整轨迹与环境内部状态生成（训练专用，执行时不可得）。
- **参数更新分工**：critic 只由价值损失更新，actor 只由策略损失更新，信念编码器由 \(\lambda_V L_V+L_\pi+L_{aux}\) 共同更新。
- **执行阶段**：去掉集中式 critic 与辅助头，每个智能体仅递归计算 \((c_{i,t},z_{i,t+1})\leftarrow f_\psi(x_{i,t},z_{i,t})\) 并采样动作，**保持完全去中心化执行**。

### 2.4 理论性质

- **Remark 4.1**：由于 \(c_t\) 在采样当前联合动作前已确定且与动作无关，用 \(G_t-\beta(c_t)\) 替换 \(G_t\) 不改变策略梯度估计的期望（score-function 基线恒等式），说明以信念为条件的基线是合法的方差缩减手段。
- **Proposition 4.2**：若联合信念上下文对回报充分（\(\mathbb{E}_\pi[G_t|F_t,c_t]=\mathbb{E}_\pi[G_t|c_t]\)），则基于全部可用信息的价值等于基于信念上下文的价值 \(V^\pi(F_t)=V^\pi(c_t)\)，即压缩不损失价值相关信息。
- **Remark 4.3**：稀疏奖励下回报驱动的表示学习信号弱，辅助损失提供**逐轮（per-turn）的额外表示监督**，有助于状态估计与伙伴建模。

## 6. 主要结论与发现

- **整体性能**：BCMAAC 在全部 6 个任务上取得最佳结果，且标准差总体与 MAAC 相当或更低，说明兼顾性能与稳定性。
- **相对 MAAC 的增益**（百分点）：Stateful Tool 59.2→77.5（+18.3，最大）、Resource Gathering 78.4→92.8（+14.4）、Filesystem Wrangling 58.9→73.0（+14.1）、Bridge Building 80.6→94.4（+13.8）、Multi-Source Gathering 47.6→58.5（+10.9）、Cross-Lingual Gathering 45.1→53.2（+8.1）。
- **训练后的多智能体方法显著优于单智能体 AC 与纯提示协作**：Parallel / Pipeline 在 Minecraft 任务上完全失败（0.0%），说明"仅增加智能体数量而不学习协作"无效。
- **低并行度任务是例外**：Filesystem Wrangling 中 Editor 必须依赖 Explorer 上一轮传递的路径，本质是串行流水线，单智能体 AC（66.9%）反而强于 MAAC（58.9%）；但 BCMAAC 通过跟踪 Editor 的就绪状态仍达 73.0%，说明关键在于"有效协作"而非智能体数量。
- **两个辅助信号互补**：BCMAAC-B（任务信念）在需要维护资源/证据/工具状态与队友就绪度的任务上更强；BCMAAC-P（伙伴动作）在需要协调施工分工的 Bridge Building 上更强；完整 BCMAAC 综合最佳。
- **收敛性**：图 3 显示 BCMAAC 在多数任务上收敛更快、回报更高、波动更小；Filesystem Wrangling 中后期反超 MAAC 且更稳定，与"更准确跟踪就绪状态

……相关”的解释一致；相比之下，MAAC 在该任务上后期出现明显回落，说明缺乏对队友就绪状态的显式建模会导致协作时序错配。

- **增益的机制解释（作者的归因）**：性能提升主要来自三方面——（1）结构化侧信息把“从长文本历史中重建环境状态”的负担从 LLM 上下文中剥离，降低了表示学习难度；（2）信念上下文作为采样动作前即确定的压缩状态，既是合法的策略梯度基线（Remark 4.1），又能在 Proposition 4.2 的意义下不损失价值相关信息，从而改善信用分配；（3）辅助头提供逐轮监督信号，缓解终局稀疏奖励下“哪些中间通信真正有用”难以归因的问题。这一归因与消融结果（BCMAAC-P 与 BCMAAC-B 各自在不同任务类型上占优、完整模型综合最佳）方向一致，但论文并未做进一步的机制性验证（如对信念表示做探针分析、或可视化信念随轮次的演化），因此“为何有效”仍主要停留在设计层面的合理性论证。

## 7. 局限与风险（结合作者自述与本文分析）

- **侧信息依赖人工领域设计**：\(x_{i,t}\) 的通道与标量需针对每个任务手工定义（附录给出各任务的维度表），这实质上把一部分“状态工程”从模型转移到了研究者，跨域迁移与新任务适配成本较高，也削弱了“端到端从经验中学习协作”的主张强度。
- **特权标签依赖标注规则 \(\Gamma_\xi\)**：任务信念与队友动作标签由规则在完整轨迹上生成，规则本身的覆盖度与正确性直接决定辅助监督质量；论文未报告标签噪声或规则消融。
- **规模与泛化验证不足**：全部实验为 2 智能体，未验证 n>2 时信念拼接 \(c_t=\mathrm{Joint}(\{c_{i,t}\})\) 的维度增长与集中式 critic 的可扩展性；任务虽跨三域但每域仅 2 个，测试集规模偏小（如 Bridge Building 仅 34 例、Multi-Source Gathering 仅 15 例），置信区间较宽。
- **基线覆盖窄**：仅与 MAAC 一个 RL 多智能体基线对比，缺少与 MAGRPO、Dr. MAS、MAPoRL、MARFT 等同类方法的直接比较，因而“相对现有 LLM 多智能体 RL 的先进性”证据不充分；同时缺少“MAAC + 相同辅助损失”这一关键对照，无法完全排除增益来自额外监督信号而非信念结构本身。
- **理论保证较弱**：Remark 4.1 与 Proposition 4.2 属于温和的性质陈述（基线合法性与压缩不损失价值信息），并非收敛性或最优性保证，且 Proposition 4.2 的前提（信念对回报充分）在实践中无法验证。
- **成本与可复现性**：未报告 GPU 型号/数量、训练墙钟时间与总算力；推理阶段虽保持去中心化，但每轮需额外前向信念编码器，其延迟与显存开销未量化。
- **潜在风险**：结构化侧信息与特权标签的边界若设计不当，存在信息泄漏（如侧信息间接编码答案）的可能，论文仅以“只依赖执行时可获得信息”的约束声明来规避，未提供泄漏检测实验。

## 8. 对领域的启示

- **“显式状态压缩”是 LLM 多智能体 RL 的一个高性价比切入点**：与其让 LLM 在长上下文中隐式维护状态，不如用一个小型循环编码器承担状态估计，把 LLM 的容量留给语言推理与通信，这一分工思路可迁移到其他长时程、部分可观测的 LLM 智能体任务。
- **CTDE（集中式训练、去中心化执行）范式在 LLM 场景仍然适用**：以信念上下文而非原始文本历史作为 critic 输入，既保留了训练期的全局信息优势，又避免了 critic 处理超长文本的困难，为 LLM 场景下的价值函数设计提供了可操作模板。
- **辅助预测任务可作为一种通用的“表示正则”**：在稀疏终局奖励的 LLM RL 中，逐轮的信念/伙伴动作预测相当于为表示学习提供了密集的代理监督，这一做法与 RLVR 框架天然兼容，可作为即插即用组件。
- **“有效协作”优于“智能体数量”**：Parallel/Pipeline 在 Minecraft 任务的 0% 失败与 Filesystem Wrangling 中单智能体 AC 反超 MAAC 的结果，提示多智能体系统的收益取决于任务的可分解性与协作协议是否被学习，而非简单地增加角色。

## 9. 总体评价

本文针对去中心化 LLM 协作中“部分可观测 + 长文本历史 + 稀疏延迟奖励”的核心困难，提出了一个结构清晰、工程可落地的方法：以结构化侧信息驱动循环信念编码，将信念上下文同时条件化到去中心化 actor 与集中式 critic，并用任务信念与伙伴动作两个辅助头提供逐轮监督。方法在 6 个跨域双智能体任务上稳定优于 MAAC 与单智能体/纯提示基线，消融实验也较清晰地分离了两类辅助信号的贡献，理论部分虽温和但为设计选择提供了合理性支撑。其主要不足在于：侧信息与标签规则的人工依赖、基线覆盖偏窄（缺少与其他 LLM 多智能体 RL 方法及“MAAC+辅助损失”的对照）、仅限 2 智能体、算力与推理开销未报告，以及 Web 类任务上增益较小、噪声较大。总体而言，这是一篇**方法贡献明确、实验扎实但外推性有待验证**的工作，其“显式信念压缩 + 辅助逐轮监督 + CTDE”的组合为 LLM 多智能体强化学习提供了一个有参考价值的基线框架。
