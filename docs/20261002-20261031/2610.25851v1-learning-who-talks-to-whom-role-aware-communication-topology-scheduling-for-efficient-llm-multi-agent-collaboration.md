## 摘要
由大语言模型（LLM）驱动的多智能体系统依赖结构化通信拓扑来促进信息交换与协作推理。然而，如何有效调度这些拓扑以动态决定谁与谁交流以及何时交流，仍然是在平衡集体推理性能与指数级token开销方面的一项根本挑战。现有拓扑调度方法要么采用无法适应动态问题求解状态的静态通信图，要么忽视智能体角色互补性，同时未能将合成图结构显式纳入团队级决策评估。为解决这些局限，我们提出ACTS，一种面向高效LLM多智能体协作的角色感知自适应通信拓扑调度框架。ACTS在集中训练与分散执行（CTDE）范式下进行编排，并引入一种新颖的双注意力机制。具体而言，角色条件关系注意力模块根据智能体角色和演化中的执行状态动态选择可变基数交互伙伴，而拓扑注意力混合器将有向通信拓扑显式嵌入团队价值分解，以实现精确的信用分配。在涵盖代码生成、多步推理、通用知识和竞争性数学的9个挑战性基准上的综合评估表明，ACTS始终优于最先进基线，平均准确率最高提升6.19个百分点，同时token消耗降低超过15%。项目网站为https://acts-mas.github.io/ACTS/。

## Abstract
Multi-agent systems driven by large language models (LLMs) rely on structured communication topologies to facilitate information exchange and collaborative reasoning. However, effectively scheduling these topologies to dynamically determine who talks to whom and when to communicate remains a fundamental challenge in balancing collective reasoning performance against exponential token overhead. Existing topology scheduling approaches either enforce static communication graphs that cannot adapt to dynamic problem-solving states, or overlook agent role complementarity while failing to explicitly incorporate the synthesized graph structure into team-level decision evaluation. To tackle these limitations, we propose ACTS, a role-aware adaptive communication topology scheduling framework for efficient LLM multi-agent collaboration. Orchestrated within a Centralized Training with Decentralized Execution (CTDE) paradigm, ACTS introduces a novel dual-attention mechanism. Specifically, a Role-conditioned Relational Attention module dynamically selects variable-cardinality interaction partners based on agent roles and evolving execution states, while a Topological Attention Mixer explicitly embeds the directed communication topology into team value decomposition for precise credit assignment. Comprehensive evaluations across 9 challenging benchmarks covering code generation, multi-step reasoning, general knowledge, and competitive mathematics demonstrate that ACTS consistently outperforms state-of-the-art baselines, boosting average accuracy by up to 6.19 percentage points while reducing token consumption by over 15%. The project website is available at https://acts-mas.github.io/ACTS/.

## 2. 方法论

### 2.1 核心思想

ACTS 在集中训练、分散执行（CTDE）范式下，将“通信模式选择”和“有向伙伴选择”结合，并把实际生成的有向通信图显式嵌入团队价值分解，实现拓扑感知的信用分配。

### 2.2 问题建模与通信动作

- 智能体集合为 \(I=\{1,\dots,N\}\)，每个智能体有角色 \(\rho_i\)。
- 第 \(t\) 轮维护局部观测 \(o_i^t\)、循环状态 \(h_i^t\) 和有向通信图 \(G^t=(I,E^t)\)。
- 每个活跃智能体从离散通信动作集中选择动作，动作包括：`off`、`solo`、`broadcast`、`receive`、`attn-broadcast`、`attn-receive`。
- 选择 `off` 或 `solo` 的智能体退出后续通信，通信候选集单调收缩；当多数智能体不活跃时可提前终止。

### 2.3 角色条件关系注意力

- 使用 GNN 聚合局部观测、角色嵌入和当前拓扑信息，再由 GRU 更新循环状态：
  - \(h_i^t=\mathrm{GRU}(\mathrm{GNN}(o_i^t,e_\rho(\rho_i),G^t),h_i^{t-1})\)。
- 通过跨注意力计算有向相关性：
  - \(\alpha_{ij}^t=\mathrm{softmax}_j((W_Qh_i^t)^\top(W_Kh_j^t)/\sqrt{d})\)。
  - 由于 query/key 有序，通常 \(\alpha_{ij}\neq\alpha_{ji}\)，从而支持有向伙伴选择。
- 聚合其他智能体信息得到 \(\xi_i^t\)，并据此选择局部 Q 值最大的通信动作。
- 拓扑构造：
  - `broadcast`/`receive` 请求全部候选伙伴；
  - `attn-broadcast`/`attn-receive` 仅保留注意力分数高于候选均值的边；
  - 发送集与接收集合并生成下一轮有向边集。

### 2.4 拓扑注意力价值混合器

- 分别编码每个智能体的入邻域和出邻域，形成拓扑表示 \(z_i^t\)，避免将有向入/出关系混为无向邻域。
- 以全局状态 \(s^t\) 为 query、\(z_i^t\) 为 key 计算多头注意力 logits，并在可通信智能体上做 softmax 得到 \(\lambda_{i,h}^t\)。
- 头权重取非负绝对值 \(w_h^t=|f_\theta(s^t)_h|\)，混合器为：
  - \(Q_{\mathrm{tot}}^t(a)=b^t+\sum_h w_h^t\sum_i\lambda_{i,h}^tQ_i^t(a_i)\)。
- 由于权重非负，混合器对每个局部 Q 单调，满足 IGM 一致性，支持分散贪心执行。
- 理论分析给出：局部加权展开、图支撑系数、入/出邻域对信用系数的不同影响，以及拓扑感知 TD 梯度。

### 2.5 训练目标

- 奖励同时考虑任务得分与 token 成本：
  - \(w_{\mathrm{task}}R_{\mathrm{task}}-w_{\mathrm{tok}}\min(C_{\mathrm{tok}}/B,1)\)。
- 使用经验回放和目标网络最小化 TD 损失；LLM 主干冻结，仅训练调度相关模块。
- 离散拓扑构造不参与梯度回传；关系注意力通过软特征 \(\xi_i^t\) 接收梯度，拓扑注意力通过混合器训练。

## 6. 主要结论与发现

- ACTS 在两个骨干上均取得最高宏平均准确率：
  - GPT-OSS-120B：75.01%，比 Agent Q-Mix 高 3.18 个百分点；

- 在准确率—token 消耗上达到 Pareto 前沿：仅单智能体提示更省 token，但准确率明显更低。
- 消融显示：
  - 拓扑注意力混合器贡献最大，替换为 QMIX 后准确率显著下降且 token 上升；
  - 固定角色伙伴路由会造成最大 token 开销且准确率下降；
  - 移除角色嵌入也会降低性能与效率。
- 通信模式随信息增益变化：高 IG 任务更倾向广播/注意力广播与持续协作；低 IG 任务更多停用智能体、采用拉取式 `attn-receive`，从而节省 token。
- 结论：角色感知的自适应有向拓扑调度与拓扑条件化价值分解，可同时提升 LLM 多智能体协作的效果与效率。

- **将拓扑调度视为可学习的一等决策变量**：ACTS 表明，通信图不应只是执行前的静态配置，而可以在每轮根据局部观测、角色和当前图状态动态生成；这对构建更可控的 LLM 多智能体系统具有方法论启发。
- **有向信用分配值得进一步推广**：入邻域/出邻域分离编码与非负注意力混合，为“谁为团队贡献负责”提供了更细粒度的结构先验，可迁移到工具调用、层级协作和异步多智能体场景。
- **效率奖励可与预算约束结合**：未来可研究拉格朗日约束、硬预算掩码或自适应 token 配额，替代简单的加权惩罚，以更直接地控制成本并分析准确率—成本前沿。
- **扩大规模与任务范围**：需要在更多智能体、更长通信轮次、异构角色和开放域任务上验证；同时应报告多种子方差、显著性检验和失败案例分析，提升结论稳健性。
- **降低对人工角色的依赖**：可探索角色自动发现、角色与拓扑联合学习，或引入任务结构先验，减少人工角色设计对调度策略的约束。
- **完善成本与可复现性报告**：建议补充硬件配置、训练时长、总 token 消耗、推理延迟和基线调参预算，为后续研究提供可比较的成本基准。

## 10. 总体评价

ACTS 的核心贡献在于把 LLM 多智能体通信拓扑从“静态图”或“执行前生成图”推进为“执行中由角色条件策略动态生成的有向图”，并通过拓扑注意力价值混合器将图结构显式纳入信用分配。方法在概念上较为完整：通信动作设计覆盖停用、广播、接收和注意力筛选，奖励同时考虑任务与 token，混合器满足 IGM 一致性，实验也提供了性能、效率和行为层面的多重证据。其主要不足在于训练规模与统计严谨性有限、算力成本披露不足、规模泛化性和基线公平性仍需加强。总体而言，论文为“效果—效率”协同的 LLM 多智能体拓扑调度提供了一个有说服力的框架，但其结论更适合视为在受控小规模设定下的强经验证据，而非已被充分验证的通用结论。
