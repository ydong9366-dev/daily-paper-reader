## 摘要
去中心化多智能体系统（MAS）使大语言模型智能体能够在无集中控制的情况下进行交互。智能体需要在测试时适应其他智能体，并复用积累的经验来改进其交互策略，以应对未来在合作、混合动机和对抗等设置下的交互。然而，现有方法往往针对特定交互设置设计适应机制。这引出一个核心问题：去中心化MAS如何支持跨交互设置的测试时适应与可靠的经验复用？我们提出EvolveMAS，一个统一的自演化框架，支持在回合内与跨回合的经验驱动适应。EvolveMAS为每个主智能体配备一个专用的MemoryAgent进行测试时记忆治理，该智能体在主智能体推理上下文之外维护隔离的结构化记忆。EvolveMAS将适应组织为两个互补过程：回合内在线适应与跨回合知识演化。在回合内在线适应中，MemoryAgent根据交互证据更新情景记忆、语义记忆和工作记忆，以指导后续动作。在跨回合知识演化中，主智能体利用记忆和回合结果提炼可复用的交互知识，包括伙伴画像和交互策略，以供后续回合使用。在涵盖三种交互设置的五项基准和六种评估配置中，EvolveMAS在对比方法中取得了最高的归一化平均分77.2。消融实验表明，测试时记忆治理与跨回合知识复用均能提升性能。交互轨迹进一步展示了更新后的记忆与提炼的知识如何指导后续交互。这些结果支持在无需更新模型参数的情况下实现去中心化MAS中的经验驱动适应。

## Abstract
Decentralized multi-agent systems (MAS) enable large language model agents to interact without centralized control. Agents need to adapt to other agents at test time and reuse accumulated experience to refine their interaction strategies for future interactions across cooperative, mixed-motive, and adversarial settings. However, existing approaches often develop adaptation mechanisms for particular interaction settings. This raises a central question: how can decentralized MAS support test-time adaptation and reliable experience reuse across interaction settings? We propose EvolveMAS, a unified self-evolution framework that supports experience-driven adaptation within and across episodes. EvolveMAS pairs each main agent with a dedicated MemoryAgent for test-time memory governance, which maintains isolated Structured Memory outside the main agent's reasoning context. EvolveMAS organizes adaptation into two complementary processes: Within-Episode Online Adaptation and Cross-Episode Knowledge Evolution. During Within-Episode Online Adaptation, MemoryAgent updates episodic, semantic, and working memory from interaction evidence to inform subsequent actions. During Cross-Episode Knowledge Evolution, the main agent uses memory and episode outcomes to distill reusable interaction knowledge comprising partner profiles and interaction strategies for subsequent episodes. Across five benchmarks and six evaluation configurations spanning the three interaction settings, EvolveMAS achieves the highest normalized average score of 77.2 among the compared methods. Ablations show that test-time memory governance and cross-episode knowledge reuse both improve performance. Interaction traces further illustrate how updated memory and distilled knowledge guide subsequent interactions. These results support experience-driven adaptation in decentralized MAS without updating model parameters.

## 二、方法论

### 2.1 总体架构：主智能体 + 专职 MemoryAgent

- 每个主智能体 $a_i$ **一对一**配备一个专用 **MemoryAgent** $m_i$ 与一份**隔离记忆**。
- 分工：
  - 主智能体负责任务推理、通信与环境交互；
  - MemoryAgent 在**主智能体推理上下文之外**维护结构化记忆与交互知识，只向主智能体提供“被治理过的交互状态”。
- 所有 MemoryAgent 共享**同一套记忆 schema 与治理协议**，但内容按各自主智能体的本地交互历史独立演化——保持去中心化，不引入中央控制器。
- 经验分三个抽象层级：**原始轨迹 $\tau_e$** → **结构化记忆 $M_{e,t}$**（交互中维护的紧凑状态）→ **交互知识 $K_e$**（跨回合可复用规律）。

### 2.2 回合级 Execute–Evaluate–Evolve（EEE）流程

以回合 $e$ 为单位，形式化为：

- **Execute**：$(\tau_e, M_e, o_e) = \mathrm{Exec}(x_e, \mathcal{A}, M_{e,0}, K_{e-1})$
- **Evaluate**：$r_e = \mathrm{Eval}(x_e, \tau_e, o_e)$
- **Evolve**：$K_e = D_a(M_e, r_e; K_{e-1})$

要点：
- $\mathrm{Eval}$ 是**任务原生（task-native）**评测器，$r_e$ 在不同设定下形式不同（胜率、通过率、目标分、共识数等），但作为“结果信号”提供**统一接口**，使演化可被结果条件化，而不要求跨异质任务共享度量空间；
- 算子 $D_a$ 从被治理的记忆、结果信号与旧知识中蒸馏新知识；
- Execute 与 Evolve 都使用 $K_{e-1}$：前者用它指导交互，后者用它作为增量精炼的基底；Evaluate 则不接触记忆与知识，保证评估独立。

### 2.3 关键技术一：回合内在线适应（Within-Episode Online Adaptation）

- 第 $t$ 轮：$(y_{e,t}, \Delta\tau_{e,t}) \sim \pi_a(\cdot \mid [x_e; M_{e,t-1}; K_{e-1}])$，随后 $M_{e,t} = \mathrm{MA_{online}}(M_{e,t-1}, \Delta\tau_{e,t})$。
- 形成**递归反馈环**：第 $t$ 轮观测到的证据更新记忆 → 记忆条件化第 $t+1$ 轮的动作策略。
- **结构化记忆三分区**（借鉴认知科学）：
  - **情景记忆 $E_{e,t}$**：具体交互事件——发生了什么、涉及谁、结果如何，为后续归纳提供有据可查的历史；
  - **语义记忆 $S_{e,t}$**：从经验中推断的可复用事实与规律（任务事实、重复出现的协调模式、伙伴观察等），可跨回合累积；
  - **工作记忆 $W_{e,t}$**：当前交互的紧凑状态——当前焦点、下一步信息、任务相关的记忆/知识视图，随情境刷新。
- 更新规则为概念级（追加事件、并入规律、刷新工作区），**不绑定具体存储实现**。

### 2.4 关键技术二：跨回合知识演化（Cross-Episode Knowledge Evolution）

- 回合结束后，以 $r_e$ 为条件，主智能体从 $M_e$ 与 $K_{e-1}$ 蒸馏 $K_e = (G_e, P_e)$：
  - **交互策略 $G_e$**：指导协调、验证、谈判、信任校准等重复情境的行为规律；
  - **伙伴画像 $P_e = \{p_{e,j}\}_{j \neq i}$**：伙伴的行为倾向、推断能力、可靠性，随新证据持续更新。
- 两个时间尺度耦合：

$$\underbrace{\Delta\tau_{e,t} \to M_{e,t} \to \text{Execute}_{t+1}}_{\text{回合内在线适应}}, \qquad \underbrace{(M_e, r_e, K_{e-1}) \to K_e \to \text{Execute}_{\text{future}}}_{\text{跨回合知识演化}}$$

- 设计意图：把“上下文膨胀”和“记忆污染”问题外移到 MemoryAgent 侧治理，主智能体的推理上下文只保留精炼后的状态与知识。
