## 摘要
设计有效的多智能体系统（MAS）仍然是一项具有挑战性且资源密集的任务。我们提出了一种贝叶斯进化优化框架，用于自动发现面向特定任务的 MAS 拓扑。该方法将进化算子与贝叶斯优化相结合：前者用于生成多样化的工作流图，后者用于将成本高昂的评估集中于有前景的候选方案。与基于 LLM 的候选选择不同，我们的方法使用图感知高斯过程和期望改进，在进化搜索过程中提供显式的选择准则。我们在 BigCodeBench 上针对代码生成进行评估，并在使用 TabPFN 的表格预处理基准上进行评估。在 BigCodeBench 上，进化得到的架构在所评估的智能体系统中取得了最高的总体性能。在时序表格数据集上，优化后的 MAS 预处理在若干任务上优于默认 TabPFN 模型，同时在 IID 数据集上保持竞争力。总体而言，结果表明贝叶斯选择在昂贵评估预算下引导进化式 MAS 搜索方面具有潜力。

## Abstract
Designing effective multi-agent systems (MAS) remains a challenging and resource-intensive task. We propose a Bayesian Evolutionary Optimization framework for automatically discovering task-specific MAS topologies. The approach combines evolutionary operators to generate diverse workflow graphs with Bayesian optimization to focus cost intensive evaluations on promising candidates. In contrast to LLM-based candidate selection, our approach uses a graph-aware Gaussian Process and Expected Improvement to provide an explicit selection criterion during evolutionary search. We evaluate the method on BigCodeBench for code generation and on a tabular preprocessing benchmark using TabPFN. On BigCodeBench, evolved architectures achieve the highest overall performance among the evaluated agent systems. On temporal tabular datasets, optimized MAS preprocessing improves over the default TabPFN model on several tasks, while remaining competitive on IID datasets. Overall, the results demonstrate the potential of Bayesian selection for guiding evolutionary MAS search under expensive evaluation budgets.

## 2. 方法论

### 2.1 核心思想

- 结合**进化算子**生成多样化工作流图，结合**图感知贝叶斯优化**选择下一个待评估候选。
- 每轮生成多个候选图，但只选择**一个**进行昂贵的端到端评估。
- 在 Promptolution 框架基础上扩展，形成完整的 MAS 优化流水线。

### 2.2 算法流程

1. **预热阶段**：用 LLM 生成初始工作流图种群，每个图的节点数随机确定，形成不同规模与拓扑。
2. **进化扩展**：对种群中的图施加变异与交叉，生成 N 个候选图。
3. **贝叶斯选择**：基于已评估图及其得分拟合高斯过程，计算每个候选的期望改进（EI），选 EI 最大的候选。
4. **提示分配**：为选中图的每个节点分配智能体类型、系统提示和工具，实例化为完整 MAS。
5. **评估与回填**：在目标任务上评估该 MAS，将图与得分加入种群，继续迭代直至预算耗尽。
6. **输出**：返回评估过的最佳 MAS 架构。

### 2.3 进化算子

- **变异**：随机选择五种算子之一：加节点、加边、删节点、删边、重连边。
- **交叉**：选两个父图，子图规模在父图规模之间随机选择，按概率从两个父图中采样节点和边。
- **搜索空间**：节点数 2–6，边数不超过 9，且为有向无环图。

### 2.4 贝叶斯选择细节

- **图相似度**：使用归一化的、类型感知的图编辑距离（GED）构造核函数：
  - \(k(x,x')=1-\frac{GED(x,x')}{|V_x|+|E_x|+|V_{x'}|+|E_{x'}|}\)。
- **高斯过程**：用该核估计候选图的预测均值 \(\mu(x)\) 与不确定性 \(\sigma(x)\)。
- **期望改进 EI**：
  - \(EI(x)=(\mu(x)-f_{best}-\xi)\Phi(z)+\sigma(x)\phi(z)\)，
  - 其中 \(z=(\mu(x)-f_{best}-\xi)/\sigma(x)\)，\(\xi\) 控制探索。
  - 选择 \(x^\star=\arg\max EI(x)\)。
- **实现注意**：附录指出 GED 核不保证半正定，负的后验方差被截断为 \(10^{-12}\)，而非投影到 PSD 锥；这会偏离标准 EI，并可能偏向与已评估图差异较大的候选。

### 2.5 提示与智能体实例化

- 基础智能体类型：Planner、Executor、Validator。
- LLM 先分析任务并生成任务特定类型。
- 三阶段配置：调度 LLM 分配类型；另一 LLM 生成系统提示；最终组合类型、提示与工具。

- **应用启示**：代码生成任务上，进化式拓扑搜索表现出较稳定的相对优势；表格预测任务则提示 MAS 预处理更适合部分时序或分布偏移场景，而非无条件替代原始预测器。

## 11. 总体评价

论文提出了一套较完整的 MAS 拓扑自动搜索与调优框架，核心贡献在于将图感知贝叶斯优化引入 MAS 候选选择，并在代码生成与表格预测两个差异较大的场景中进行了初步验证。方法设计清晰、预算效率导向明确，实验报告也较为细致。然而，论文对“贝叶斯选择本身”的贡献缺乏直接消融，图核处理存在数学上的近似偏差，基线公平性、统计显著性和计算成本报告仍不充分。综合来看，这是一项方法上有启发性、实验结果有前景但证据强度中等的工作；其结论更适合表述为“进化式 MAS 拓扑搜索在所评设置下具有竞争力”，而非已经证明贝叶斯选择普遍优于其他候选选择策略。
